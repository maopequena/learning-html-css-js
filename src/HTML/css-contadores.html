Contadores

Os contadores são como "variáveis". Seus valores podem ser incrementados por regras do CSS, que acompanharão quantas vezes um elemento é usado.

Para trabalhar com contadores, usaremos as seguintes propriedades:

counter-reset
Define o valor inicial de um contador.
counter-increment
Incrementa um contador.
content
Insere um conteúdo no elemento.
counter() ou counters()
Adiciona o valor de um contador em um elemento.

Para usar contadores, primeiro é preciso definir o counter-reset.
