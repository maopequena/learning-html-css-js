Funções matemáticas

As funções matemáticas nos permitem usar expressões matemáticas como valores de propriedades do CSS.

A função calc()

Esta função executa um cálculo e usa o resultado como o valor da propriedade.

Sintaxe: calc(expressão). A "expressão" é obrigatória. Podemos usar os seguintes operadores: + - * /.

A função max()

Usa o maior valor de uma lista separada por vírgulas como o valor da propriedade.

Sintaxe: max(valor1, valor2, valor3...). Os valores são obrigatórios.

A função min()

Usa o menor valor de uma lista separada por vírgulas como o valor da propriedade.

Sintaxe: min(valor1, valor2, valor3...). Os valores são obrigatórios.
