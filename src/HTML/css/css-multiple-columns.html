Layout de várias colunas

Propriedades

Estas são as propriedades disponíveis para criar um layout de várias colunas:

  • column-count: define a quantidade de colunas que o elemento deve ter.
  • column-gap: define o espaço entre as colunas.
  • column-rule-style: define o estilo da borda entre as colunas.
  • column-rule-width: define a largura da borda entre as colunas.
  • column-rule-color: define a cor da borda entre as colunas.
  • column-rule: abreviação para as três últimas propriedades.
  • column-span: define por quantas colunas um elemento deve se expandir.
  • column-width: define a largura ideal de cada coluna, este é um valor sugerido.
