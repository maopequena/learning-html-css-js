Gradientes

Há três tipos de gradientes no CSS:

  • Linear: de cima para baixo, da esquerda para a direita, na diagonal
  • Radial: definido pelo centro
  • Cônico: giram a partir de um ponto central

Linear

Para criar um gradiente linear, defina ao menos duas cores. É possível definir também um ponto inicial e uma direção (ou ângulo) para o gradiente.

Sintaxe: background-image: linear-gradient(direção, cor1, cor2, ...);. Adicione "in lch, " após o parêntese de abertura para suavizar o gradiente e deixar as cores mais vívidas.

Radial

Para criar um gradiente radial, defina ao menos duas cores. É preciso definir também o centro.

Sintaxe: background-image: radial-gradient(tamanho forma at posição, corInicial, ..., corFinal);.

Por padrão, forma é "ellipse", tamanho é "farthest-corner" e posição é "center".

Cônico

As transições de cores do gradiente cônico giram em torno de um ponto central. É preciso definir ao menos duas cores.

Sintaxe: background-image: conic-gradient([from angle] [at position,] color [degree], color [degree], ...);. Por padrão o ângulo é 0deg e a posição é "center". Se não for definido um valor em graus para as cores, elas serão distribuídas igualmente em volta do centro. Exemplo:
