Transições no CSS

Transições possibilitam mudar o estado de um elemento em determinado período de tempo.

Estas são as propriedades possíveis: transition, transition-delay, transition-duration, transition-property e transition-timing-function.

Como usar transições?

Para criar um efeito de transição, é preciso especificar duas coisas:

  • A propriedade do CSS à qual se deseja adicionar uma transição.
  • A duração do efeito.

Se não especificar a duração, a transição não acontecerá, porque o valor padrão é 0.

A propriedade transition-timing-function

Esta propriedade define a curva de velocidade do efeito de transição. Podemos usar os seguintes valores:

  • ease: define uma transição iniciando devagar, ficando mais rápida e finalizando devagar. Este é o padrão.
  • linear: define uma transição com a mesma velocidade do início ao fim.
  • ease-in: define uma transição que começa devagar.
  • ease-out: define uma transição que termina devagar.
  • ease-in-out: define uma transição que começa e termina devagar.
  • cubic-bezier(n,n,n,n): possibilita definir seus próprios valores em uma função de curva de Bézier.
