Media queries

Com a regra @media é possível definir diferentes regras de estilo para diferentes tipos de mídia. Essa regra não procura somente pelo tipo de dispositivo, mas pelas suas capacidades, por exemplo:

  • A largura e a altura do viewport.
  • A orientação do viewport (paisagem ou retrato).
  • A resolução da tela.

As media queries são uma ótima maneira de adequar a folha de estilo do seu site a dispositivos diversos, como desktops, laptops, tablets e celulares.

Tipos de mídia

Os valores aceitos são:

  • all: usado para todos os tipos de dispositivos.
  • print: usado para o modo de visualização de impressão.
  • screen: usado para telas de computadores, celulares, etc.

Recursos comuns

Este são os recursos alterados por media queries:

Valor Descrição
orientation Altera a orientação do viewport: paisagem ou retrato
max-height Altera a altura máxima do viewport
min-height Altera a altura mínima do viewport
height Altera a altura do viewport (inclusive a barra de rolagem)
max-width Altera a largura máxima do viewport
min-width Altera a largura mínima do viewport
width Altera a largura do viewport (inclusive a barra de rolagem)

Sintaxe

Uma media query consiste de um tipo de mídia e pode conter um ou mais recursos, que serão verdadeiros ou falsos.

      
        @media not|only mediatype and (media feature) and (media feature) {
          propriedade de CSS: valor;
          propriedade de CSS: valor;
          propriedade de CSS: valor;
          ...
        }

O mediatype é opcional (se omitido, é definido como all). Entretanto, se forem usadas as palavras-chave not ou only, é preciso definir o mediatype.

O resultado da consulta é verdadeiro se o tipo de mídia definido corresponder ao tipo de dispositivo em que o documento está sendo exibido e se todos os recursos de mídia da consulta forem verdadeiros. Quando a media query é considerada como verdadeira, as regras de estilo correspondentes são aplicadas seguindo as regras normais da cascata. Consulte O modelo de cascata para ver a ordem correta.

As palavras-chave têm os seguintes significados:

  • not: inverte o significado de toda a media query.
  • only: impede que navegadores mais antigos, que não oferecem suporte a media queries, apliquem determinados estilos. Esta palavra-chave não tem efeito em navegadores modernos.
  • and: combina um tipo de mídia e um ou mais recursos de mídia.

Também é possível vincular várias folhas de estilo, dependendo do tipo da mídia ou da largura da janela do navegador (viewport):

      
        <link rel="stylesheet" media="print" href="print.css">
        <link rel="stylesheet" media="screen" href="screen.css">
        <link rel="stylesheet" media="screen and (min-width: 480px)" href="example1.css">
        <link rel="stylesheet" media="screen and (min-width: 701px) and (max-width: 900px)" href="example2.css">
        etc....

Um exemplo muito comum para as media queries é deslocar o menu ou a barra de navegação lateral para cima ou para baixo do conteúdo da página quando a tela do dispositivo é pequena. Isso garante que a leitura não seja prejudicada.

As media queries são usadas, principalmente, para tornar um site mais acessível, aumentando o tamanho da fonte, alterando as cores, e muito mais.
