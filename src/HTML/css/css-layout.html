Layout

A seguir trataremos de propriedades do CSS que configuram o layout da página HTML.

As propriedades width, max-width e margin: auto.

Já sabemos que um elemento de bloco ocupa toda a largura disponível da página.

Definir a propriedade width de um elemento de bloco impedirá que ele se estique até as margens de seu contêiner. Definir as margens como automáticas centraliza o elemento horizontalmente nesse contêiner.

Porém, quando a largura da tela é menor que a largura definida, o navegador adiciona barras de rolagem à página e o contêiner pode ficar maior que a tela, vazando nas laterais. Para solucionar esse problema, defina a propriedade max-width.

A propriedade position

Especifica o tipo de posicionamento de um elemento (static, relative, fixed, absolute ou sticky). Depois, os elementos são posicionados usando as propriedades top, bottom, left e right. Essas propriedades, entretanto, funcionam de forma diferente dependendo do valor da propriedade position do elemento pai.

Lembre-se: essa propriedade define o posicionamento de acordo com o contêiner pai do objeto definido. Isto é, se o elemento estiver dentro de um contêiner, o posicionamento do elemento será relativo ao contêiner.

position: static

Todos os elementos têm essa posição definida por padrão e não são afetados pelas propriedades top, bottom, left e right. Isso define o elemento de acordo com o fluxo normal da página.

Exemplo

Este elemento div tem position: static;.

position: relative

Um elemento com esta propriedade será posicionado de forma relativa ao seu contêiner, e as propriedades top, bottom, left e right alteram a posição do elemento.

Exemplo

Este elemento div tem position: relative; e left: 70px;.

position: fixed

Um elemento com esta propriedade é posicionado relativamente ao viewport (ou o elemento <html> pai), isto é, sempre fica no mesmo lugar ao rolar a página. Use top, bottom, left e right para controlar o posicionamento do elemento.

O local na página em que o elemento ficaria não tem espaço em branco.

Note o elemento fixo no canto direito inferior da página! Veja que ele não ocupa espaço aqui.

Este elemento div tem position: fixed;, bottom: 0; e right: 0;.

position: absolute

Um elemento com esta propriedade é posicionado relativamente ao ancestral mais próximo, em vez de relativamente ao viewport, como o elemento fixed. Entretanto, se o elemento absoluto não tiver ancestrais, ele usará o corpo do documento e se movimentará na página com a rolagem.

Observação: elementos com posição absoluta são removidos do fluxo normal da página e podem ficar sobrepostos a outros elementos. Isso significa duas coisas:

  1. Você pode posicionar esse elemento onde quiser, usando top, right, bottom e left em seu pai relativo mais próximo.
  2. Todo o conteúdo em volta de um elemento absoluto será reposicionado para preencher o espaço restante deixado por aquele elemento.

Exemplo

Este elemento div tem position: relative;
Este elemento div tem position: absolute; com top: 80px; e right: 0;.

position: sticky

Esta propriedade posiciona o elemento com base na rolagem da página. Esta propriedade alterna o estado entre "relative" e "fixed": o elemento fica relativo até atingir a posição definida, depois fica fixo.

Observação: elementos com posição fixa não são removidos do fluxo normal da página e podem ficar sobrepostos a outros elementos.

Observação: elementos com posição fixa não tem ancestrais.

Exemplo

Exemplo de posicionamento sticky

Ao definir um valor para position diferente de static, é possível separar os elementos com as propriedades top, right, bottom e left. Porém esses valores de direção comportam-se de forma diferente:

  • Com position: relative, o elemento mantém seu lugar no fluxo do documento, mesmo ao definir esses valores. Os valores serão relativos à posição do elemento.
  • Com position: absolute, o elemento baseia os valores de direção na posição relativa de seu pai.
  • Com position: fixed, o elemento baseia os valores de direção no viewport.
  • Com position: sticky, o elemento aplica os valores de direção quando está em seu estado "grudado/fixado".

A propriedade overflow

Define se um conteúdo deve ser cortado e se serão exibidas barras de rolagem no caso de o conteúdo ser maior que a área definida para o elemento.

Valores da propriedade overflow

  • visible: padrão. o conteúdo que sobra não é cortado e é processado fora da caixa do elemento.
  • hidden: o conteúdo que sobra é cortado e o restante fica invisível.
  • scroll: o conteúdo que sobra é cortado e são exibidas barras de rolagem para o restante.
  • auto: similar a scroll, mas as barras de rolagem aparecem conforme necessário.

Observação: essa propriedade só funciona para elementos com uma altura definida.

Exemplos

overflow-x e overflow-y

Definem o que acontece com os eixos horizontal e vertical, respectivamente, do elemento em questão.

overflow-x: hidden specifies what to do with the left/right edges of the content. overflow-y: scroll specifies what to do with the top/bottom edges of the content.

overflow: wrap

overflow-wrap: normal|anywhere|break-word|initial|inherit;

Define se o navegador pode ou não quebrar linhas se o conteúdo for muito grande para o contêiner.

As propriedades float e clear

float define como o elemento deve flutuar na página e clear define quais elementos podem flutuar ao lado do elemento com esta propriedade e em qual lado.

O uso mais simples de float é fazer o texto se adequar em volta de uma imagem.

Valores de clear: left, right, none, both e inherit.

display: inline-block

Em comparação com o elemento display: inline, a principal diferença é que display: inline-block possibilita definir a largura e a altura do elemento. Além disso, com display: inline-block, as margens e paddings superior e inferior são respeitadas, o que não acontece com display: inline.

Em comparação com display: block, a principal diferença é que display: inline-block não adiciona uma quebra de linha após o elemento, então um elemento fica grudado aos que estão ao lado dele.

Layout de páginas da Web

O cabeçalho geralmente fica no topo da página (ou logo abaixo do menu de navegação) e costuma apresentar um logotipo e o nome do site.

A barra de navegação contém uma lista de links para ajudar os visitantes a navegar pelo site.

O layout da seção de conteúdo geralmente depende dos usuários que se deseja atrair com o site. Os layouts mais comuns são de 1 (para navegadores móveis), 2 (para tablets e laptops) ou 3 (para desktops apenas) colunas. Uma dessas colunas pode ocupar 50% da largura disponível, exibindo o conteúdo principal, deixando os outros 50% para serem divididos entre outras duas colunas (cada uma com 25%).

O rodapé fica no final da página e geralmente apresenta informações como copyright e de contato.

Propriedades lógicas

A propriedade writing-mode

O texto flui na direção determinada pelo modo de escrita do documento (fluxo de bloco: vertical e fluxo de linha: horizontal). Você pode alterar isso com a propriedade writing-mode. Ela pode ser aplicada a todo o documento ou a elementos específicos.

Fluxo relativo

No CSS, propriedades como margin e padding são relativas ao lado nomeado, como margin-top, que refere-se ao lado superior de um elemento. Com propriedades lógicas, margin-top torna-se margin-block-start. Quer dizer, independentemente do idioma e da direção do texto, o fluxo do bloco terá as regras de margem apropriadas.

Isso também serve para a propriedade padding.

Veja também: CSS (Cascading Style Sheets) e Margens e padding no CSS.

Tamanho relativo

Para impedir que um elemento exceda determinada largura ou altura, costumamos usar as propriedades max-width e max-height. Suas contrapartes lógicas são max-inline-size e max-block-size. E para min-width e min-height, min-inline-size e min-block-size.

Início e fim

Ao invés de usar direções, como top, right, bottom e left, use start e end, que possibilita aplicar propriedades do CSS que respondem a alterações no modo de escrita.

Por exemplo, ao invés de usar text-align: right, use text-align: end.

Espaçamento e posicionamento

Usar propriedades lógicas para margem, padding e inset facilita posicionar os elementos e determinar como os elementos interagem entre si e com o modo de escrita. As propriedades relacionadas à margem e ao padding ainda são mapeamentos para direções, porém a principal diferença é que quando o modo de escrita mudar, elas também mudarão. Por exemplo, ao invés de usar:

            
              .my-element {
                padding-top: 2em;
                padding-bottom: 2em;
                margin-left: 2em;
                position: relative;
                top: 0.2em;
              }

Podemos usar:

            
              .my-element {
                padding-block-start: 2em;
                padding-block-end: 2em;
                margin-inline-start: 2em;
                position: relative;
                inset-block-start: 0.2em;
              }

Bordas

Também há propriedades lógicas para bordas. Por exemplo: border-block-end, border-inline-end e border-end-end-radius. Esta última define o fim do bloco e da linha.

Assista ao vídeo Five easy and fun CSS effects, de Kevin Powell, para saber como estilizar com a propriedade outline para ver alguns efeitos interessantes com as bordas e o elemento <hr>.

Unidades

As propriedades lógicas nos dão duas novas unidades: vi e vb. A unidade vi é 1% do tamanho do viewport na direção da linha (horizontal) e é equivalente à propriedade não-lógica vw. A unidade vb é 1% do viewport na direção do bloco (vertical) e é equivalente à propriedade não-lógica vh.

Essas unidades sempre se relacionarão à direção do modo de escrita. Por exemplo, se quiser que um elemento tome 80% do espaço de linha disponível no viewport, use a unidade vi para alternar automaticamente esse tamanho para ser top e bottom se o modo de escrita é vertical.

Usar as propriedades lógicas de forma pragmática

As propriedades lógicas e o modo de escrita não servem apenas para internacionalização. Também é possível usá-las para criar uma interface de usuário mais versátil.

Por exemplo, um gráfico que contém legendas nos dois eixos, X e Y, pode exibir a legenda do eixo Y verticalmente com as mesmas margens do eixo X se você usar propriedades lógicas.

Usando propriedades lógicas, por exemplo, é possível posicionar um ícone e seu texto correspondente com margens corretas independentemente do modo ou da direção de escrita.
