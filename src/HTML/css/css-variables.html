Variáveis

Use a função var() para inserir o valor de uma variável do CSS.

As variáveis do CSS têm acesso ao DOM, o que significa que podemos criar variáveis com escopos local ou global, alterá-las com JavaScript e alterá-las usando media queries.

Um exemplo muito útil para as variáveis no CSS são as cores do design do site. Ao invés de copiar e colar as mesmas cores repetidamente, defina-as como variáveis.

A forma tradicional de definir cores é a seguinte:

        
          body {
            background-color: #1e90ff;
          }

          h2 {
            border-bottom: 2px solid #1e90ff;
          }

          .container {
            color: #1e90ff;
            background-color: #ffffff;
            padding: 15px;
          }

          button {
            background-color: #ffffff;
            color: #1e90ff;
            border: 1px solid #1e90ff;
            padding: 5px;
          }

Porém, usando var(--nome, valor), podemos fazer o seguinte:

        
          :root {
            --blue: #1e90ff;
            --white: #ffffff;
          }

          body {
            background-color: var(--blue);
          }

          h2 {
            border-bottom: 2px solid var(--blue);
          }

          .container {
            color: var(--blue);
            background-color: var(--white);
            padding: 15px;
          }

          button {
            background-color: var(--white);
            color: var(--blue);
            border: 1px solid var(--blue);
            padding: 5px;
          }

--nome é obrigatório, valor é opcional e é usado como fallback, caso a variável não seja encontrada.

Observação: o nome da variável deve começar com dois hifens (--) e diferencia maiúsculas de minúsculas!

Como funciona a função var()

Variáveis globais podem ser acessadas/usadas em todo o documento, as locais só podem ser usadas no seletor em que foram declaradas.

Para criar uma variável com escopo global, declare-a no seletor :root, que corresponde ao elemento raiz do documento. Para criar uma variável com escopo local, declare-a dentro do seletor em que será usada.

As vantagens de usar var() são:

  • O código fica mais fácil de ler (isto é, mais compreensível).
  • Fica mais fácil alterar os valores das cores.

No exemplo acima, se quisermos alterar para um azul mais claro, só precisamos alterar o código da cor em um lugar: na variável.

É possível, ainda, substituir os valores das variáveis globais localmente. Se quisermos um tom de azul diferente somente para os botões, por exemplo, podemos alterar a variável no seletor do botão:

        
          :root {
            --blue: #1e90ff;
            --white: #ffffff;
          }

          body {
            background-color: var(--blue);
          }

          h2 {
            border-bottom: 2px solid var(--blue);
          }

          .container {
            color: var(--blue);
            background-color: var(--white);
            padding: 15px;
          }

          button {
            --button-blue: #0000ff; /* local variable will override global */
            background-color: var(--white);
            color: var(--blue);
            border: 1px solid var(--button-blue);
            padding: 5px;
          }

Alterar variáveis com JavaScript

Como as variáveis têm acesso ao DOM, podemos alterá-las com JavaScript. Eis um exemplo de como criar um script para exibir e alterar a variável --blue do exemplo anterior.

        
          <script>
            // Get the root element
            var r = document.querySelector(':root');

            // Create a function for getting a variable value
            function myFunction_get() {
              // Get the styles (properties and values) for the root
              var rs = getComputedStyle(r);
              // Alert the value of the --blue variable
              alert("The value of --blue is: " + rs.getPropertyValue('--blue'));
            }

            // Create a function for setting a variable value
            function myFunction_set() {
              // Set the value of variable --blue to another value (in this case "lightblue")
              r.style.setProperty('--blue', 'lightblue');
            }
          </script>

Alterar variáveis com media queries

É possível alterar as variáveis globais e locais usando media queries. Podemos alterar uma variável --fontsize ou --nome-da-cor quando a tela atinge determinada largura. Por exemplo, podemos diminuir ou aumentar o tamanho da fonte para telas de celulares ou de desktops. Exemplo de uso:

        
          /* Variable declarations */
          :root {
            --blue: #1e90ff;
            --white: #ffffff;
          }

          .container {
            --fontsize: 25px;
          }

          /* Styles */
          body {
            background-color: var(--blue);
          }

          h2 {
            border-bottom: 2px solid var(--blue);
          }

          .container {
            color: var(--blue);
            background-color: var(--white);
            padding: 15px;
            font-size: var(--fontsize);
          }

          @media screen and (min-width: 450px) {
            .container {
              --fontsize: 50px;
            }
            :root {
              --blue: lightblue;
            }
          }
