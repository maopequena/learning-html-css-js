Opacidade/Transparência

A propriedade opacity define a opacidade (ou transparência) de um elemento. Ela recebe um valor de 0.0 a 1.0, do mais ao menos transparente. Por exemplo:

Os elementos filhos de um elemento com a propriedade opacity herdam a opacidade, então o texto de uma imagem ou caixa transparente pode ser difícil de ler.
