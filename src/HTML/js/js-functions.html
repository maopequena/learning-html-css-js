Funções

Em JavaScript, uma função é um bloco de código que realiza uma determinada tarefa. Ela é executada quando algo a "chama".

As funções servem, principalmente, para podermos reutilizar o código em diferentes lugares do projeto. Diferentes argumentos têm resultados diferentes.

Apesar de o operador typeof retornar "function" para funções, o JavaScript considera uma função como um objeto, com propriedades e métodos. A propriedade argumento.length retorna o número de parâmetros recebidos ao chamar a função:

			
				function minhaFuncao(a, b) {
					return arguments.length;
				}

O método toString() retorna a função como uma cadeia de caracteres:

			
				function minhaFuncao(a, b) {
					return a * b;
				}
				
				let text = minhaFuncao.toString();

Uma função definida como propriedade de um objeto é o método do objeto. Uma função que cria novos objetos é um construtor de objetos.

Sintaxe

Para definir uma função, use a palavra-chave function, seguida de um nome (definido pelo desenvolvedor, use algo fácil de lembrar e que se relacione à tarefa que a função executará), de parênteses (( )) e de chaves ({ }). Os nomes das funções podem conter letras, dígitos, sublinhados e cifrões (mesma regra das variáveis). Os parênteses podem conter nomes de parâmetros, separados por vírgulas. O código a ser executado pela função deve ser colocado entre as chaves:

				
					function nome(parâmetro1, parâmetro2, parâmetro3) {
						// código a executar
					}

Lembre-se de sempre usar ponto-e-vírgula (;) para separar declarações executáveis no JavaScript. Como a declaração de uma função não é executável, não é comum usar ponto-e-vírgula após a chave final de uma função.

Parâmetros e argumentos

Argumentos são os valores recebidos pela função ao chamá-la, e dentro da função os argumentos (chamados parâmetros) comportam-se como variáveis. Lembre-se:

Uma função do JavaScript não realiza qualquer verificação dos valores dos parâmetros (argumentos).

Os parâmetros são os nomes listados na definição da função. Os argumentos são os valores reais passados para (e recebidos pela) a função.

O operador ()

Este operador chama a função, mas lembre-se que acessar uma função com parâmetros incorretos pode retornar uma resposta incorreta.

call()

O método predefinido call() possibilita escrever um método que pode ser usado em diferentes objetos.

Ele pode ser usado para chamar um método com um objeto como argumento (parâmetro). Com este método, um objeto pode usar um método que pertence a outro objeto.

						
							const pessoa = {
								nomeCompleto: function() {
									return this.primeiroNome + " " + this.sobrenome;
								}
							}
							const pessoa1 = {
								primeiroNome:"John",
								sobrenome: "Doe"
							}
							const pessoa2 = {
								primeiroNome:"Mary",
								sobrenome: "Doe"
							}
							
							// Isso retorna "John Doe":
							pessoa.nomeCompleto.call(person1);

							// Isso retorna "Mary Doe"
							person.nomeCompleto.call(person2);

Como vimos acima, este método aceita argumentos.

						
							const pessoa = {
								nomeCompleto: function(cidade, pais) {
									return this.primeiroNome + " " + this.sobrenome + "," + cidade + "," + pais;
								}
							}
							
							const pessoa1 = {
								primeiroNome:"John",
								sobrenome: "Doe"
							}
							
							pessoa.nomeCompleto.call(pessoa1, "Oslo", "Noruega");

apply()

Assim como call(), este método possibilita escrever um método que pode ser usado em diferentes objetos.

A diferença é:

  • call() aceita argumentos separadamente.
  • apply() aceita argumentos como uma matriz.
						
							const pessoa = {
								nomeCompleto: function(cidade, pais) {
									return this.primeiroNome + " " + this.sobrenome + "," + cidade + "," + pais;
								}
							}
							
							const pessoa1 = {
								primeiroNome:"John",
								sobrenome: "Doe"
							}
							
							pessoa.nomeCompleto.apply(pessoa1, ["Oslo", "Noruega"]);

bind()

Este método possibilita emprestar um método de outro objeto.

						
							const pessoa = {
								primeiroNome:"John",
								sobrenome: "Doe",
								nomeCompleto: function () {
									return this.primeiroNome + " " + this.sobrenome;
								}
							}
							
							const membro = {
								primeiroNome:"Hege",
								sobrenome: "Nilsen",
							}
							
							let nomeCompleto = pessoa.fullName.bind(membro);

							// Retorna "Hege Nilsen"

Regras de parâmetros

As definições de função no JavaScript não especificam tipos de dados para parâmetros, não verificam o tipo dos argumentos informados e não verificam a quantidade de argumentos recebidos.

Ao chamar uma função com argumentos ausentes (menos do que o declarado*), os valores ausentes são definidos com undefined. Algumas vezes isso é aceito, mas é melhor atribuir um valor padrão para o parâmetro:

						
							function minhaFuncao(x, y) {
								if (y === undefined) { // Se y for indefinido
									y = 2;							 // Defina y como 2
								}
							}

							OU

							function minhaFuncao(x, y = 10) { // valor padrão diretamente no parâmetro
								return x + y;
							}
							minhaFuncao(5);

*Se a quantidade de argumentos for maior que a quantidade de parâmetros, é possível usar o objeto arguments.

O parâmetro rest

O parâmetro rest (...) permite que uma função trate um número indefinido de argumentos como uma matriz:

						
							function soma(...args) {
								let soma = 0;
								for (let arg of args) soma += arg;
								return soma;
							}
							
							let x = soma(4, 9, 16, 25, 29, 100, 66, 77); // 326

O objeto arguments

As funções no JavaScript têm um objeto incorporado chamado arguments, que contém uma matriz dos argumentos usados ao chamar a função. Dessa forma é possível usar a função para encontrar, por exemplo, o valor mais alto em uma lista de números:

						
							x = encontrarMax(1, 123, 500, 115, 44, 88);

							function encontrarMax() {
								let max = -Infinity;
								for (let i = 0; i < arguments.length; i++) {
									if (arguments[i] > max) {
										max = arguments[i];
									}
								}
								return max;
							}

Ou criar uma função para somar todos os valores inseridos:

						
							x = somarTudo(1, 123, 500, 115, 44, 88);

							function somarTudo() {
								let sum = 0;
								for (let i = 0; i < arguments.length; i++) {
									sum += arguments[i];
								}
								return sum;
							}

Argumentos são passados pelo valor

Ao chamar uma função, os parâmetros se tornam os argumentos da função, e eles são passados pelo seu valor, isto é, a função só recebe os valores, não os locais dos argumentos.

Se uma função alterar o valor de um argumento, isso não altera o valor original do parâmetro. Mudanças feitas aos argumentos não ficam visíveis (não se refletem) fora da função.

Objetos são passados como referências

No JavaScript, as referências dos objetos são os valores. Por causa disso, os objetos se comportam como se fossem passados pela referência, isto é, se a função alterar a propriedade de um objeto, isso altera o valor original. Mudanças feitas a propriedades de objetos ficam visíveis (se refletem) foram da função.

Como chamar uma função

O código dentro de uma função será executado quando "algo" chamar a função:

  • Quando um evento ocorre (p.ex. um clique no botão do mouse).
  • Quando a função é chamada pelo código
  • Automaticamente (chamada em si mesma)

O código em uma função não é executado ao definir a função. Em vez disso, é executado ao chamar a função.

É comum usar o termo "invocar uma função" em vez de "chamar". Também se usa "iniciar" ou "executar". Porém, aqui, usaremos chamar, porque as funções podem ser chamadas sem serem "invocadas" (que é um termo um tanto pejorativo no português brasileiro).

Chamar automaticamente

Esta é a forma mais comum de chamar uma função no JavaScript, porém não é uma prática recomendada. Variáveis, métodos e funções globais podem facilmente criar conflitos de nome e bugs no objeto global.

					
						function minhaFuncao(a, b) {
							return a * b;
						}
						minhaFuncao(10, 2);           // Retorna 20

A função acima não pertence a nenhum objeto, mas, no JavaScript, sempre há um objeto padrão global.

No HTML, o objeto padrão global é a página HTML em si, então a função acima "pertence" à página HTML.

Em um navegador, o objeto da página é a janela do navegador. Então a função acima automaticamente se torna uma função da janela.

minhaFuncao e window.minhaFuncao são a mesma coisa neste caso.

Chamar como um método

É possível definir funções como métodos de objetos. O exemplo a seguir cria um objeto (meuObjeto) com duas propriedades (primeiroNome e sobrenome) e um método (nomeCompleto):

					
						const meuObjeto = {
							primeiroNome:"John",
							sobrenome: "Doe",
							nomeCompleto: function () {
								return this.primeiroNome + " " + this.sobrenome;
							}
						}
						meuObjeto.nomeCompleto();         // Retorna "John Doe"

O método nomeCompleto é uma função, que pertence ao objeto meuObjeto. this é o objeto "dono" do código JavaScript, neste caso, o valor de this é neuObjeto. Podemos testar isso alterando o método fullName para retornar o valor de this:

					
						const meuObjeto = {
							primeiroNome:"John",
							sobrenome: "Doe",
							nomeCompleto: function () {
								return this;
							}
						}
						
						// Retorna [object Object] (o objeto proprietário)
						meuObjeto.nomeCompleto();

Chamar com um construtor

Se chamar uma função com a palavra-chave new na frente, essa chamada se torna um construtor. Parece que criamos uma função, mas como as funções no JavaScript são objeto, na verdade estamos criando um novo objeto:

					
						// Um construtor de função:
						function minhaFuncao(arg1, arg2) {
							this.primeiroNome = arg1;
							this.sobrenome  = arg2;
						}

						// Isso cria um novo objeto
						const meuObjeto = new minhaFuncao("John", "Doe");

						// Isso retorna "John"
						meuObjeto.primeiroNome;

O novo objeto herda as propriedades e métodos de seu construtor.

Retorno de função

Ao atingir uma declaração return, a função pára de executar. Se uma declaração chamou a função, o JavaScript "retorna" para executar o código após a declaração de chamada.

As funções geralmente calculam um valor de retorno, que "retorna" de volta para o que chamou a função. Exemplo:

				
					// A função é chamada, o valor de retorno será exibido em x
					let x = minhaFuncao(4, 3);
					
					function minhaFuncao(a, b) {
					// A função retorna o produto de a e b
						return a * b;
					}

Usar funções como variáveis

Funções podem ser usadas da mesma forma que as variáveis, em todos os tipos de fórmulas, atribuições e cálculos. Em vez de usar uma variável para armazenar o valor de uma função, é possível usar a função diretamente, como um valor de variável. Por exemplo:

				
					// Em vez disso:
					let x = toCelsius(77);
					let text = "The temperature is " + x + " Celsius";

					// Faça isso:
					let text = "The temperature is " + toCelsius(77) + " Celsius";

Variáveis locais

As variáveis declaradas em uma função JavaScript se tornam locais e só podem ser acessadas dentro da função. Por causa disso, é possível usar variáveis com o mesmo nome em diferentes funções. As variáveis locais são criadas ao iniciar uma função e excluídas após sua conclusão.

A função de seta

Funções de seta simplificam a escrita de códigos de funções, tornando-a mais curta.

				
					// Sem a função de seta:
					hello = function() {
						return "Hello World!";
					}

					// Com a função de seta:
					hello = () => {
						return "Hello World!";
					}

E se a função tem apenas uma declaração que retorna um valor, é possível remover também as chaves e a palavra-chave return:

				
					hello = () => "Hello World!";

Os parâmetros podem ser colocados entre os parênteses. E se tivermos apenas um parâmetro, podemos remover também os parênteses:

				
					// Com parênteses:
					hello = (val) => "Hello " + val;

					// Sem parênteses:
					hello = val => "Hello " + val;

Porém, recomenda-se sempre usar os parênteses, mesmo quando desnecessários.

Funções de seta não são içadas, e devem ser definidas antes do uso.

É mais seguro usar const do que var, porque uma expressão de função é sempre um valor constante.

E a palavra-chave this?

Em funções de seta, o comportamento da palavra-chave this também é diferente. Nelas, essa palavra-chave não é vinculada ao objeto que chamou a função, mas sim ao objeto que definiu a função.

Para entender melhor a diferença, veja os exemplos em JavaScript Arrow Functions.

Expressões de funções

Uma função no JavaScript também pode ser definida com uma expressão. Uma expressão de função pode ser armazenada em uma variável, o que nos permite usar a variável como uma função:

				
					// Armazenar a expressão de uma função em uma variável
					const x = function (a, b) {return a * b};

					// Usar a variável como uma função
					let z = x(4, 3);

Funções armazenadas em variáveis não precisam ter nomes, elas são anônimas, porque são chamadas pela variável.

Funções automáticas

Expressões de função também podem chamar a si mesmas, elas iniciam automaticamente, sem serem chamadas. Isso ocorre se a expressão for seguida de (). Porém, não é possível chamar automaticamente uma declaração de função, para isso é preciso adicionar parênteses em volta da função para indicar que é uma expressão de função:

					
						(function () {
							let x = "Olá!!";  // Eu chamo a mim mesma!
						})();

Esse tipo de expressão também é anônimo.

Podemos usar funções como valores

Podemos usar funções como valores ou em expressões:

				
					function minhaFuncao1(a, b) {
						return a * b;
					}
					
					let x = minhaFuncao1(4, 3);

					function minhaFuncao2(a, b) {
						return a * b;
					}
					
					let x = minhaFuncao2(4, 3) * 2;

Closures

As variáveis no JavaScript podem pertencer ao escopo local ou ao escopo global. As variáveis globais podem se tornar locais (isto é, privadas) com closures.

Variáveis locais

Uma variável local é "privada" quando está dentro de uma função. A função pode acessar todas as variáveis do escopo local. Por exemplo:

					
						function myFunction() { // a é uma variável local definida dentro da função
							let a = 4;
							return a * a;
						}

Variáveis globais

Uma variável global é "pública", e é definida fora de uma função. A função pode acessar todas as variáveis do escopo global. Por exemplo:

					
						let a = 4; // a é uma variável global definida fora da função
						function myFunction() {
							return a * a;
						}

Em uma página da Web, as variáveis globais pertencem à página e podem ser usadas (ou alteradas) por todos os scripts na página.

Uma variável local só pode ser usada dentro da função em que foi definida. Ela é privada e fica oculta de outras funções e scripts.

Variáveis globais e locais com o mesmo nome são completamente diferentes. Se você alterar uma, não altera a outra.

Variáveis não declaradas (criadas sem as palavras-chave var, let ou const), sempre são globais, mesmo se forem criadas dentro de uma função.

					
						function myFunction() { // A variável a é global porque não foi declarada
							a = 4;
						}

Ciclo de vida de variáveis

As variáveis globais permanecem ativas até que a página seja descartada, como ao navegar para outra página ou ao fechar a janela. As variáveis locais têm uma vida mais curta: são criadas ao chamar a função e excluídas ao finalizar a função.

Funções aninhadas

Todas as funções têm acesso ao escopo global. Na verdade, em JavaScript, todas as funções têm acesso ao escopo "acima" delas.

O JavaScript oferece suporte a funções aninhadas, que têm acesso ao escopo "acima" delas. Por exemplo, a função plus() abaixo tem acesso à variável counter da função pai:

				
					function add() {
						let counter = 0;
						function plus() {counter += 1;}
						plus();   
						return counter;
					}

O dilema do contador

Suponhamos que queremos usar uma variável para contar algo, e esse contador deve estar disponível para todas as funções. Poderíamos usaruma variável global e uma função para aumentar o contador:

				
					// Iniciar contador
					let contador = 0;

					// Função para incrementar o contador
					function somar() {
						contador += 1;
					}

					// Chamar somar() 3 vezes
					somar();
					somar();
					somar();

					// O contador agora deve valer "3"

Porém, há um problema com a solução acima: qualquer código na página pode alterar o contador sem precisar chamar somar(). O contador deve, então, ser local à função somar(), para impedir que outros códigos o alterem:

				
					// Iniciar contador
					let contador = 0;

					// Função para incrementar o contador
					function somar() {
						let contador = 0;
						contador += 1;
					}

					// Chamar somar() 3 vezes
					somar();
					somar();
					somar();

					// O contador deveria ser "3", mas é "0"

Isso não funciona porque exibimos o contador global em vez de um local. Podemos remover o contador global e acessar o local fazendo com que a função o retorne:

				
					// Função para incrementar o contador
					function somar() {
						let contador = 0;
						contador += 1;
						return contador;
					}

					let x= 0;
					// Chamar somar() 3 vezes
					x = somar();
					x = somar();
					x = somar();

					// O contador deveria ser "3", mas é "1".

Não funcionou porque redefinimos o contador local sempre que chamamos a função.

Uma função aninhada talvez resolvesse o dilema do contador, se pudéssemos chegar à função plus() a partir do escopo global. E também precisamos descobrir como executar counter = 0 apenas uma vez.

A solução é uma closure!

				
					function meuContador() {
						let contador = 0;
						return function() {
							contador++;
							return contador;
						};
					}
					const somar = meuContador();
					somar();
					somar();
					somar();
					
					// Agora, o contador é 3
Explicação

A variável somar é atribuída ao valor de retorno de uma função. Essa função é executada apenas uma vez, define o contador como zero (0) e retorna uma expressão de função. Dessa forma, somar se torna uma função, que pode acessar o contador em seu escopo pai.

Isso é uma closure. Ela possibilita que uma função tenha variáveis "privadas". O contador está protegido pelo escopo da função meuContador, e só pode ser alterado usando a função somar.

Closures podem ser usadas para:

  • Criar variáveis privadas
  • Preservar o estado entre chamadas de uma função
  • Simular o escopo de bloco entes do uso de let e const
  • Implementar determinados padrões de design, como "currying" e "memoization"
