Mapas

Um mapa guarda pares de chave-valor, em que as chaves podem ter qualquer tipo de dado. O mapa se lembra da posição original de inserção das chaves.

Mapas são objetos, isto é, um typeof retorna object. O instanceof de um mapa retorna true.

Como criar um mapa

É possível criar um mapa em JavaScript das seguintes maneiras:

  • Passando uma matriz para new Map()
  • Criando um mapa vazio e usando Map.set()

new Map()

Passe uma matriz para o construtor new Map(), por exemplo:

					
						// Criar o mapa
						const frutas = new Map([
							["macas", 500],
							["bananas", 300],
							["laranjas", 200]
						]);

set()

Adicione elementos a um mapa com o método set():

					
						// Criar o mapa
						const futas = new Map();

						// Definir os valores do mapa
						futas.set("macas", 500);
						futas.set("bananas", 300);
						futas.set("laranjas", 200);

Também podemos usar este método para alterar os valores existentes de um mapa:

					
						frutas.set("macas", 200);

get()

Obtém o valor associado a uma chave do mapa:

					
						frutas.get("macas");    // Retorna 500

size

Retorna a quantidade de elementos em um mapa:

					
						frutas.size;

delete()

Remova um elemento do mapa:

					
						frutas.delete("laranjas");

clear()

Remove todos os elementos de um mapa:

					
						frutas.clear();

has()

Retorna true se uma chave existir no mapa:

					
						frutas.has("macas");

forEach()

Executa uma função para cada par de chave-valor do mapa:

					
						// Listar todos os elementos
						let texto = "";
						frutas.forEach (function(value, key) {
							texto += key + ' = ' + value;
						})

entries()

Retorna um objeto iterador com pares de [chave, valor] de um mapa:

					
						// Listar todas as entradas
						let texto = "";
						for (const x of frutas.entries()) {
							texto += x;
						}

keys()

Retorna um objeto iterador com as chaves de um mapa:

					
						// Listar todas as chaves
						let texto = "";
						for (const x of frutas.keys()) {
							texto += x;
						}

values()

Retorna um objeto iterador com os valores de um mapa:

					
						// Listar todos os valores
						let texto = "";
						for (const x of frutas.values()) {
							texto += x;
						}

Este método também pode ser usado para somar os valores de um mapa:

					
						// Somar todos os valores
						let total = 0;
						for (const x of frutas.values()) {
							total += x;
						}

groupBy()

Este método agrupa elementos de um objeto de acordo com valores de strings retornados por uma função de retorno. Ele não altera o objeto original.

					
						// Criar uma matriz
						const frutas = [
							{name:"macas", quantity:300},
							{name:"bananas", quantity:500},
							{name:"laranjas", quantity:200},
							{name:"kiwis", quantity:150}
						];

						// Função de retorno para agrupar elementos
						function meuRetorno({ quantity }) {
							return quantity > 200 ? "ok" : "pouco";
						}

						// Agrupar por quantidade
						const resultado = Map.groupBy(frutas, meuRetorno);

groupBy() pode ser usado com objetos e mapas. A diferença é que com objetos, ele agrupa elementos em um objeto; com mapas, agrupa-os em um mapa.

Diferenças entre objetos e mapas

Objeto Mapa
Não é iterável diretamente É iterável diretamente
Não tem uma propriedade size Tem uma propriedade size
As chaves devem ser sequências de caracteres (ou símbolos) As chaves podem ter qualquer tipo de dado
As chaves não tem uma ordem adequada As chaves são ordenadas pela inserção
Tem chaves por padrão Não tem chaves por padrão

Objetos como chaves

Um importante recurso dos mapas é poder usar os objetos como chaves.

					
						// Criar objetos
						const macas = {name: 'Maçãs'};
						const bananas = {name: 'Bananas'};
						const laranjas = {name: 'Laranjas'};

						// Criar um mapa
						const frutas = new Map();

						// Adicionar novos elementos ao mapa
						frutas.set(macas, 500);
						frutas.set(bananas, 300);
						frutas.set(laranjas, 200);

Neste caso, as chaves são objetos (variáveis), não sequências de caracteres ("strings"). Se usarmos o método get() no código acima com a string "macas", o resultado será Undefined.
