Declarações

Um programa de computador é uma lista de "instruções" a serem "executadas" por um computador.

Na linguagem de programação, essas instruções chamam-se declarações.

Um programa em JavaScript é uma lista de declarações, que são executadas pelo navegador.

Composição

Declarações de JavaScript são compostas de valores, operadores, expressões, palavras-chave e comentários. Por exemplo, a declaração a seguir informa o navegador para escrever "Hello, Dolly." em um elemento HTML que contém a id "demo":

			
				document.getElementById("demo").innerHTML = "Hello Dolly.";

Um programa em JavaScript pode conter muitas declarações, e elas são executadas, uma por vez, na mesma ordem em que são escritas.

Separa-se declarações com ponto-e-vírgula (;):

			
				let a, b, c;  // Declarar 3 variáveis
				a = 5;        // Atribuir o valor 5 a a
				b = 6;        // Atribuir o valor 6 a b
				c = a + b;    // Atribuir a soma de a e b a c

O ponto-e-vírgula não é obrigatório, mas é uma prática recomendada.

Espaços em branco são ignorados, mas facilitam a leitura do código e também são considerados prática recomendada.

Outra prática recomendada é quebrar as linhas de código após aproximadamente 80 caracteres. Dê preferência para quebrar o código após os operadores.

Funções

As declarações JavaScript podem ser agrupadas em blocos de código, dentro de chaves ({ }). O propósito disso é definir declarações que devem ser executadas juntas. A essa prática dá-se o nome de função. Por exemplo:

			
				function minhaFuncao() {
					document.getElementById("demo1").innerHTML = "Hello Dolly!";
					document.getElementById("demo2").innerHTML = "Como vai?";
				}

Saiba mais sobre funções.

Palavras-chave

As declarações começam com uma palavra-chave que identifica a ação a ser executada pelo código JavaScript. Esta lista exibe todas as palavras que são "reservadas" por serem palavras-chave designadas e, portanto, não podem ser usadas como nomes de variáveis. Eis algumas delas:

Palavra-chave Descrição
var Declara uma variável
let Declara uma variável em bloco
const Declara uma constante em bloco
if Marca um bloco de declarações para ser executado de acordo com uma condição
switch Marca um bloco de declarações para ser executado em diferentes casos
for Marca um bloco de declarações para ser executado em loop
function Declara uma função
return Sai de uma função
try Implementa a manipulação de erros em um bloco de declarações

Sintaxe

A sintaxe do JavaScript define dois tipos de valores:

  • Valores fixos: são chamados de literais ou constantes.
  • Valores variáveis: são chamados de variáveis.

Literais ou constantes

As duas regras de sintaxe mais importantes para valores fixos são:

  1. Números são escritos com ou sem decimais: 10.50, 1001, 0... Aparecem SEMPRE fora de aspas.
  2. Sequências de caracteres (ou "strings") são texto, escritas SEMPRE com aspas duplas ou simples: "Hello World!", 'John Doe', "input-btn"... Um número entre aspas se transforma em uma string.

Variáveis

Em uma linguagem de programação, as variáveis são usadas para armazenar valores de dados. Em JavaScript, as variáveis usam as palavras-chave var (que só deve ser usada para código a ser executado em navegadores mais antigos), let ou const.

O sinal de igual (=) é usado para atribuir valores às variáveis.

No exemplo a seguir, x é uma variável que recebe o valor 6.

			
				let x;
				x = 6;

Deve-se declarar as variáveis antes de usá-las no código. E a prática recomendada é declarar todas as variáveis no início do script.

Após definir uma variável, se não for atribuído um valor a ela, ela é considerada undefined (indefinida).

Use const para declarar variáveis cujo valor ou tipo não serão alterados durante a execução do código. Use let somente se não puder usar const.

Uma declaração pode conter muitas variáveis, se separadas por uma vírgula: let person = "John Doe", carName = "Volvo", price = 200;. Ou podemos colocar cada item em uma linha:

			
				let person = "John Doe",
				carName = "Volvo",
				price = 200;

Em programas de computador, geralmente declaramos variáveis sem um valor. O valor pode ser calculado depois ou algo que será fornecido posteriormente, como digitação do usuário. Uma variável declarada sem valor terá o valor undefined.

Uma variável pode ser re-declarada usando a palavra-chave var, mas não as palavras-chave let e const. Por exemplo:

			
				var carName = "Volvo";
				var carName;

A variável acima ainda terá o valor "Volvo" após as declarações serem executadas.

Operadores

O JavaScript usa operadores matemáticos (+ - * /) para computar valores:

			
				(5 + 6) * 10

E o operador de atribuição, como vimos anteriormente, é o sinal de igual (=).

Expressões

Uma expressão combina valores, variáveis e operadores para calcular para uma avaliação. Por exemplo, 5*10 avalia para 50.

As expressões também podem conter variáveis: x*10.

Os valores podem ser números ou sequências de caracteres. Por exemplo, "John" + " " + "Doe" avalia para "John Doe".

Comentários

Nem todas as declarações do JavaScript são executadas. Códigos definidos após duas barras (//) ou entre os símbolos /* */ são considerados como comentários, e são ignorados.

Use comentários para explicar o código JavaScript e torná-lo mais fácil de ler. Ou para impedir a execução de determinada declaração ao depurar o código ou testar alternativas.

Use duas barras (//) para definir comentários até o final da linha atual. Use barra, asterisco (/* */) para comentários em mais de uma linha (um bloco de comentários).

Comentários em bloco geralmente são designados para documentações oficiais.

Nomes ou identificadores

Identificadores são nomes no JavaScript que identificam variáveis, palavras-chave e funções. As regras são as mesmas que em muitas outras linguagens de programação; o nome/identificador deve começar com:

  • Uma letra (A-Z ou a-z)
  • Um sinal de cifrão ($)
  • Um sublinhado (_)

Os caracteres seguintes podem ser letras, números, sublinhados ou cifrões.

O primeiro caractere de um nome/identificador não pode ser um número!

Todos os identificadores em JavaScript diferenciam maiúsculas de minúsculas. As variáveis lastName e lastname são diferentes. LET, Let e let são diferentes.

Diferentemente do HTML e do CSS, JavaScript não aceita hifens para separar os identificadores. Prefira usar camelCase ou sublinhados (snake_case).

Assim como o HTML, JavaScript usa UTF-8 como o conjunto de caracteres.

Todas as variáveis em JavaScript DEVEM ser identificadas com nomes exclusivos. Esses nomes podem ser curtos (como x ou y) ou mais descritivos (como fullName ou age). e não se esqueça que não se pode usar palavras reservadas.

Os sinais de igual (=), cifrão ($) e sublinhado (_)

Como já vimos, o sinal de igual (=) é um operador de atribuição. Ele atribui determinado valor a uma variável. Por exemplo, x = x + 5; faz total sentido em JavaScript, porque calcula o valor de x + 5 e atualiza o valor de x.

Para definir o "igual a" em JavaScript, use === (três sinais de igual em sequência).

Como o JavaScript trata o cifrão como uma letra, os identificadores que contêm o $ são nomes de variáveis válidos. Por exemplo:

			
				let $ = "Hello World";
				let $$$ = 2;
				let $meuDinheiro = 5;

Não é muito comum usar o cifrão em JavaScript, mas programadores profissionais geralmente o usam como um alias para a principal função em uma biblioteca JavaScript. Em jQuery, por exemplo, a função principal $ é usada para selecionar elementos HTML, isto é $("p") significa "selecione todos os elementos p".

Como o JavaScript trata o sublinhado como uma letra, os identificadores que contêm o _ são nomes de variáveis válidos. Por exemplo:

			
				let _lastName = "Johnson";
				let _x = 2;
				let _100 = 5;

Não é muito comum usar o sublinhado em JavaScript, mas programadores profissionais têm uma convenção de usá-lo como um alias para variáveis "privadas" (ou ocultas).

Aritmética

É possível fazer cálculos com variáveis no JavaScript usando os operadores + - / * % e =.

Se houver qualquer string no meio de um cálculo, toda a declaração será convertida para texto. Por exemplo, 5 + "10" se transforma em "510".
