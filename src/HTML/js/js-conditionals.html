Declarações condicionais

Ao escrever o código, geralmente queremos realizar diferentes ações para diferentes condições. As declarações condicionais executam um código diferente dependendo de uma condição ser verdadeira ou falsa. As declarações condicionais incluem:

  • if
  • if... else...
  • if... else... if... else...
  • switch
  • ternária (? :)

Quando devemos usar as condicionais?

  • Use if para definir um bloco de código a executar se determinada condição especificada for verdadeira
  • Use else para definir um bloco de código a executar se a mesma condição for falsa
  • Use else if para definir uma nova condição a testar se a primeira condição for falsa
  • Use switch para definir vários blocos de código alternativos a executar
  • Use (? :) (condicional ternária) como uma abreviação para if...else

if

Use if para especificar um bloco de código a executar se determinada condição for true.

Sintaxe

				
					if (condição) {
						// código a executar se a condição for verdadeira
					}

Note que usar if com letras maiúsculas (If, IF ou iF) gera um erro no JavaScript.

if aninhado

É possível usar uma declaração if dentro de outra:

					
						let idade = 16;
						let pais = "Brasil";
						let text = "Você NÃO pode votar!";

						if (pais == "Brasil") {
							if (idade >= 16) {
								text = "Você pode votar!";
							}
						}

Declarações if aninhadas podem tornar o código mais complexo. Uma solução melhor é usar o operador lógico AND: 

					
						let idade = 16;
						let pais = "Brasil";
						let text = "Você NÃO pode votar!";

						if (pais == "Brasil" && idade >= 16) {
							text = "Você pode votar!";
						}

else

Use else para especificar um bloco de código a executar se a mesma condição de if for false.

Sintaxe

				
					if (condição) {
						// código a executar se a condição for verdadeira
					}
					else {
						// código a executar se a condição for falsa
					}

else if

Use else if para especificar uma nova condição a testar se a condição for false.

Sintaxe

				
					if (condição1) {
						// código a executar se a condicional for verdadeira
					} else if (condição2) {
						// código a executar se a condicional for falsa e a condição2 for verdadeira
					} else {
						// código a executar se a condição1 for falsa e a condição2 for falsa
					}

Exemplo

Este exemplo usa um número aleatório para direcionar o usuário ao site da W3Schools ou da World Wildlife Foundation (WWF); cada opção tem 50% de chance de ser apresentado. 

				
					let text;
					if (Math.random() < 0.5) {
						text = "<a href='https://w3schools.com'>Visit W3Schools</a>";
					} else {
						text = "<a href='https://wwf.org'>Visit WWF</a>";
					}
					document.getElementById("demo").innerHTML = text;

switch

Use switch para especificar vários blocos de código alternativos a executar.

Com base em uma condição, o switch seleciona um ou mais blocos de código a executar. Ele executa os blocos de código que correspondem a uma expressão. Geralmente usamos o switch como uma alternativa mais fácil de ler em relação a várias declarações if...else if...else, especialmente ao lidar com vários valores possíveis.

Sintaxe

				
					switch(expressão) {
						case x:
							// bloco de código
							break;
						case y:
							// bloco de código
							break;
						default:
							// bloco de código
					}

Funciona assim:

  • A expressão do switch é avaliada uma vez.
  • O valor da expressão é comparado com os valores de cada caso.
  • Se há uma correspondência, o bloco de código associado é executado.
  • Se não há correspondência, nenhum código é executado.

Exemplo

O método getDay() retorna o dia da semana como um número entre 0 e 6: (domingo=0, segunda-feira=1, terça-feira=2, etc...). O exemplo abaixo usa o número para calcular o nome do dia da semana: 

				
					switch (new Date().getDay()) {
						case 0:
							dia = "domingo";
							break;
						case 1:
							dia = "segunda-feira";
							break;
						case 2:
							dia = "terça-feira";
							break;
						case 3:
							dia = "quarta-feira";
							break;
						case 4:
							dia = "quinta-feira";
							break;
						case 5:
							dia = "sexta-feira";
							break;
						case 6:
							dia = "sábado";
					}

break

Quando o JavaScript chega à palavra-chave break, ele "sai" do bloco switch; isso interrompe a execução dentro do bloco switch. Nenhuma outra declaração no bloco será executada.

Não é necessário inserir break no último caso, já que o switch termina ali de qualquer forma.

Note que a palavra-chave break é crucial para impedir que o código continue a ser executado nos próximos casos de blocos de código (e no bloco default, se houver), mesmo se seus valores não corresponderem à expressão.

default

A palavra-chave default especifica um bloco de código a executar se não houver correspondência com outros casos. Essa palavra-chave é opcional e pode ser uma alternativa se não houver um caso apresentado.

Exemplo: o método getDay() retorna o dia da semana como um número entre 0 e 6. Se hoje não for sábado (6), nem domingo (0), a mensagem padrão é exibida. 

				
					switch (new Date().getDay()) {
						case 6:
							text = "Hoje é sábado";
							break;
						case 0:
							text = "Hoje é domingo";
							break;
						default:
							text = "Espero que o fim de semana chegue logo";
					}

default não precisa ser a última opção no bloco de código, porém se não for, lembre-se de adicionar break abaixo do caso default: 

				
					switch (new Date().getDay()) {
						default:
							text = "Espero que o fim de semana chegue logo";
							break;
						case 6:
							text = "Hoje é sábado";
							break;
						case 0:
							text = "Hoje é domingo";
					}

Blocos de código comuns

Pode haver situações em que você quer que diferentes casos no switch usem o mesmo código. No exemplo abaixo, os casos 4 e 5 executam o mesmo código, assim como 0 e 6: 

				
					switch (new Date().getDay()) {
						case 4:
						case 5:
							text = "O fim de semana chega logo!";
							break;
						case 0:
						case 6:
							text = "É o fim de semana";
							break;
						default:
							text = "Espero que o fim de semana chegue logo";
					}

Se um valor corresponder a vários casos, o primeiro caso será selecionado. Se não houver correspondências, o programa continua até a etiqueta default. Se essa etiqueta não existir, o programa continua para a declaração após o switch.

Comparação rigorosa

O switch usa a comparação rigorosa (===), isto é os valores devem ter o mesmo tipo para serem uma correspondência. Esse tipo de comparação só pode ser verdadeira se ambos os operandos forem do mesmo tipo. Por exemplo, abaixo vemos que não há correspondência para x: 

				
					let x = "0";
					switch (x) {
						case 0:
							text = "Desligado";
							break;
						case 1:
							text = "Ligado";
							break;
						default:
							text = "Nenhum valor encontrado";
					}

Operador ternário (? :)

Use a condicional ternária (? :) como uma abreviação para if...else. Observe que a expressão1 no exemplo abaixo é a expressão verdadeira e a expressão2 é a expressão falsa.

Este operador tem o nome "ternário" por aceitar 3 (três) operandos e é o único operador no JavaScript que requer três operandos.

Sintaxe

				
					condição ? expressão1 : expressão2

Exemplos

				
					let text = (idade > 18) ? "Adulto" : "Menor de idade";

					let membro = true;
					let discount = membro ? 0.2 : 0;
Parâmetro Descrição
condição Obrigatório.
A condição a testar.
Uma expressão que avaliada como verdadeira ou falsa.
? Obrigatório.
O operador que separa a condição das expressões.
expressão1 Obrigatória.
O valor a retornar se a condição for verdadeira.
: Obrigatório.
O operador que separa as expressões.
expressão2 Obrigatório.
O valor a retornar se a condição for falsa.
