Eventos

Eventos em HTML são "coisas"" que acontecem com o HTML. Ao usar JavaScript em páginas HTML, ele pode "reagir"" a esses eventos.

Um evento pode ser algo que o navegador ou que o usuário faz. Eis alguns exemplos de eventos:

  • Uma página HTML termina de carregar
  • Uma alteração a um campo no HTML
  • Um clique em um botão no HTML

Geralmente, quando o evento ocorre, podemos querer fazer algo. O JavaScript nos permite executar código ao detectar um evento. O HTML aceita que atributos manipuladores de eventos, com código JavaScript, sejam adicionados aos elementos usando aspas simples ou duplas.

No exemplo a seguir, adicionamos o atributo onclick a um elemento <button>:

			
				<button onclick="document.getElementById('demo').innerHTML = Date()">The time is?</button>

Este código altera o conteúdo do elemento com a id="demo". No exemplo a seguir, o código altera o conteúdo em seu próprio elemento, usando self.innerHTML, e o resultado do clique aparece como o nome do botão.

			
				<button onclick="this.innerHTML = Date()">The time is?</button>

Note que um código JavaScript geralmente apresenta várias linhas e é comum ver os atributos de eventos chamando funções.

Eventos comuns no HTML

A lista a seguir apresenta alguns dos eventos de HTML mais comuns:

Evento Descrição
onchange Um elemento HTML sofre uma alteração
onclick O usuário clica em um elemento HTML
onmouseover O usuário passa o mouse sobre um elemento HTML
onmouseout O usuário tira o mouse de um elemento HTML
onkeydown O usuário pressiona uma tecla do teclado
onload O navegador termina de carregar a página

A lista é ainda mais longa, consulte a Referência sobre eventos JavaScript relacionados ao DOM no site da w3schools ou no MDN.

Manipuladores de eventos

Podem ser usados para manipular e verificar digitação do usuário, ações do usuário e ações do navegador:

  • Coisas que devem ser feitas sempre que a página carrega
  • Coisas que devem ser feitas ao fechar a página
  • Uma ação que deve ser executada quando um usuário clica em um botão
  • Conteúdo que deve ser verificado quando o usuário insere dados
  • E muito mais...

Podemos usar diversos métodos para que o JavaScript trate os eventos:

  • Os atributos do evento HTML podem executar diretamente o código JavaScript
  • Os atributos do evento HTML podem chamar funções JavaScript
  • Você pode atribuir suas próprias funções manipuladoras de eventos a elementos HTML
  • Você pode impedir que os eventos sejam enviados ou manipulados
  • E muito mais...
