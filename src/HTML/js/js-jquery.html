jQuery vs JavaScript

O jQuery foi criado em 2006 por John Resig. Seu propósito era lidar com incompatibilidades entre navegadores e simplificar a manipulação do DOM do HTML, o tratamento de eventos, animações e o Ajax.

Por mais de 10 anos, o jQuery foi a biblioteca JavaScript mais popular do mundo. Entretanto, após a versão 5 do JavaScript (2009), a maioria dos recursos do jQuery pode ser solucionada com algumas linhas de JavaScript padrão. Vejamos alguns exemplos.

Encontrar um elemento HTML pela id

Retornar o elemento com id="id01":

					
						// jQuery:
						myElement = $("#id01");

						// JavaScript:
						myElement = document.getElementById("id01");

Encontrar um elemento HTML pelo nome da tag

Retornar todos os elementos <p>:

					
						// jQuery:
						myElements = $("p");

						// JavaScript:
						myElements = document.getElementsByTagName("p");

Encontrar elementos HTML pelo nome da classe

Retornar todos os elementos class="intro":

					
						// jQuery:
						myElements = $(".intro");

						// JavaScript:
						myElements = document.getElementsByTagName("intro");

Encontrar elementos HTML pelo seletor CSS

Retornar todos os elementos <p> com class="intro": 

					
						// jQuery:
						myElements = $("p.intro");

						// JavaScript:
						myElements = document.getElementsByTagName("p.intro");

Definir o conteúdo do texto

					
						// jQuery:
						myElement.text("Hello Sweden!");

						// JavaScript:
						myElement.textContent = "Hello Sweden!";

Obter o conteúdo do texto

Obter o texto de um elemento HTML:

					
						// jQuery:
						myText = $("#02").text();

						// JavaScript:
						myText = document.getElementById("02").textContent;

Definir o conteúdo HTML de um elemento

					
						// jQuery:
						myElement.html("
Hello World
");

						// JavaScript:
						myElement.innerHTML = "
Hello World
";

Obter o conteúdo HTML de um elemento

					
						// jQuery:
						content = myElement.html();

						// JavaScript:
						content = myElement.innerHTML;

Estilos CSS com jQuery

Ocultar elementos HTML

						
							// jQuery:
							myElement.hide();

							// JavaScript:
							myElement.style.display = "none";

Exibir elementos HTML

						
							// jQuery:
							myElement.show();

							// JavaScript:
							myElement.style.display = "";

Estilizar elementos HTML

						
							// jQuery:
							$("#demo").css("font-size","35px");

							// JavaScript:
							document.getElementById("demo").style.fontSize = "35px";

Remover elementos HTML

					
						// jQuery:
						$("#id02").remove();

						// JavaScript:
						document.getElementById("id02").remove();

Obter o elemento pai

					
						// jQuery:
						myParent = $("#02").parent().prop("nodeName");

						// JavaScript:
						myParent = document.getElementById("02").parentNode.nodeName;
