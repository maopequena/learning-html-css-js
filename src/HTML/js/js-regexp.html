Expressões regulares

Uma expressão regular é uma sequência de caracteres que forma um padrão de pesquisa. Esse padrão pode ser usado para operações de pesquisa, substituição e validação de texto.

Ao pesquisar dados em um texto, podemos usar esse padrão de pesquisa para descrever o que estamos procurando. Uma expressão regular pode conter um único caractere ou um padrão mais complicado. A sintaxe é: 

			
				/padrão/modificadores;

Por exemplo:

			
				/w3schools/i;

Que significa:

  • w3schools é o padrão a ser pesquisado
  • i é o modificador, que neste caso significa que a pesquisa não deve fazer distinção entre maiúsculas e minúsculas

Métodos de sequências de caracteres

Geralmente usamos as expressões regulares com dois métodos de strings: search() e replace(). O primeiro método usa expressões regulares para pesquisar por uma correspondência, e retorna a posição dessa correspondência. O segundo método retorna uma cadeia de caracteres alterada pelo padrão pesquisado. Por exemplo: 

				
					// search() sem expressão regular:
					let text = "Visit W3Schools!";
					let n = text.search("W3Schools"); // 6

					// search() com expressão regular:
					let text = "Visit W3Schools";
					let n = text.search(/w3schools/i); // 6

					// replace() sem expressão regular:
					let text = "Visit Microsoft!";
					let n = text.replace("Microsoft", "W3School"); // Visit W3School!

					// replace() com expressão regular:
					let text = "Visit Microsoft!";
					let n = text.replace(/microsoft/i, "W3School"); // Visit W3School!

Modificadores

Modificador Descrição
i Não diferenciar maiúsculas e minúsculas
g Localizar tudo (pesquisa global)
u Habilita o suporte a Unicode

Padrões de expressões regulares

Use os colchetes para localizar um grupo de caracteres
Expressão Descrição
[abc] Localizar qualquer dos caracteres entre os colchetes
[0-9] Localizar qualquer dos dígitos entre os colchetes
(x|y) Localizar qualquer das alternativas separadas por |

Caracteres que têm um significado especial
Metacaractere Descrição
\d Localizar um dígito
\s Localizar um caractere de espaço em branco
\w Localizar uma palavra

Quantificadores definem quantidades
Quantificador Descrição
n+ Corresponde qualquer sequência de caracteres que contém ao menos um n
n* Corresponde qualquer sequência de caracteres que contém zero ou mais ocorrências de n
n? Corresponde qualquer sequência de caracteres que contém zero ou uma ocorrência de n

Uso do objeto RegExp

Este objeto tem propriedades e métodos predefinidos.

test()

Pesquisa por um padrão e retorna true ou false dependendo do resultado: 

				
					const padrao = /e/;
					padrao.test("As melhores coisas da vida são grátis!"); // retorna "true"

					OU

					/e/.test("As melhores coisas da vida são grátis!"); // retorna "true"

exec()

Pesquisa por um padrão e retorna o texto encontrado como um objeto. Se não houver correspondência, retorna um objeto vazio (null): 

				
					/e/.exec("The best things in life are free!"); // [
																														'e',
																														index: 2,
																														input: 'The best things in life are free!',
																														groups: undefined
																														]

Asserções

Asserções correspondem limites e ao redor:

  • Limites: de strings e de palavras
  • Ao redor: à frente e atrás

Essas são as mais comuns:

Sintaxe Nome Descrição
^ Limite de strings Corresponde o início de uma string
$ Limite de strings Corresponde o final de uma string
\b Limite de palavra Corresponde o início ou o final de uma palavra
(?=...) Ao redor: à frente Corresponde a próxima string
(?<=...) Ao redor: atrás Corresponde a string anterior
