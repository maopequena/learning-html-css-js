Módulos

Os módulos no JavaScript possibilitam "detalhar" o código em diferentes arquivos, o que simplifica sua manutenção. É possível importar módulos de arquivos externos com a palavra-chave import e, para usá-los no HTML, é preciso adicionar type="module" à tag <script>. Por exemplo:

			
				<script type="module">
					import messidade from "./messidade.js";
				</script>

É possível também armazenar módulos com funções e variáveis em um arquivo externo. Para isso, há dois tipos de exportação: exportação nomeada e exportação padrão.

Exportação nomeada

Vamos criar um arquivo chamado pessoa.js e preenchê-lo com o que desejamos exportar. Para exportar algo, é preciso usar a palavra-chave export e há duas formas de exportar: linha a linha ou em um bloco no final do arquivo.

				
					pessoa.js

					// Exportar linha a linha:
					export const nome = "Jesse";
					export const idade = 40;

					// Exportar em um bloco:
					const nome = "Jesse";
					const idade = 40;
					
					export { nome, idade };

Exportação padrão

Agora vamos criar outro arquivo, mensagem.js, para demonstrar a exportação padrão. Só pode haver uma exportação padrão por arquivo.

				
					mensagem.js

					const mensagem = () => {
					const nome = "Jesse";
					const idade = 40;
					return nome + ' tem ' + idade + 'anos.';
					};
					
					export default mensagem;

Para importar módulos externos, é preciso usar a palavra-chave import e deve-se levar em conta o tipo de exportação: para importar exportações nomeadas, usa-se chaves, mas não para exportações padrão.

			
				import { nome, idade } from "./pessoa.js";

				import mensagem from "./mensagem.js";

Observação: os módulos só funcionam com o protocolo HTTP(s). Uma página que usa o protocolo file:// não consegue usar a importação/exportação.
