Controle de fluxo em JavaScript

Controle de fluxo é a ordem em que as declarações são executadas em um programa. Por padrão, o JavaScript executa o código de cima para baixo e da esquerda para a direita. Declarações com controle de fluxo possibilitam alterar essa ordem, com base em condições, loops ou palavras-chave.

Controle de fluxo condicional

Podemos alterar o fluxo usando condicionais, como if, else ou switch. Por exemplo: 

				
					let idade = 18;
					let texto = "Desconhecido";

					if (idade <== 18) {
						texto = "Adulto";
					} else {
						texto = "Menor de idade";
					}

Controle de fluxo de repetição

Podemos alterar o fluxo usando loops, como for, while e do/while. Por exemplo: 

				
					for (let i = 0; i < 5; i++) {
						texto += "O número é " + i + "
";
					}

Declarações de quebra

As declarações de quebra, como break, continue, return e throw também alteram o fluxo: 

				
					for (let i = 0; i < 10; i++) {
						if (i === 3) { break; }
						texto += "O número é " + i + "
";
					}

Controle de fluxo com funções

Podemos alterar o fluxo usando funções. Por exemplo: 

				
					function myFunction(p1, p2) {
						return p1 * p2;
					}

Fluxo assíncrono

Podemos alterar o fluxo usando Callbacks (retornos de chamada), Promises (promessas) e async/await (assincronia/espera) em eventos e chamadas de rede. Por exemplo: 

				
					async function fetchData() {
					let dados = await fetch("https://api.example.com/data");
					// código a executar
				}

Blocos de código

Um bloco de código, ou bloco de declaração, é um grupo de declarações entre chaves ({ }). Eles são importantes para controlar o fluxo de execução do código e definir o escopo de variáveis em um programa JavaScript.

O corpo de uma função JavaScript sempre contém um bloco de código. Eles são essenciais para declarações if e para outros loops.

Lembre-se que variáveis dentro de um bloco de código têm um escopo local.

Como blocos de código separam o escopo, eles mantêm o código organizado e limpo, gerando variáveis que podem ser de uso temporário e depois descartadas.
