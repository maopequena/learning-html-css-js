Retornos de chamada

Um retorno de chamada é uma função passada a outra função como um argumento. Essa técnica possibilita que uma função chame outra. Uma função de retorno de chamada pode ser executada após o término de outra função.

Sequência de funções

As funções do JavaScript são executadas na sequência em que são chamadas, não na sequência em que são definidas. Os exemplos a seguir exibem "Até logo" primeiro e depois "Olá": 

				
					function primeiraFuncao() {
						funcaoExibidora("Olá");
					}
					
					function segundaFuncao() {
						funcaoExibidora("Até logo");
					}
					
					// Exemplo 1:
					primeiraFuncao();
					segundaFuncao();

					// Exemplo 2:
					segundaFuncao();
					primeiraFuncao();

Como controlar a sequência

Algumas vezes é preciso ter melhor controle de quando executar uma função.

Suponhamos que queremos fazer um cálculo e, depois, exibir o resultado. Poderíamos chamar uma função que faz o cálculo (minhaCalculadora), salvar o resultado e, então, chamar outra função (funcaoExibidora) para mostrar o resultado: 

					
						function funcaoExibidora(some) {
							document.getElementById("demo").innerHTML = some;
						}
						
						function minhaCalculadora(num1, num2) {
							let soma = num1 + num2;
							return soma;
						}
						
						let resultado = minhaCalculadora(5, 5);
						funcaoExibidora(resultado);

O problema do exemplo acima é que precisamos chamar duas funções para exibir o resultado.

Outra opção é chamar a função que faz o cálculo (minhaCalculadora) e deixr que ela chame a funão de exibição (funcaoExibidora): 

					
						function funcaoExibidora(some) {
							document.getElementById("demo").innerHTML = some;
						}
						
						function minhaCalculadora(num1, num2) {
							let soma = num1 + num2;
							funcaoExibidora(soma);
						}
						
						minhaCalculadora(5, 5);

O problema com esta segunda abordagem é que não podemos impedir a função que faz o cálculo de exibir o resultado. Assim, a solução é usar um retorno de chamada.

Com ele, podemos chamar a função de cálculo (minhaCalculadora) com um retorno (meuRetorno) e deixar que a primeira execute o retorno após finalizar o cálculo: 

					
						function funcaoExibidora(some) {
							document.getElementById("demo").innerHTML = some;
						}
						
						function minhaCalculadora(num1, num2, meuRetorno) {
							let soma = num1 + num2;
							meuRetorno(soma);
						}
						
						minhaCalculadora(5, 5, funcaoExibidora);

Neste exemplo, funcaoExibidora é uma função de retorno de chamada, que é passada como argumento para minhaCalculadora. Note que ao passar uma função como argumento não se deve usar parênteses: minhaCalculadora(5, 5, funcaoExibidora) e não minhaCalculadora(5, 5, funcaoExibidora()).

Os retornos de chamada são muito usados em funções assíncronas, em que uma função precisa esperar por outra.

JavaScript assíncrono

Funções executadas em paralelo com outras funções são chamadas de assíncronas. Um bom exemplo é a setTimeout(), com a qual podemos definir um período de tempo de pausa até a execução de uma função: 

			
				setTimeout(minhaFuncao, 3000); // 3000 é a quantidade de milissegundos, isto é, 3 segundos

				function minhaFuncao() {
					document.getElementById("demo").innerHTML = "Eu te amo!!";
				}

E, além de passar o nome de uma função como argumento, podemos passar uma função completa: 

			
				setTimeout(function() { minhaFuncao("Eu te amo!!!"); }, 3000);

				function minhaFuncao(value) {
					document.getElementById("demo").innerHTML = value;
				}

Com a função setInterval(), podemos definir que uma função de retorno seja executada em intervalos regulares: 

			
				setInterval(minhaFuncao, 1000);

				function minhaFuncao() {
					let d = new Date();
					document.getElementById("demo").innerHTML=
					d.getHours() + ":" +
					d.getMinutes() + ":" +
					d.getSeconds();
				}

Alternativas

Com a programação assíncrona, programas em JavaScript podem iniciar tarefas que demoram a executar e continuar executando outras tarefas em paralelo. Porém, programas assíncronos são difíceis de escrever e de depurar. Por causa disso, a maioria dos método de JavaScript assíncronos não usam retorno de chamada, mas sim promessas.

Promessas

O "código em produção" pode demorar um pouco para executar, o "código em consumo" deve esperar por um resultado. Uma promessa é um objeto que vincula os códigos em produção e em consumo.

Uma promessa contém o código em produção e chamadas para o código em consumo: 

			
				let minhaPromessa = new Promise(function(minhaSolucao, minhaRejeicao) {
				// "Código em produção" (pode demorar a executar)
				
					minhaSolucao(); // quando bem sucedido
					minhaRejeicao();  // quando houver erro
				});
				
				// "Código em consumo" (deve esperar que uma promessa seja resolvida)
				minhaPromessa.then(
					function(valor) { /* código se bem sucedido */ },
					function(erro) { /* código se houver erro */ }
				);

Quando o código em produção receber o resultado, deve chamar uma das funções de retorno:

Quando isto ocorrer Chamar
Sucesso minhaSolucao (valor do resultado)
Erro minhaRejeicao (objeto de erro)

Propriedades do objeto de promessa

Um objeto Promise do JavaScript pode estar:

  • Pendente (pending)
  • Concluído (fulfilled)
  • Rejeitado (rejected)

O objeto Promise aceita duas propriedades: state e result.

Quando um objeto Promise está "pendente" (em execução), o resultado é indefinido; quando é "concluído", o resultado é um valor; e quando é "rejeitado", é um objeto de erro.

minhaPromessa.state minhaPromessa.result
"pendente" indefinido
"concluído" um valor com o resultado
"rejeitado" um objeto de erro

Note que não é possível acessar as propriedades state e result de uma promessa. É preciso usar métodos para manipular promessas.

Sintaxe de uma promessa

				
					minhaPromessa.then(
					function(valor) { /* código se bem sucedido */ },
					function(erro) { /* código se houver erro */ }
					);

Promise.then() recebe dois argumentos: um retorno de chamada para o sucesso e outro para a falha. Ambos são opcionais, então é possível incluir um retorno de chamada apenas para o sucesso, ou para a falha.

Exemplos

1. OK ou Erro

				
					function funcaoExibidora(some) {
						document.getElementById("demo").innerHTML = some;
					}
					
					let minhaPromessa = new Promise(function(minhaSolucao, minhaRejeicao) {
						let x = 0;
					
					// O código em produção (que pode demorar)
					
						if (x == 0) {
							minhaSolucao("OK");
						} else {
							minhaRejeicao("Erro");
						}
					});
					
					minhaPromessa.then(
						function(value) {funcaoExibidora(value);},
						function(error) {funcaoExibidora(error);}
					);

2. Exibir depois de 3 segundos

Com retorno de chamada

				
					setTimeout(function() { minhaFuncao("Eu te amo!!!"); }, 3000);

					function minhaFuncao(value) {
						document.getElementById("demo").innerHTML = value;
					}

Com promessa

				
					let minhaPromessa = new Promise(function(minhaSolucao, minhaRejeicao) {
						setTimeout(function() { minhaSolucao("Eu te amo!!!"); }, 3000);
					});
					
					minhaPromessa.then(function(value) {
						document.getElementById("demo").innerHTML = value;
					});

3. Aguardar um arquivo

Com retorno de chamada

				
					function obterArquivo(meuRetorno) {
						let req = new XMLHttpRequest();
						req.open('GET', "meucarro.html");
						req.onload = function() {
							if (req.status == 200) {
								meuRetorno(req.textoResposta);
							} else {
								meuRetorno("Erro: " + req.status);
							}
						}
						req.send();
					}
					
					obterArquivo(funcaoExibidora);

Com promessa

				
					let minhaPromessa = new Promise(function(minhaSolucao, minhaRejeicao) {
						let req = new XMLHttpRequest();
						req.open('GET', "meucarro.html");
						req.onload = function() {
							if (req.status == 200) {
								minhaSolucao(req.response);
							} else {
								minhaRejeicao("Arquivo não encontrado");
							}
						};
						req.send();
					});
					
					minhaPromessa.then(
						function(value) {myDisplayer(value);},
						function(error) {myDisplayer(error);}
					);

Assincronia

As palavras-chave async e await facilitam a escrita do código. async faz uma função retornar uma promessa, await faz uma função esperar uma promessa.

Sintaxe de async

Usar a palavra-chave async antes de uma função, faz ela retornar uma promessa: 

				
					async function minhaFuncao() {
						return "Olá";
					}

					// É o mesmo que:

					function minhaFuncao() {
						return Promise.resolve("Olá");
					}

Agora vamos usar a promessa:

				
					async function minhaFuncao() {
						return "Olá";
					}
					minhaFuncao().then(
						function(value) {myDisplayer(value);},
						function(error) {myDisplayer(error);}
					);

					// Ou, uma forma mais simples, já que não esperamos receber um erro:

					async function minhaFuncao() {
						return "Olá";
					}
					minhaFuncao().then(
						function(value) {myDisplayer(value);}
					);

Sintaxe de await

A palavra-chave await só pode ser usada dentro de uma função assíncrona, e faz com que a função pause a execução e espere por uma promessa com um resultado antes de continuar: 

				
					let value = await promise;

Exemplo

Vamos aprender como usar async e await devagar: 

				
					async function funcaoExibidora() {
						let minhaPromessa = new Promise(function(resolve, reject) {
							resolve("Eu te amo!!");
						});
						document.getElementById("demo").innerHTML = await minhaPromessa;
					}
					
					funcaoExibidora();

Os dois argumentos (resolve e reject) são pré-definidos pelo JavaScript. Não os criaremos, mas chamaremos um deles quando a função executadora estiver pronta. E, na maioria das vezes, não precisaremos de uma função reject. Então agora, vejamos como fica sem o reject: 

				
					async function funcaoExibidora() {
						let minhaPromessa = new Promise(function(resolve) {
							resolve("Eu te amo!!");
						});
						document.getElementById("demo").innerHTML = await minhaPromessa;
					}
					
					funcaoExibidora();

E vamos adicionar um período de espera:

				
					async function funcaoExibidora() {
						let minhaPromessa = new Promise(function(resolve) {
							setTimeout(function() {resolve("Eu te amo!!");}, 3000);
						});
						document.getElementById("demo").innerHTML = await minhaPromessa;
					}
					
					funcaoExibidora();

Agora vamos solicitar um arquivo:

				
					async function obterArquivo() {
						let minhaPromessa = new Promise(function(resolve) {
							let req = new XMLHttpRequest();
							req.open('GET', "meucarro.html");
							req.onload = function() {
								if (req.status == 200) {
									resolve(req.response);
								} else {
									resolve("Arquivo não encontrado");
								}
							};
							req.send();
						});
						document.getElementById("demo").innerHTML = await minhaPromessa;
					}
					
					obterArquivo();
