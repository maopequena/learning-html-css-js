Retornos de chamada

Um retorno de chamada é uma função passada a outra função como um argumento. Essa técnica possibilita que uma função chame outra. Uma função de retorno de chamada pode ser executada após o término de outra função.

Sequência de funções

As funções do JavaScript são executadas na sequência em que são chamadas, não na sequência em que são definidas. Os exemplos a seguir exibem "Até logo" primeiro e depois "Olá":

				
					function primeiraFuncao() {
						funcaoExibidora("Olá");
					}
					
					function segundaFuncao() {
						funcaoExibidora("Até logo");
					}
					
					// Exemplo 1:
					primeiraFuncao();
					segundaFuncao();

					// Exemplo 2:
					segundaFuncao();
					primeiraFuncao();

Como controlar a sequência

Algumas vezes é preciso ter melhor controle de quando executar uma função.

Suponhamos que queremos fazer um cálculo e, depois, exibir o resultado. Poderíamos chamar uma função que faz o cálculo (minhaCalculadora), salvar o resultado e, então, chamar outra função (funcaoExibidora) para mostrar o resultado:

					
						function funcaoExibidora(some) {
							document.getElementById("demo").innerHTML = some;
						}
						
						function minhaCalculadora(num1, num2) {
							let soma = num1 + num2;
							return soma;
						}
						
						let resultado = minhaCalculadora(5, 5);
						funcaoExibidora(resultado);

O problema do exemplo acima é que precisamos chamar duas funções para exibir o resultado.

Outra opção é chamar a função que faz o cálculo (minhaCalculadora) e deixr que ela chame a funão de exibição (funcaoExibidora):

					
						function funcaoExibidora(some) {
							document.getElementById("demo").innerHTML = some;
						}
						
						function minhaCalculadora(num1, num2) {
							let soma = num1 + num2;
							funcaoExibidora(soma);
						}
						
						minhaCalculadora(5, 5);

O problema com esta segunda abordagem é que não podemos impedir a função que faz o cálculo de exibir o resultado. Assim, a solução é usar um retorno de chamada.

Com ele, podemos chamar a função de cálculo (minhaCalculadora) com um retorno (meuRetorno) e deixar que a primeira execute o retorno após finalizar o cálculo:

					
						function funcaoExibidora(some) {
							document.getElementById("demo").innerHTML = some;
						}
						
						function minhaCalculadora(num1, num2, meuRetorno) {
							let soma = num1 + num2;
							meuRetorno(soma);
						}
						
						minhaCalculadora(5, 5, funcaoExibidora);

Neste exemplo, funcaoExibidora é uma função de retorno de chamada, que é passada como argumento para minhaCalculadora. Note que ao passar uma função como argumento não se deve usar parênteses: minhaCalculadora(5, 5, funcaoExibidora) e não minhaCalculadora(5, 5, funcaoExibidora()).

Os retornos de chamada são muito usados em funções assíncronas, em que uma função precisa esperar por outra.

JavaScript assíncrono

Funções executadas em paralelo com outras funções são chamadas de assíncronas. Um bom exemplo é a setTimeout(), com a qual podemos definir um período de tempo de pausa até a execução de uma função:

			
				setTimeout(minhaFuncao, 3000); // 3000 é a quantidade de milissegundos, isto é, 3 segundos

				function minhaFuncao() {
					document.getElementById("demo").innerHTML = "Eu te amo!!";
				}

E, além de passar o nome de uma função como argumento, podemos passar uma função completa:

			
				setTimeout(function() { minhaFuncao("Eu te amo!!!"); }, 3000);

				function minhaFuncao(value) {
					document.getElementById("demo").innerHTML = value;
				}

Com a função setInterval(), podemos definir que uma função de retorno seja executada em intervalos regulares:

			
				setInterval(minhaFuncao, 1000);

				function minhaFuncao() {
					let d = new Date();
					document.getElementById("demo").innerHTML=
					d.getHours() + ":" +
					d.getMinutes() + ":" +
					d.getSeconds();
				}

Alternativas

Com a programação assíncrona, programas em JavaScript podem iniciar tarefas que demoram a executar e continuar executando outras tarefas em paralelo. Porém, programas assíncronos são difíceis de escrever e de depurar. Por causa disso, a maioria dos método de JavaScript assíncronos não usam retorno de chamada, mas sim promessas.
