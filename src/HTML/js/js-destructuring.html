Desestruturação

A desestruturação "desempacota" as propriedades de um objeto em variáveis. Também pode ser usado para desestruturações de matrizes e quaisquer outros objetos iteráveis. Sua sintaxe é a seguinte:

			
				let {primeiroNome, sobrenome, idade} = pessoa;

				let [primeiroNome, sobrenome, idade] = pessoa;

A desestruturação não destrói e não altera o objeto original.

Note que a ordem das propriedades não importa:

			
				let {sobrenome, primeiroNome, idade} = pessoa;

				let [idade, sobrenome, primeiroNome] = pessoa;

Propriedades ausentes podem receber um valor padrão diretamente na desestruturação:

			
				// Criar o objeto
				const pessoa = {
					primeiroNome: "John",
					sobrenome: "Doe",
					idade: 50
				};

				// Desestruturar
				let {primeiroNome, sobrenome, pais = "Brasil"} = pessoa;

Também é possível usar alias para as propriedades:

			
				// Criar o objeto
				const pessoa = {
					primeiroNome: "John",
					sobrenome: "Doe",
					idade: 50
				};

				// Destructuring
				let {sobrenome : nome} = pessoa;

Trocar variáveis

Usando a desestruturação, é possível trocar variáveis no JavaScript:

				
					let primeiroNome = "John";
					let sobrenome = "Doe";

					// Desestruturação
					[primeiroNome, sobrenome] = [sobrenome, primeiroNome];

Sequências de caracteres

Outro uso para a desestruturação é "desempacotar" caracteres de uma string:

				
					// Criar uma string
					let nome = "W3Schools";

					// Desestruturação
					let [a1, a2, a3, a4, a5] = nome;

Matrizes

Podemos coletar variáveis de matrizes usando a desestruturação:

				
					// Criar uma matriz
					const frutas = ["Bananas", "Laranjas", "Maçãs", "Mangas"];

					// Desestruturação
					let [fruta1, fruta2] = frutas;

Podemos também pular os elementos da matriz usando uma ou mais vírgulas:

				
					// Criar uma matriz
					const frutas = ["Bananas", "Laranjas", "Maçãs", "Mangas"];

					// Desestruturação
					let [fruta1,,,fruta2] = frutas;

Também é possível coletar valores de índices específicos da matriz:

				
					// Criar a matriz
					const frutas = ["Bananas", "Laranjas", "Maçãs", "Mangas"];
					
					// Desestruturação
					let {[0]:fruta1, [1]:fruta2} = frutas;

Mapas

				
					// Criar o mapa
					const frutas = new Map([
						["macas", 500],
						["bananas", 300],
						["laranjas", 200]
					]);

					// Desestruturação
					let texto = "";

A propriedade rest

Podemos usar a palavra-chave ...rest no final da sintaxe de desestruturação. Isso faz com que os valores restantes sejam armazenados na nova matriz:

				
					// Criar a matriz
					const numeros = [10, 20, 30, 40, 50, 60, 70];

					// Desestruturação
					const [a,b, ...rest] = numeros;
