JSON

JSON (JavaScript Object Notation) é um formato de intercâmbio de dados leve que permite armazenar e transmitir dados estruturados. Geralmente é usado para transferir dados de um servidor para uma página da Web. O JSON funciona com qualquer linguagem de programação1, é auto-descritivo2 e fácil de usar.

Como o formato do JSON é idêntico ao código para criar objetos do JavaScript, qualquer programa JavaScript pode facilmente converter dados JSON em objetos JavaScript nativos.

1 A sintaxe do JSON vem da sintaxe de notação de objeto do JavaScript, mas seu formato é apenas texto. O código para ler e gerar dados JSON pode ser escrito em qualquer linguagem de programação.

2 Isto é, explica a si mesmo.

Exemplo

				
					{
					"funcionarios":[
						{"primeiroNome":"John", "sobrenome":"Doe"},
						{"primeiroNome":"Anna", "sobrenome":"Smith"},
						{"primeiroNome":"Peter", "sobrenome":"Jones"}
					]
					}

Regras de sintaxe do JSON

  • Os dados devem ter pares de nome/valor
  • Os dados devem ser separados por vírgulas
  • Chaves armazenam objetos
  • Colchetes armazenam matrizes

Pares de nome/valor

Um par de nome/valor consiste de um nome de campo (entre aspas duplas), seguido de dois-pontos e seguido do valor. LEMBRE-SE: os nomes no JSON REQUEREM aspas duplas, mas não no JavaScript.

					
						"primeiroNome":"John"

Objetos

Assim como no JavaScript, objetos são escritos com chaves e podem conter vários pares de nome/valor:

					
						{"primeiroNome":"John", "sobrenome":"Doe"}

Matrizes

Assim como no JavaScript, matrizes são escritas com colchetes e podem conter objetos:

					
						"funcionarios":[
							{"primeiroNome":"John", "sobrenome":"Doe"},
							{"primeiroNome":"Anna", "sobrenome":"Smith"},
							{"primeiroNome":"Peter", "sobrenome":"Jones"}
						]

Como converter o texto JSON em um objeto JavaScript

Um uso comum para o JSON é ler dados de um servidor e exibi-los em uma página da Web. Para simplificar, podemos demonstrar isso usando uma cadeia de caracteres.

Primeiro, vamos criar uma cadeia de caracteres com a sintaxe do JSON:

			
				let texto = '{ "funcionarios" : [' +
					'{ "primeiroNome":"John" , "sobrenome":"Doe" },' +
					'{ "primeiroNome":"Anna" , "sobrenome":"Smith" },' +
					'{ "primeiroNome":"Peter" , "sobrenome":"Jones" } ]}';

Em seguida, usamos a função JSON.parse() do JavaScript para converter essa cadeia de caracteres em um objeto do JavaScript:

			
				const obj = JSON.parse(texto);

Por fim, usamos o novo objeto na página:

			
				<p id="demo"></p>

				<script>
				document.getElementById("demo").innerHTML =
				obj.funcionarios[1].primeiroNome + " " + obj.funcionarios[1].sobrenome;
				</script>
