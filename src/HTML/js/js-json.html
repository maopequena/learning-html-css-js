JSON

JSON (JavaScript Object Notation) é um formato de troca de dados leve que permite armazenar e transmitir dados estruturados. Geralmente é usado para transferir dados de um servidor para uma página da Web. O JSON funciona com qualquer linguagem de programação1, é auto-descritivo2 e fácil de usar.

Como o formato do JSON é idêntico ao código para criar objetos do JavaScript, qualquer programa JavaScript pode facilmente converter dados JSON em objetos JavaScript nativos.

1 A sintaxe do JSON vem da sintaxe de notação de objeto do JavaScript, mas seu formato é apenas texto. O código para ler e gerar dados JSON pode ser escrito em qualquer linguagem de programação.

2 Isto é, explica a si mesmo.

Exemplo

				
					{
					"funcionarios":[
						{"primeiroNome":"John", "sobrenome":"Doe"},
						{"primeiroNome":"Anna", "sobrenome":"Smith"},
						{"primeiroNome":"Peter", "sobrenome":"Jones"}
					]
					}

Regras de sintaxe do JSON

  • Os dados devem ter pares de nome/valor
  • Os dados devem ser separados por vírgulas
  • Chaves armazenam objetos
  • Colchetes armazenam matrizes

Pares de nome/valor

Um par de nome/valor consiste de um nome de campo (entre aspas duplas), seguido de dois-pontos e seguido do valor, também entre aspas duplas. LEMBRE-SE: os nomes no JSON REQUEREM aspas duplas, mas não no JavaScript. 

					
						"primeiroNome":"John"

Objetos

Assim como no JavaScript, objetos são escritos com chaves e podem conter vários pares de nome/valor: 

					
						{"primeiroNome":"John", "sobrenome":"Doe"}

Matrizes

Assim como no JavaScript, matrizes são escritas com colchetes e podem conter objetos: 

					
						"funcionarios":[
							{"primeiroNome":"John", "sobrenome":"Doe"},
							{"primeiroNome":"Anna", "sobrenome":"Smith"},
							{"primeiroNome":"Peter", "sobrenome":"Jones"}
						]

O tipo de arquivo JSON deve ser .json, o tipo MIME para texto JSON é application/json.

Como converter o texto JSON em um objeto JavaScript

Um uso comum para o JSON é ler dados de um servidor e exibi-los em uma página da Web. Para simplificar, podemos demonstrar isso usando uma cadeia de caracteres.

Primeiro, vamos criar uma cadeia de caracteres com a sintaxe do JSON: 

			
				let texto = '{ "funcionarios" : [' +
					'{ "primeiroNome":"John" , "sobrenome":"Doe" },' +
					'{ "primeiroNome":"Anna" , "sobrenome":"Smith" },' +
					'{ "primeiroNome":"Peter" , "sobrenome":"Jones" } + ]}'';

Em seguida, usamos a função JSON.parse() do JavaScript para converter essa cadeia de caracteres em um objeto do JavaScript: 

			
				const obj = JSON.parse(texto);

Por fim, usamos o novo objeto na página:

			
				<p id="demo"></p>

				<script>
				document.getElementById("demo").innerHTML =
				obj.funcionarios[1].primeiroNome + " " + obj.funcionarios[1].sobrenome;
				</script>

Também é possível converter um objeto JavaScript em um texto JSON usando a função JSON.stringify(). 

			
				const obj = {
					"funcionarios":[
					{"primeiroNome":"John", "sobrenome":"Doe"},
					{"primeiroNome":"Anna", "sobrenome":"Smith"},
					{"primeiroNome":"Peter", "sobrenome":"Jones"}
					]
				};

				const meuJSON = JSON.stringify(obj);

Com JSON, é possível receber texto puro de um servidor e usá-lo como um objeto JavaScript. É possível enviar um objeto JavaScript para um servidor em formato de texto puro. E é possível trabalhar com dados como objetos JavaScript, sem necessidade de análises ou traduções complicadas.

Não é preciso armazenar dados em um formato específico e, independentemente de onde serão armazenados, o texto é sempre um formato permitido. O JSON permite isso!

JSON vs XML

Podemos usar ambos para receber e enviar dados de um servidor, mas o JSON é mais usado. Compare os dois exemplos abaixo, um em JSON e outro em XML. Ambos apresentam uma matriz com três funcionários: 

			
				EXEMPLO JSON:

				{"funcionarios":[
					{ "primeiroNome":"John", "sobrenome":"Doe" },
					{ "primeiroNome":"Anna", "sobrenome":"Smith" },
					{ "primeiroNome":"Peter", "sobrenome":"Jones" }
				]}

				EXEMPLO XML:

				<funcionarios>
				<funcionario>
					<primeiroNome>John</primeiroNome>
					<sobrenome>Doe</sobrenome>
				</employee>
				<employee>
					<primeiroNome>Anna</primeiroNome>
					<sobrenome>Smith</sobrenome>
				</employee>
				<employee>
					<primeiroNome>Peter</primeiroNome>
					<sobrenome>Jones</sobrenome>
				</funcionario>
			</funcionarios>

JSON é similar a XML porque:

  • Ambos são auto-descritivos (fácil de ler para humanos)
  • Ambos são hierárquicos (valores estão dentro de valores)
  • Ambos podem ser lidos e usados por várias linguagens de programação
  • Ambos podem ser solicitados com XMLHttpRequest

JSON é diferente de XML porque:

  • O JSON não tem tags de fechamento
  • O JSON é mais curto
  • O JSON é mais rápido para ler e escrever
  • O JSON pode usar matrizes

Porém, a principal diferença entre eles é que o XML precisa de um leitor específico, enquanto o JSON pode ser lido por uma função JavaScript padrão.

No caso de aplicativos AJAX, é mais fácil e rápido usar JSON do que XML:

Com XML:

  • Solicitar um documento XML
  • Usado o DOM do XML para iterar pelo documento
  • Extrair valores e armazená-los em variáveis

Com JSON:

  • Solicitar uma string JSON
  • Usar JSON.parse() na string

Tipos de dados válidos no JSON

Os tipos de dados válidos no JSON incluem: strings, números, booleanos, nulos, matrizes e objetos. Note que não é possível usar funções, datas e undefined.

Exemplos

Strings

{"nome":"John"}

Números

{"idade":30}

Objetos


{
"funcionario":{"nome":"John", "idade":30, "cidade":"Nova York"}
}

Matrizes


{
"funcionarios":["John", "Anna", "Peter"]
}

Booleanos

{"venda":true}

Nulos

{"nomeDoMeio":null}

Como converter datas e funções em JSON

Um uso comum para o JSON é trocar dados de/para um servidor da Web. Ao receber dados de um servidor, eles serão sempre strings, ou cadeias de caracteres. Analise os dados com JSON.parse() e eles se tornarão um objeto JavaScript.

Exemplo

Recebemos o seguinte de um servidor:

					
						'{"nome":"John", "idade":30, "cidade":"Nova York"}'

Use a função JSON.parse():

				
					const obj = JSON.parse('{"nome":"John", "idade":30, "cidade":"Nova York"}');

Depois é só usar o objeto no JavaScript:

				
					<p id="demo"></p>

					<script>
					document.getElementById("demo").innerHTML = obj.nome;
					</script>

Matrizes

Note que ao usar JSON.parse() em uma matriz, o método retorna uma matriz e não um objeto: 

				
					const text = '["Ford", "BMW", "Audi", "Fiat"]';
					const meuArr = JSON.parse(text);

Exceções

Análise de datas

Objetos de data não são permitidos no JSON. Se precisar incluir uma data, escreva-a como uma cadeia de caracteres e, depois, converta-a de volta para um objeto de data: 

				
					const texto = '{"nome":"John", "dataNascimento":"1986-12-14", "cidade":"Nova York"}';
					const obj = JSON.parse(texto);
					obj.dataNascimento = new Date(obj.dataNascimento);

					document.getElementById("demo").innerHTML = obj.nome + ", " + obj.dataNascimento;

Ou use o segundo parâmetro de JSON.parse(): o reviver, que verifica cada propriedade antes de retornar o valor. 

				
					const texto = '{"nome":"John", "dataNascimento":"1986-12-14", "cidade":"Nova York"}';
					const obj = JSON.parse(texto, function (key, value) {
						if (key == "dataNascimento") {
							return new Date(value);
						} else {
							return value;
						}
					});

					document.getElementById("demo").innerHTML = obj.nome + ", " + obj.dataNascimento;

Análise de funções

Funções não são permitidas no JSON. Se precisar incluir uma função, escreva-a como uma cadeia de caracteres e depois converta-a de volta para uma função: 

				
					const texto = '{"nome":"John", "idade":"function () {return 30;}", "cidade":"Nova York"}';
					const obj = JSON.parse(texto);
					obj.idade = eval("(" + obj.idade + ")");

					document.getElementById("demo").innerHTML = obj.nome + ", " + obj.idade();

Evite usar funções no JSON, já que elas podem perder o escopo e é preciso usar eval() para executá-las.

JSON.stringify()

Objeto

Imagine que temos o seguinte objeto no JavaScript:

				
					const obj = {nome: "John", idade: 30, cidade: "Nova York"};

Vamos usar a função JSON.stringify para convertê-lo:

				
					const meuJSON = JSON.stringify(obj);

O resultado será uma cadeia de caracteres com a notação JSON, que já pode ser enviado para um servidor:

				
					{"nome":"John","idade":30,"cidade":"Nova York"}

Matriz

Também podemos transformar matrizes em cadeias de caracteres com a mesma função:

				
					const matriz = ["John", "Peter", "Sally", "Jane"];
					const meuJSON = JSON.stringify(matriz);

					// Resultado:
					["John","Peter","Sally","Jane"]

Armazenar dados

Para armazenar dados, é preciso que eles estejam em um formato específico e, independentemente de onde são armazenados, sempre é possível armazenar em formato de texto. O JSON possibilita armazenar objetos JavaScript nesse formato.

				
					// Armazenar os dados:
					const meuObj = {nome: "John", idade: 31, cidade: "Nova York"};
					const meuJSON = JSON.stringify(meuObj);
					localStorage.setItem("testeJSON", meuJSON);

					// Recuperar os dados:
					let texto = localStorage.getItem("testeJSON");
					let obj = JSON.parse(texto);
					document.getElementById("demo").innerHTML = obj.nome;

Todos os tipos de dados

Esta função pode converter qualquer tipo de dados em uma cadeia de caracteres, não só objetos e matrizes. Por exemplo:

				
					// Números:
					const num = 123e-5;
					const meyJSON = JSON.stringify(num); // 0.00123

					// Booleanos:
					let bool = new Boolean(1);
					const meuJSON = JSON.stringify(bool); // true

Datas

Objetos de data não são permitidos no JSON. A função JSON.stringify() converterá qualquer objeto de data em cadeias de caracteres:

				
					const obj = {nome: "John", hoje: new Date(), cidade : "Nova York"};
					const meuJSON = JSON.stringify(obj); // {"nome":"John","hoje":"2025-07-11T17:31:15.568Z","cidade":"Nova York"}

Após receber o objeto no ponto final, é possível converter o objeto novamente em data.

Funções

As funções não são objetos permitidos no JSON, porém a função JSON.stringify() removerá qualquer função de um objeto JavaScript, transformando ambos a chave e o valor em cadeias de caracteres:

				
					const obj = {nome: "John", idade: function () {return 30;}, cidade: "Nova York"};
					const meuJSON = JSON.stringify(obj); // {"nome":"John","cidade":"Nova York"}

Podemos evitar que a função seja removida ao convertê-la primeiro em uma cadeia de caracteres:

				
					const obj = {nome: "John", idade: function () {return 30;}, cidade: "Nova York"};
					obj.idade = obj.idade.toString();
					const meuJSON = JSON.stringify(obj); // {"nome":"John","idade":"function () {return 30;}","cidade":"Nova York"}

Lembre-se que ao enviar funções via JSON, elas podem perder o escopo (o contexto) e deverão ser convertidas com a função eval() para que funcionem novamente.

Enviar dados para um servidor

Se um objeto JavaScript contém dados, podemos converter o objeto em JSON e enviá-lo ao servidor:

				
					const meuObj = {nome: "John", idade: 31, cidade: "Nova York"};
					const meuJSON = JSON.stringify(meuObj);
					window.location = "demo_json.php?x=" + meuJSON;

Receber dados de um servidor

Ao receber dados no formato JSON, podemos convertê-los em um objeto JavaScript:

				
					const meuJSON = '{"nome":"John", "idade":31, "cidade":"Nova York"}';
					const meuObj = JSON.parse(meuJSON);
					document.getElementById("demo").innerHTML = meuObj.nome;

Solicitar JSON de um servidor

Podemos solicitar JSON se um servidor usando AJAX. Desde que a resposta venha no formato JSON, podemos convertê-la em um objeto JavaScript.

				
					const xmlhttp = new XMLHttpRequest();
					xmlhttp.onload = function() {
						const meuObj = JSON.parse(this.textoResposta);
						document.getElementById("demo").innerHTML = meuObj.nome;
					};
					xmlhttp.open("GET", "json_demo.txt");
					xmlhttp.send();

Este é o objeto usado no exemplo acima:

					
						{"nome":"John",
						"idade":31,
						"animais":[
							{ "animal":"cão", "nome":"Fido" },
							{ "animal":"gato", "nome":"Felix" },
							{ "animal":"hamster", "nome":"Raio" }]
						}

JSON e PHP

A seguir veremos como compartilhar dados em JSON entre o cliente e o servidor PHP.

O arquivo PHP

O PHP oferece algumas funções para lidar diretamente com JSON. Podemos converter objetos do PHP em JSON usando a função json_encode():

				
					<?php
					$meuObj->nome = "John";
					$meuObj->idade = 30;
					$meuObj->cidade = "Nova York";

					$meuJSON = json_encode($meuObj);

					echo $meuJSON;
					?>

O cliente JavaScript

Agora vejamos como fica o JavaScript no lado do cliente, usando uma chamada AJAX para solicitar o arquivo PHP acima:

				
					const xmlhttp = new XMLHttpRequest();
					xmlhttp.onload = function() {
						const meuObj = JSON.parse(this.responseText);
						document.getElementById("demo").innerHTML = meuObj.nome;
					}
					xmlhttp.open("GET", "demo_file.php");
					xmlhttp.send();

Matriz no PHP

Também podemos converter matrizes no PHP para JSON usando a função json_encode():

				
					<?php
					$minhaMatriz = array("John", "Mary", "Peter", "Sally");

					$meuJSON = json_encode($minhaMatriz);

					echo $meuJSON;
					?>

E este é o JavaScript correspondente:

				
					var xmlhttp = new XMLHttpRequest();
					xmlhttp.onload = function() {
						const meuObj = JSON.parse(this.responseText);
						document.getElementById("demo").innerHTML = meuObj[2];
					}
					xmlhttp.open("GET", "demo_file_array.php", true);
					xmlhttp.send();

Banco de dados PHP

O PHP é uma linguagem de programação usada no servidor, usada para acessar um banco de dados. Imagine que temos um banco de dados no servidor e queremos enviar uma solicitação a ele, vinda do cliente, para pedir as 10 primeiras linhas em uma tabela chamada "clientes".

No cliente, criamos um objeto JSON que descreve a quantidade de linha que se deseja retornar. Antes de enviar a solicitação ao servidor, precisamos converter o objeto JSON em uma cadeia de caracteres, para enviá-lo como parâmetro à URL da página em PHP:

				
					const limite = {"limit":10};
					const paramDB = JSON.stringify(limite);
					xmlhttp = new XMLHttpRequest();
					xmlhttp.onload = function() {
						document.getElementById("demo").innerHTML = this.responseText;
					}
					xmlhttp.open("GET","json_demo_db.php?x=" + paramDB);
					xmlhttp.send();

Explicação do exemplo:

  • Definir um objeto que contém uma propriedade "limite" e seu valor
  • Converter o objeto em uma cadeia de caracteres JSON
  • Enviar uma solicitação ao arquivo PHP, com a cadeia de caracteres JSON como parâmetro
  • Aguardar até que a solicitação retorne com o resultado (em formato JSON)
  • Exibir o resultado recebido do arquivo PHP

Vejamos o arquivo PHP:

					
						<?php
						header("Content-Type: application/json; charset=UTF-8");
						$obj = json_decode($_GET["x"], false);

						$conn = new mysqli("meuServidor", "meuUsuario", "minhaSenha", "Northwind");
						$stmt = $conn->prepare("SELECT nome FROM clientes LIMIT ?");
						$stmt->bind_param("s", $obj->limit);
						$stmt->execute();
						$result = $stmt->get_result();
						$outp = $result->fetch_all(MYSQLI_ASSOC);

						echo json_encode($outp);
						?>

Explicação

  • Converter a solicitação em um objeto usando a função json_decode() do PHP
  • Acessar o banco de dados e preencher uma matriz com os dados solicitados
  • Adicionar a matriz a um objeto e retorná-lo como JSON usando a função json_encode()

Depois é só usar os dados:

					
						xmlhttp.onload = function() {
						const meuObj = JSON.parse(this.responseText);
						let texto = "";
						for (let x in meuObj) {
							texto += meuObj[x].nome + "
";
						}
						document.getElementById("demo").innerHTML = texto;
					}

Método POST no PHP

Ao enviar dados para o servidor, é melhor usar o método HTTP POST. Para enviar solicitações AJAX usando este método, defina-o com o cabeçalho correto. Os dados enviador ao servidor devem, então, se tornar um argumento do método send():

					
						const paramDB = JSON.stringify({"limit":10});
						const xmlhttp = new XMLHttpRequest();
						xmlhttp.onload = function() {
							const meuObj = JSON.parse(this.responseText);
							let texto ="";
							for (let x in meuObj) {
								texto += meuObj[x].nome + "
";
							}
							document.getElementById("demo").innerHTML = texto;
						}
						xmlhttp.open("POST", "json_demo_db_post.php");
						xmlhttp.setRequestHeader("Content-type", "application/x-www-form-urlencoded");
						xmlhttp.send("x=" + paramDB);

O arquivo PHP aqui tem uma diferença: o método usado para transferir os dados.

					
						<?php
						header("Content-Type: application/json; charset=UTF-8");
						$obj = json_decode($_POST["x"], false);

						$conn = new mysqli("meuServidor", "meuUsuario", "minhaSenha", "Northwind");
						$stmt = $conn->prepare("SELECT nome FROM clientes LIMIT ?");
						$stmt->bind_param("s", $obj->limit);
						$stmt->execute();
						$result = $stmt->get_result();
						$outp = $result->fetch_all(MYSQLI_ASSOC);

						echo json_encode($outp);
						?>

JSON e HTML

É possível traduzir JSON em JavaScript e, em seguida, usá-lo para criar páginas em HTML. Exemplos:

  • Tabela em HTML
  • Tabela dinâmica em HTML
  • Lista suspensa em HTML

Tabela em HTML

Criar uma tabela em HTML com dados advindos de JSON:

					
						const paramDB = JSON.stringify({table:"clientes",limit:20});
						const xmlhttp = new XMLHttpRequest();
						xmlhttp.onload = function() {
							meuObj = JSON.parse(this.responseText);
							let texto = "<table border='1'>"
							for (let x in meuObj) {
								texto += "<tr><td>" + meuObj[x].name + "</td></tr>";
							}
							texto += "</table>"
							document.getElementById("demo").innerHTML = texto;
						}
						xmlhttp.open("POST", "json_demo_html_table.php");
						xmlhttp.setRequestHeader("Content-type", "application/x-www-form-urlencoded");
						xmlhttp.send("x=" + paramDB);

Tabela dinâmica em HTML

Criar uma tabela em HTML com base no valor selecionado em uma lista suspensa ("Clientes", "Produtos" ou "Fornecedores"):

					
						<select id="minhaselecao" onchange="alterar_minhaselecao(this.value)">
						<option value="">Escolha uma opção:</option>
						<option value="customers">Clientes</option>
						<option value="products">Produtos</option>
						<option value="suppliers">Fornecedores</option>
					</select>

					<script>
					function alterar_minhaselecao(sel) {
						const paramDB = JSON.stringify({table:sel,limit:20});
						const xmlhttp = new XMLHttpRequest();
						xmlhttp.onload = function() {
							const meuObj = JSON.parse(this.responseText);
							let texto = "<table border='1'>"
							for (let x in meuObj) {
								texto += "<tr><td>" + meuObj[x].name + "</td></tr>";
							}
							texto += "</table>"
							document.getElementById("demo").innerHTML = texto;
						}
						xmlhttp.open("POST", "json_demo_html_table.php");
						xmlhttp.setRequestHeader("Content-type", "application/x-www-form-urlencoded");
						xmlhttp.send("x=" + paramDB);
					}
					</script>

Lista suspensa em HTML

Criar uma lista suspensa em HTML com dados advindos de JSON:

					
						const paramDB = JSON.stringify({table:"clientes",limit:20});
						const xmlhttp = new XMLHttpRequest();
						xmlhttp.onload = function() {
							const meuObj = JSON.parse(this.responseText);
							let texto = "<select>"
							for (let x in meuObj) {
								texto += "<option>" + meuObj[x].name + "</option>";
							}
							texto += "</select>"
							document.getElementById("demo").innerHTML = texto;
							}
						xmlhttp.open("POST", "json_demo_html_table.php", true);
						xmlhttp.setRequestHeader("Content-type", "application/x-www-form-urlencoded");
						xmlhttp.send("x=" + paramDB);

JSONP

JSONP é um método para enviar dados JSON sem ter que se preocupar com problemas de domínios cruzados. JSONP não usa o objeto XMLHttpRequest, mas a tag <script>.

JSONP significa JSON with Padding.

Solicitar um arquivo de outro domínio pode gerar problemas devido à política de domínios cruzados. Solicitar um script externo de outro domínio não gera esse problema. O JSONP usa isso para solicitar arquivos com a tag script em vez do objeto XMLHttpRequest.

O arquivo no servidor

O arquivo no servidor contém o resultado em uma chamada de função:

					
						<?php
						$meuJSON = '{ "nome":"John", "idade":30, "cidade":"Nova York" }';

						echo "minhaFunc(".$meuJSON.");";
						?>

O resultado retorna uma chamada para uma função chamada "minhaFunc", com os dados JSON como parâmetro. Certifique-se de que a função existe no cliente.

A função JavaScript

A função "minhaFunc" está localizada no cliente e fica pronta para lidar com os dados JSON:

					
						function minhaFunc(meuObj) {
						document.getElementById("demo").innerHTML = meuObj.nome;
					}

Criar uma tag script dinâmica

O exemplo acima executa a função "minhaFunc" ao carregar a página, com base em onde você coloca a tag script, o que não é muito adequado. Essa tag só deve ser criada quando necessário, portanto podemos criar e inserir a tag ao clicar em um botão:

					
						function clicarBotao() {
						let s = document.createElement("script");
						s.src = "demo_jsonp.php";
						document.body.appendChild(s);
					}

Resultado JSONP dinâmico

Os exemplos acima ainda são muito estáticos. Vamos criar um exemplo mais dinâmico enviando o JSON para o arquivo php e deixando que ele retorne um objeto JSON com base nas informações recebidas.

					
						<?php
						header("Content-Type: application/json; charset=UTF-8");
						$obj = json_decode($_GET["x"], false);

						$conn = new mysqli("meuServidor", "meuUsuario", "minhaSenha", "Northwind");
						$result = $conn->query("SELECT name FROM ".$obj->$table." LIMIT ".$obj->$limit);
						$outp = array();
						$outp = $result->fetch_all(MYSQLI_ASSOC);

						echo "minhaFunc(".json_encode($outp).")";
						?>

Explicação:

  • Converter a solicitação em um objeto usando a função PHP json_decode().
  • Acessar o banco de dados e preencher uma matriz com os dados selecionados.
  • Adicionar a matriz a um objeto.
  • Converter a matriz em JSON usando a função json_encode().
  • Colocar a "minhaFunc()" em volta do objeto retornado.

E esta é a função que será chamada no arquivo php:

					
						const obj = { table: "produtos", limit: 10 };
						let s = document.createElement("script");
						s.src = "jsonp_demo_db.php?x=" + JSON.stringify(obj);
						document.body.appendChild(s);

						function minhaFunc(meuObj) {
							let txt = "";
							for (let x in meuObj) {
								txt += meuObj[x].nome + "<br>";
							}
							document.getElementById("demo").innerHTML = txt;
						}

Função de retorno de chamada

Quando não se tem controle sobre o arquivo no servidor, como podemos fazê-lo chamar a função correta? Em alguns casos, o arquivo no servidor oferece uma função de retorno como parâmetro. O exemplo abaixo chama a função que você passar como um parâmetro de retorno de chamada:

					
						let s = document.createElement("script");
						s.src = "jsonp_demo_db.php?callback=minhaFuncExcibicao";
						document.body.appendChild(s);
