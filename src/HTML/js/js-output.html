Possibilidades de exibição

O JS pode "exibir" dados de diferentes maneiras:

  • Com innerHTML para escrever código dentro do elemento.
  • Com document.write() para escrever código na saída do documento.
  • Com window.alert() para exibir uma caixa de alerta.
  • Com console.log() para exibir uma mensagem no console do navegador.

InnerHTML

document.write()

Esta função só deve ser usada para fins de teste, porque se o documento HTML já tiver sido carregado, ela excluirá todo o conteúdo do documento! Veja exemplos aqui e aqui.

window.alert()

Esta função exibe uma caixa de alerta no navegador para fornecer informações. Por exemplo:

			
				<script>
				window.alert(5 + 6);
				</script>

exibirá uma caixa com o valor da soma assim que a página carregar, antes de exibir qualquer conteúdo.

Você pode ocultar a palavra-chave window, já que este é um objeto de escopo global e, portanto, quaisquer variáveis, propriedades e métodos, por padrão, pertencem a esse objeto.

console.log()

Para fins de depuração, podemos usar este método para exibir dados no console do navegador.

"print"

O JS não possui métodos ou objetos que "imprimem" informações. A única exceção é o método window.print(), que imprime — literalmente — o conteúdo da janela atual. Veja um exemplo.
