Escopo

Como vimos nas seções sobre loop e declarações de variáveis, o escopo determina o acesso (ou visibilidade) das variáveis. Há três tipos de escopo:

  • De bloco
  • De função
  • Global

Variáveis

No JavaScript, objetos e funções também são considerados variáveis e o escopo determina a acessibilidade deles em diferentes partes do código.

O ciclo de vida de uma variável no JavaScript começa com sua declaração. Variáveis locais são excluídas ao concluir a função. Variáveis globais são excluídas ao fechar a janela do navegador (ou a aba).

Escopo de bloco

Até o ES6 (2015), as variáveis no JavaScript tinham apenas dois escopos: global e de função. Desde então, temos duas palavras-chave importantes: let e const, que fornecem também o escopo de bloco. As variáveis declaradas dentro de um bloco delimitado por chaves ({ }) não podem ser acessadas de fora do bloco.

Variáveis declaradas com a palavra-chave var não podem ter escopo de bloco e podem ser acessadas de fora das chaves ({ }).

Escopo de função

As variáveis declaradas em uma função no JavaScript são locais e não é possível usá-las fora das chaves ({ }). Como essas variáveis só são reconhecidas dentro de suas funções, é possível usar variáveis com o mesmo nome em funções diferentes. Elas são criadas quando a função inicia e excluídas quando a função termina, isto é, cada função cria um novo escopo. As três palavras-chave let, const e var podem ser usadas para criar variáveis com escopo de função.

Parâmetros de funções funcionam como variáveis locais dentro de funções.

Escopo global

Uma variável declarada fora de uma função tem escopo global, isto é, todos os scripts e funções em uma página podem acessá-la de qualquer lugar. As três palavras-chave let, const e var podem ser usadas para criar variáveis com escopo global.

Ao atribuir um valor a uma variável que não havia sido declarada, ela se torna automaticamente global. O exemplo abaixo declara uma variável global carName, apesar de o valor estar sendo declarado somente dentro de uma função:

				
					myFunction();

					// qualquer código aqui pode usar carName

					function myFunction() {
						carName = "Volvo";
					}

Modo restrito

Todos os navegadores modernos executam o JavaScript no modo restrito, isto é, variáveis não declaradas não são globais automaticamente.

Variáveis globais no HTML

No JavaScript, o escopo global é o ambiente JavaScript, mas no HTML, é o objeto window. Variáveis declaradas com a palavra-chave var pertencem ao objeto window.

Variáveis declaradas com let não pertencem ao objeto window.

NÃO crie variáveis globais, a menos que queira isso explicitamente, essas variáveis (ou funções) podem sobrescrever as variáveis do objeto window!
