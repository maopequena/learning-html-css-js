Operadores

Use os operadores para realizar diferentes tipos de cálculos lógicos e matemáticos:

Tipos de operadores

Há diferentes tipos de operadores em JavaScript:

  • Aritméticos
  • Atribuição
  • Comparação
  • Sequência de caracteres (strings)
  • Lógicos
  • Bitwise
  • Ternários
  • De tipo

Operadores aritméticos

Operadores aritméticos realizam cálculos com números, que podem ser literais, variáveis ou expressões.

			
	let x = 100 + 50; // cálculo com literais
	let x = a + b; // cálculo com variáveis
	let x = (100 + 50) * a // cálculo com expressão

Operadores e operandos

Em um cálculo aritmético, os números são chamados de operandos e os símbolos que definem o cálculo são chamados de operadores.

Operando Operador Operando
100 + 50

A tabela a seguir exibe os operadores aritméticos e descreve o que fazem.

Operador Descrição
+ Adição
- Subtração
* Multiplicação
** Exponente (ES2016, gera o mesmo resultado que Math.pow(x, y))
/ Divisão
% Módulo (resto da divisão)
++ Incremento
-- Decremento

Em aritmética, a divisão de dois inteiros gera um quociente e um resto. Na matemática, o resultado de uma operação de módulo é o resto de uma divisão aritmética.

O operador de precedência

Considere a seguinte expressão:

			
	let x = 100 + 50 * 3;

Neste caso, qual o resultado? 100 + 150? Ou 150 * 3? O que fazer primeiro: a adição ou a multiplicação?

Na escola aprendemos que a multiplicação vem primeiro, pois multiplicação e divisão têm precedência sobre adição e subtração. E para definir essa precedência usamos parênteses.

No JavaScript é igual! Podemos usar parênteses para definir qual cálculo deve ser realizado primeiro. Lembre-se que o computador não entende a regra da escola e precisamos instruir pelo código como fazer o cálculo, minuciosamente.

Caso não seja definida a precedência, o JavaScript assume que os cálculos serão feitos da esquerda para a direita.

Todos os operadores acima também podem ser usados para comparar texto:

			
	let text1 = "A";
	let text2 = "B";
	let result = text1 < text2; // resultado = true

	let text1 = "20";
	let text2 = "5";
	let result = text1 < text2; // resultado = true

O sinal de adição (+) e seus similares de atribuição (+=) também podem ser usados com texto para concatenação:

			
	let text1 = "What a very ";
	text1 += "nice day"; // resultado de text1 = "What a very nice day"

Observação: ao somar números e strings de números, a string SEMPRE vence e ambos os valores tornam-se strings:

			
	let x = 5 + 5; // x = "10"
	let y = "5" + 5; // y = "55"
	let z = "Hello" + 5; // z = "Hello5"

Operadores bitwise

Operadores de bit manipulam números de 32 bits. Qualquer operando numérico na operação é convertido em um número de 32 bits. O resultado é convertido de volta para um número em JavaScript.

Operador Descrição Exemplo É o mesmo que Resultado Decimal
& E 5 & 1 0101 & 0001 0001  1
| OU 5 | 1 0101 | 0001 0101  5
~ NÃO ~ 5  ~0101 1010  10
^ OU EXCLUSIVO 5 ^ 1 0101 ^ 0001 0100  4
<< deslocar um bit à esquerda (efetivamente, multiplicar por 2) 5 << 1 0101 << 1 1010  10
>> deslocar um bit à direita (efetivamente, dividir por 2) 5 >> 1 0101 >> 1 0010   2
>>> deslocamento não atribuído à direita 5 >>> 1 0101 >>> 1 0010   2

Os exemplos acima usam exemplos não atribuídos de 4 bits, mas o JavaScript usa números atribuídos de 32 bits. Por causa disso, em JavaScript, ~ 5 não retorna 10, mas sim -6. Isto é, ~00000000000000000000000000000101 retorna 11111111111111111111111111111010.
