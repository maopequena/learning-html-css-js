AJAX

AJAX não é uma linguagem de programação, é uma técnica para acessar servidores da Web a partir de uma página no navegador. AJAX significa Asynchronous JavaScript and XML.

O AJAX combina um objeto XMLHttpRequest, que acompanha qualquer navegador, para solicitar dados de um servidor da Web, do JavaScript e do DOM HTML.

Dessa forma, as páginas da Web são atualizadas de forma assíncrona, trocando dados com um servidor da Web em segundo plano. E não é preciso recarregar a página para obter os novos dados.

Como o AJAX funciona

Explicação

  1. Determinado evento ocorre em uma página (a página carrega, o usuário clica em um botão, etc...)
  2. O JavaScript cria um objeto XMLHttpRequest
  3. O objeto XMLHttpRequest envia uma solicitação a um servidor da Web
  4. O servidor processa a solicitação
  5. O servidor enviar uma resposta de volta à página da Web
  6. O JavaScript lê a resposta
  7. O JavaScript executa a ação apropriada (como atualizar a página)

Em navegadores modernos, temos a API de solicitação (fetch()). Saiba mais em API de solicitação.

O objeto XMLHttpRequest

A base do AJAX é o objeto XMLHttpRequest, que:

  • Cria um objeto XMLHttpRequest
  • Define uma função de retorno
  • Abre um objeto XMLHttpRequest
  • Envia uma solicitaçãoa um servidor

Todos os navegadores modernos oferecem suporte a este objeto, que pode ser usado para trocar dados com um servidor da Web em segundo plano, isto é, podemos atualizar uma página sem a necessidade de recarregá-la.

Como criar o objeto XMLHttpRequest

Sintaxe: let variável = new XMLHttpRequest();

Como definir uma função de retorno é passada como um parâmetro em outra função e deve conter o código a executar quando a resposta do objeto XMLHttpRequest estiver pronta.

Exemplo de sintaxe:

						
							xhttp.onload = funcao() {
								// Código que indica o que fazer quando a resposta estiver pronta
							}

Por exemplo, para enviar uma solicitação a um servidor, podemos usar os métodos open() e send():

						
							xhttp.open("GET", "ajax_info.txt");
							xhttp.send();

Por motivos de segurança, os navegadores modernos não permitem o acesso entre domínios, portanto a página de origem e o arquivo XML a ser carregado precisam estar no mesmo servidor.

Propriedades do objeto XMLHttpRequest

Propriedade Descrição

onreadystatechange Define uma função a ser chamada quando a propriedade readyState mudar
readyState Contém o status de XMLHttpRequest. Explicação dos códigos:
0: solicitação não iniciada

statusText Retorna o texto de status (p.ex. "OK" ou "Not Found" [Não encontrado])

A propriedade onload

Com o objeto XMLHttpRequest é possível definir uma função de retorno a ser executada quando a solicitação recebe uma resposta. Define-se essa função na propriedade onload:

					
						xhttp.onload = function() {
							document.getElementById("demo").innerHTML = this.responseText;
						}
						xhttp.open("GET", "ajax_info.txt");
						xhttp.send();

Se houver mais de uma tarefa AJAX no site, crie uma função para executar o objeto XMLHttpRequest e uma para cada tarefa AJAX. A chamada para a função deve conter o URL e qual função chamar quando a resposta estiver pronta. Exemplo:

					
						carregarDoc("url-1", minhaFuncao1);

						carregarDoc("url-2", minhaFuncao2);

						function carregarDoc(url, cFunction) {
							const xhttp = new XMLHttpRequest();
							xhttp.onload = function() {cFunction(this);}
							xhttp.open("GET", url);
							xhttp.send();
						}

						function minhaFuncao1(xhttp) {
							// a ação a executar
						}
						function minhaFuncao2(xhttp) {
							// a ação a executar
						}

A propriedade onreadystatechange

A propriedade readyState contém o status de XMLHttpRequest. A propriedade onreadystatechange define uma função de retorno a ser executada quando readyState mudar. As propriedades status e statusText contêm o status do objeto XMLHttpRequest.

Propriedade Descrição
onreadystatechange Define uma função a ser chamada quando a propriedade readyState mudar
readyState Contém o status de XMLHttpRequest.
0: solicitação não iniciada
1: conexão com o servidor estabelecida
2: solicitação recebida
3: processando a solicitação
4: solicitação finalizada, a resposta está pronta
status 200: "OK"
403: "Proibido"
404: "Página não encontrada"
Para ver a lista completa, acesse Referência sobre mensagens HTTP
statusText Retorna o texto do status (p.ex. "OK" ou "Não encontrado")

A função onreadystatechange é chamada sempre que readyState muda. Quando readyState é 4 e o status é 200, a resposta está pronta. Exemplo:

					
						function carregarDoc() {
							const xhttp = new XMLHttpRequest();
							xhttp.onreadystatechange = function() {
								if (this.readyState == 4 && this.status == 200) {
									document.getElementById("demo").innerHTML =
									this.responseText;
								}
							};
							xhttp.open("GET", "ajax_info.txt");
							xhttp.send();
						}

O evento onreadystatechange é acionado quatro vezes (1-4), uma vez para cada mudança de readyState.

XMLHttpRequest

Usa-se este objeto para solicitar dados de um servidor.

Enviar uma solicitação para um servidor

Para enviar uma solicitação a um servidor, podemos usar os métodos open() e send().

					
						xhttp.open("GET", "ajax_info.txt", true);
						xhttp.send();
Método Descrição
open(method, url, async) Especifica o tipo de solicitação:
method: o tipo de solicitação, GET ou POST
url: o local do servidor (do arquivo)
async: true (se assíncrono) ou false (se síncrono)
send() Envia a solicitação ao servidor (usado para GET)
send(string) Envia a solicitação ao servidor (usado para POST)

O parâmetro url do método open() é um endereço em um servidor. Pode ser qualquer tipo de arquivo, como .txt ou .xml, ou arquivos de script, como .asp ou .php, que executam ações no servidor antes de enviar uma resposta.

As solicitações enviadas ao servidor devem ser assíncronas, isto é, o parâmetro async deve ser true. Dessa forma, o JavaScript não precisa esperar pela resposta do servidor e pode executar outros scripts enquanto espera pela resposta e lidar com a resposta quando estiver pronta.

O valor padrão para o parâmetro async é true, então você pode omiti-lo no código.Não se recomenda usar false, porque o JavaScript para de executar até que a resposta do servidor esteja pronta. Se o servidor estiver ocupado ou for lento, o aplicativo pode travar ou parar.

Entretanto, async = false pode ser usado para um teste rápido.

GET ou POST?

GET é mais simples e rápido que POST e pode ser usado na maioria dos casos. Entretanto, sempre use solicitações POST nos seguintes casos:

  • Não for possível usar um arquivo em cache (ao atualizar um arquivo ou banco de dados no servidor, por exemplo).
  • Ao enviar uma grande quantidade de dados ao servidor (POST não tem limites de tamanho).
  • Ao enviar informações digitadas pelo usuário (que podem conter caracteres desconhecidos), POST é mais robusto e seguro que GET.
