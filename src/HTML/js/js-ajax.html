AJAX

AJAX não é uma linguagem de programação, é uma técnica para acessar servidores da Web a partir de uma página no navegador. AJAX significa Asynchronous JavaScript and XML.

O AJAX combina um objeto XMLHttpRequest, que acompanha qualquer navegador, para solicitar dados de um servidor da Web, ao JavaScript e ao DOM HTML.

Dessa forma, as páginas da Web são atualizadas de forma assíncrona, trocando dados com um servidor da Web em segundo plano. E não é preciso recarregar a página para obter os novos dados.

Como o AJAX funciona

Explicação

  1. Determinado evento ocorre em uma página (a página carrega, o usuário clica em um botão, etc...)
  2. O JavaScript cria um objeto XMLHttpRequest
  3. O objeto XMLHttpRequest envia uma solicitação a um servidor da Web
  4. O servidor processa a solicitação
  5. O servidor enviar uma resposta de volta à página da Web
  6. O JavaScript lê a resposta
  7. O JavaScript executa a ação apropriada (como atualizar a página)
