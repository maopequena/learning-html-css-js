APIs da Web

Introdução

Uma API da Web é o sonho de um desenvolvedor:

  • Ela amplia a funcionalidade do navegador.
  • Ela pode simplificar, e muito, funções complexas.
  • Ela pode fornecer uma sintaxe simplificada para um código complexo.

O que é uma API da Web?

API significa Interface de Programação de Aplicativos. Há vários tipos de APIs: da Web, de navegador e de servidor.

Todos os navegadores têm APIs incorporadas que oferecem suporte a operações complexas e ajudam a acessar dados. Por exemplo, a API Geolocation retorna as coordenadas da localização do navegador.

Há também APIs de terceiros, que não estão incorporadas no navegador. Para usá-las, é preciso fazer download do código da Internet. Exemplos:

  • API do YouTube: possibilita exibir vídeos em um site.
  • API do Twitter (X): possibilita exibir tweets em um site.
  • API do Facebook: possibilita exibir informações do FB em um site.

API de validação do JavaScript

Métodos de validação para restrição no DOM:

Propriedade Descrição
checkValidity() Retorna true se um elemento inserido contém dados válidos.
setCustomValidity() Define a propriedade validationMessage de um elemento inserido.

Propriedades de validação para restrição no DOM:

Propriedade Descrição
validity Contém propriedades booleanas relacionadas à validade de um elemento inserido.
validationMessage Contém a mensagem que o navegador exibirá quando validity for false.
willValidate Indica se um elemento inserido será validado.

A propriedade validity oferece várias propriedades relacionadas à validação de dados:

Propriedade Descrição
customError Retorna true se houver uma mensagem de validação personalizada.
patternMismatch Retorna true se o valor de um elemento não corresponde ao atributo pattern.
rangeOverflow Retorna true se o valor de um elemento é maior que o atributo max.
rangeUnderflow Retorna true se o valor de um elemento é menor que o atributo min.
stepMismatch Retorna true se o valor de um elemento é inválido em relação ao atributo step.
tooLong Retorna true se o valor de um elemento excede o atributo maxLength.
typeMismatch Retorna true se o valor de um elemento é inválido em relação ao atributo type.
valueMissing Retorna true se um elemento com o atributo required não tem valor.
valid Retorna true se o valor de um elemento é válido.

API de histórico

Esta API fornece métodos para acessar o objeto window.history, que contém os URLs visitados pelo usuário.

back()

Este método carrega o URL anterior no histórico e é o mesmo que clicar na seta para voltar na janela do navegador.

go()

Carrega um URL específico no histórico.

A tabela a seguir mostra a propriedade e os métodos do objeto window.history:

Método Descrição
back() Carrega o URL anterior no histórico
forward() Carrega o próximo URL no histórico
go() Carrega um URL específico do histórico
Propriedade Descrição
length Retorna a quantidade de URLs no histórico

API de armazenamento

A API de armazenamento é uma sintaxe simples para armazenar e recuperar dados no navegador.

localStorage

Este objeto fornece acesso ao armazenamento local para determinado site e possibilita armazenar, ler, adicionar, alterar e excluir itens de dados do domínio relevante. Os dados armazenados não tem validade e não serão excluídos ao fechar o navegador; eles ficam disponíveis por dias, semanas ou anos.

setItem()

Este método armazena um item de dados e recebe como parâmetros um nome e um valor:

						
							localStorage.setItem("nome", "John Doe");
							sessionStorage.setItem("nome", "John Doe");

getItem()

Este método recupera um item de dados do armazenamento e recebe apenas o nome como parâmetro:

						
							localStorage.getItem("nome");
							sessionStorage.getItem("nome", "John Doe");

sessionStorage

Este objeto é idêntico a localStorage, porém só armazena dados para a sessão atual, os dados são excluídos ao fechar o navegador.

						
							sessionStorage.getItem("nome");

Propriedades e métodos do objeto de armazenamento

Propriedade/Método Descrição
key(n) Retorna o nome da enésima chave no armazenamento
length Retorna a quantidade de itens de dados armazenada no objeto Storage
getItem(nomeDaChave) Retorna o valor do nome de chave especificado
setItem(nomeDaChave, valor) Adiciona uma chave ao armazenamento, ou atualiza um valor de chave (se já existir)
removeItem(nomeDaChave) Remove a chave do armazenamento
clear() Esvazia todas as chaves no armazenamento
