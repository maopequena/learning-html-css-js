APIs da Web

Introdução

Uma API da Web é o sonho de um desenvolvedor:

  • Ela amplia a funcionalidade do navegador.
  • Ela pode simplificar, e muito, funções complexas.
  • Ela pode fornecer uma sintaxe simplificada para um código complexo.

O que é uma API da Web?

API significa Interface de Programação de Aplicativos. Há vários tipos de APIs: da Web, de navegador e de servidor.

Todos os navegadores têm APIs incorporadas que oferecem suporte a operações complexas e ajudam a acessar dados. Por exemplo, a API de geolocalização retorna as coordenadas da localização do navegador.

Há também APIs de terceiros, que não estão incorporadas no navegador. Para usá-las, é preciso fazer download do código da Internet. Exemplos:

  • API do YouTube: possibilita exibir vídeos em um site.
  • API do Twitter (X): possibilita exibir tweets em um site.
  • API do Facebook: possibilita exibir informações do FB em um site.

API de validação do JavaScript

Métodos de validação para restrição no DOM:

Propriedade Descrição
checkValidity() Retorna true se um elemento inserido contém dados válidos.
setCustomValidity() Define a propriedade validationMessage de um elemento inserido.

Propriedades de validação para restrição no DOM:

Propriedade Descrição
validity Contém propriedades booleanas relacionadas à validade de um elemento inserido.
validationMessage Contém a mensagem que o navegador exibirá quando validity for false.
willValidate Indica se um elemento inserido será validado.

A propriedade validity oferece várias propriedades relacionadas à validação de dados:

Propriedade Descrição
customError Retorna true se houver uma mensagem de validação personalizada.
patternMismatch Retorna true se o valor de um elemento não corresponde ao atributo pattern.
rangeOverflow Retorna true se o valor de um elemento é maior que o atributo max.
rangeUnderflow Retorna true se o valor de um elemento é menor que o atributo min.
stepMismatch Retorna true se o valor de um elemento é inválido em relação ao atributo step.
tooLong Retorna true se o valor de um elemento excede o atributo maxLength.
typeMismatch Retorna true se o valor de um elemento é inválido em relação ao atributo type.
valueMissing Retorna true se um elemento com o atributo required não tem valor.
valid Retorna true se o valor de um elemento é válido.

API de histórico

Esta API fornece métodos para acessar o objeto window.history, que contém os URLs visitados pelo usuário.

back()

Este método carrega o URL anterior no histórico e é o mesmo que clicar na seta para voltar na janela do navegador.

go()

Carrega um URL específico no histórico.

A tabela a seguir mostra a propriedade e os métodos do objeto window.history:

Método Descrição
back() Carrega o URL anterior no histórico
forward() Carrega o próximo URL no histórico
go() Carrega um URL específico do histórico
Propriedade Descrição
length Retorna a quantidade de URLs no histórico

API de armazenamento

A API de armazenamento é uma sintaxe simples para armazenar e recuperar dados no navegador.

localStorage

Este objeto fornece acesso ao armazenamento local para determinado site e possibilita armazenar, ler, adicionar, alterar e excluir itens de dados do domínio relevante. Os dados armazenados não tem validade e não serão excluídos ao fechar o navegador; eles ficam disponíveis por dias, semanas ou anos.

setItem()

Este método armazena um item de dados e recebe como parâmetros um nome e um valor:

						
							localStorage.setItem("nome", "John Doe");
							sessionStorage.setItem("nome", "John Doe");

getItem()

Este método recupera um item de dados do armazenamento e recebe apenas o nome como parâmetro:

						
							localStorage.getItem("nome");
							sessionStorage.getItem("nome", "John Doe");

sessionStorage

Este objeto é idêntico a localStorage, porém só armazena dados para a sessão atual, os dados são excluídos ao fechar o navegador.

						
							sessionStorage.getItem("nome");

Propriedades e métodos do objeto de armazenamento

Propriedade/Método Descrição
key(n) Retorna o nome da enésima chave no armazenamento
length Retorna a quantidade de itens de dados armazenada no objeto Storage
getItem(nomeDaChave) Retorna o valor do nome de chave especificado
setItem(nomeDaChave, valor) Adiciona uma chave ao armazenamento, ou atualiza um valor de chave (se já existir)
removeItem(nomeDaChave) Remove a chave do armazenamento
clear() Esvazia todas as chaves no armazenamento

API de tarefas

Uma API de tarefas (Workers API) é um script executado em segundo plano, independente de outros scripts e que não afeta o desempenho da página.

Antes de criar uma tarefa, é preciso garantir que haja suporte do navegador. Para tanto, use o seguinte código:

					
						if (typeof(Worker) !== "undefined") {
							// Sim! Há suporte para tarefas!
							// Código a executar
						} else {
							// Desculpe! Não há suporte para tarefas.
						}

Como criar uma tarefa

Para criar uma tarefa, é preciso usar um arquivo JavaScript externo, sem adicioná-lo ao HTML ou a um JavaScript com outros scripts. O exemplo a seguir gera uma contagem no arquivo demo_workers.js.

						
							let i = 0;

							function contagem() {
								i ++;
								postMessage(i);
								setTimeout("contagem()",500);
							}

							contagem();

Observe o método postMessage(), usado para exibir uma mensagem na página HTML.

Tarefas não são usadas para coisas tão simples, mas para algo que exige muito processamento.

Agora que temos o arquivo, precisamos chamá-lo na página HTML. O código a seguir verifica se a tarefa já existe, caso contrário, cria um novo objeto e executa o código em demo_workers.js.

						
							if (typeof(w) == "undefined") {
								w = new Worker("demo_workers.js");
							}

Agora podemos enviar e receber mensagens da tarefa. Vamos adicionar o event listener onmessage à tarefa:

						
							w.onmessage = function(event){
								document.getElementById("result").innerHTML = event.data;
							};

Ao publicar uma mensagem, a tarefa executa o código no event listener. Os dados são armazenados em event.data.

Como finalizar uma tarefa

O objeto de tarefa continua a aguardar mensagens, mesmo após a finalização do script externo. Para parar a tarefa e liberar recursos do computador, use o método terminate().

						
							w.terminate();

Como reutilizar uma tarefa

Ao definir a variável de tarefa como undefined, ela pode ser reutilizada.

						
							w = undefined;

Observe que as tarefas estão em arquivos externos, então não têm acesso aos seguintes objetos JavaScript:

  • O objeto window
  • O objeto document
  • O objeto pai

Exemplo completo da API de tarefas

							
								<!DOCTYPE html>
								<html>
								<body>

								<p>Contar números: <output id="result"></output></p>
								<button onclick="iniciarTarefa()">Iniciar tarefa</button>
								<button onclick="pararTarefa()">Parar tarefa</button>

								<script>
								let w;

								function iniciarTarefa() {
									if (typeof(w) == "undefined") {
										w = new Worker("demo_workers.js");
									}
									w.onmessage = function(event) {
										document.getElementById("result").innerHTML = event.data;
									};
								}

								function pararTarefa() {
									w.terminate();
									w = undefined;
								}
								</script>

								</body>
								</html>

API de solicitação

Esta API possibilita fazer solicitações HTTP a servidores da Web, isto é não precisamos mais usar XMLHttpRequest. Vejamos alguns exemplos:

Buscar um arquivo e exibir seu conteúdo

						
							fetch(arquivo)
							.then(x => x.texto())
							.then(y => exibir(y));

Como esta API baseia-se em async e await, pode ser mais fácil entendê-la assim:

						
							async function obterTexto(arquivo) {
								let x = await fetch(arquivo);
								let y = await x.texto();
								exibir(y);
							}

Melhor ainda: vamos usar nomes compreensíveis ao invés de x e y.

						
							async function obterTexto(arquivo) {
								let meuObjeto = await fetch(arquivo);
								let meuTexto = await meuObjeto.texto();
								exibir(meuTexto);
							}

API de geolocalização

Use esta API para obter a posição geográfica de um usuário. Porém, note que, como ela pode comprometer a privacidade, a posição só fica disponível se o usuário permitir. E lembre-se que a geolocalização é mais precisa em dispositivos com GPS, como smartphones.

A geolocalização só funciona em contextos seguros, como HTTPS.

O exemplo abaixo retorna a latitude e a longitude de um usuário através do método getCurrentPosition(). Note que este é um script bem básico, que não lida com erros.

					
						<script>
							const x = document.getElementById("demo");
							function obterLocal() {
								if (navigator.geolocation) {
									navigator.geolocation.getCurrentPosition(exibirPosicao);
								} else {
									x.innerHTML = "Não há suporte para a geolocalização neste navegador.";
								}
							}
							
							function exibirPosicao(posicao) {
								x.innerHTML = "Latitude: " + position.coords.latitude +
								"<br>Longitude: " + position.coords.longitude;
							}
							</script>

Explicação:

  • Verifica se há suporte para a geolocalização
  • Se há, executa o método getCurrentPosition(). Caso contrário, exibe uma mensagem para o usuário
  • Se o método getCurrentPosition() for bem sucedido, retorna um objeto de coordenadas para a função especificada no parâmetro (exibirPosicao)
  • A função exibirPosicao() retorna a Latitude e a Longitude

Use o segundo parâmetro de getCurrentPosition() para lidar com erros. Ele especifica uma função a executar se falhar ao obter a posição do usuário.

					
						function exibirErros(error) {
							switch(error.code) {
								case error.PERMISSION_DENIED:
									x.innerHTML = "O usuário negou a solicitação de geolocalização."
									break;
								case error.POSITION_UNAVAILABLE:
									x.innerHTML = "As informações de localização estão indisponíveis."
									break;
								case error.TIMEOUT:
									x.innerHTML = "Tempo excedido na solicitação para obter a localização."
									break;
								case error.UNKNOWN_ERROR:
									x.innerHTML = "Erro desconhecido."
									break;
							}
						}

Como exibir o resultado em um mapa

Para exibir o resultado em um mapa, é preciso ter acesso a um serviço de mapas, como o Google Maps. No exemplo abaixo, usamos a latitude e a longitude retornadas para mostrar o local no Google Maps (com uma imagem estática):

						
							function exibirPosicao(posicao) {
								let latlon = posicao.coords.latitude + "," + position.coords.longitude;
							
								let img_url = "https://maps.googleapis.com/maps/api/staticmap?center=
								"+latlon+"&zoom=14&size=400x300&sensor=false&key=SUA_CHAVE_API";
							
								document.getElementById("mapholder").innerHTML = "";
							}

Também podemos usar a geolocalização para exibir informações atualizadas de local, exibir pontos de interesse próximos ao usuário e navegação em mapas (GPS).

O método getCurrentPosition() retorna um objeto quanto é bem sucedido. As propriedades latitude, longitude e accuracy (precisão) sempre são retornadas, as propriedades abaixo somente quando estão disponíveis:

Propriedade Retorna
coords.latitude A latitude como um número decimal (sempre retornada)
coords.longitude A longitude como um número decimal (sempre retornada)
coords.accuracy A precisão da posição (sempre retornada)
coords.altitude A altitude, em metros, acima do nível do mar (somente se disponível)
coords.altitudeAccuracy A precisão da altitude da posição (somente se disponível)
coords.heading A orientação (norte, sul, leste ou oeste), em graus, no sentido horário a partir do norte (somente se disponível)
coords.speed A velocidade, em metros por segundo (somente se disponível)
timestamp A data/hora da resposta (somente se disponível)

Outros métodos interessantes da geolocalização

watchPosition()

Retorna a posição atual do usuário e continua retornando uma posição atualizada conforme o usuário se move (como o GPS em um carro).

clearWatch()

Pára o método watchPosition().
