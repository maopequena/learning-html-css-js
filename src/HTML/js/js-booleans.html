Booleanos

Em programação, muitas vezes precisamos de um tipo de dado que só pode ter dois valores, como:

  • Sim / Não
  • Ligado / Desligado
  • Verdadeiro / Falso

É para isso que servem os booleanos: um booleano representa um de dois valores: true ou false.

Qualquer coisa com um "valor" é verdadeira:

			
				Boolean(3.14) // true
				Boolean(100) // true
				Boolean(-15) // true
				Boolean("Hello") // true
				Boolean("false") // true
				Boolean(7 + 1 + 3.14) // true

Qualquer coisa sem um "valor" é falsa:

			
				let x = 0; // x é zero
				const a = Boolean(x); // false

				let y = -0; // y é menos zero
				const b = Boolean(y); // false

				let z = ""; // z é uma cadeia de caracteres vazia
				const c = Boolean(z); // false

				let w; // w é indefinido
				const d = Boolean(x); // false

				let v = null; // v é nulo
				const e = Boolean(v); // false

				let u = false; // u é falso
				const f = Boolean(u); // false

				let t = 10 / "Hello"; // t é NaN
				const g = Boolean(t); // false

A função Boolean()

Use esta função para descobrir se uma expressão (ou variável) é verdadeira:

			
				Boolean(10 > 9); // true

A expressão acima pode ser escrita também sem a palavra-chave Boolean:

			
				(10 > 9); // true
				10 > 9; // true

Booleanos como objetos

Normalmente, os booleanos no JavaScript são valores primitivos criados a partir de literais: let x = false;. Mas eles também podem ser definidos como objetos com a palavra-chave new: let y = new Boolean(false);. typeof x retorna boolean, typeof y retorna object.

OBSERVAÇÃO: não crie objetos booleanos! A palavra-chave new só complica o código e reduz sua velocidade de execução. Além disso, objetos booleanos podem gerar resultados inesperados: se compararmos x e y do exemplo usado acima com o operador ==, o resultado é true, e com o operador ===, o resultado é false.

Comparações e condições

O valor booleano de uma expressão é a base para todas as comparações e condições no JavaScript.

Observe que comparar dois objetos no JavaScript sempre retorna false.

Para testar se algo é true ou false, podemos usar operadores de comparação e lógicos.

Operador condicional (ternário, ?)

O JavaScript também oferece um operador condicional que atribui um valor a uma variável com base em uma condição. Sua sintaxe é a seguinte:

				
					nome_variável = (condição) ? valor1:valor2

Exemplo de uso

					
						let voteable = (age < 18) ? "Too young":"Old enough";

Neste caso, se a variável age é um valor abaixo de 18, o valor da variável votable será "Too young". Caso contrário, será "Old enough".

Comparar diferentes tipos de dados

Comparar dados de tipos diferentes pode gerar resultados inesperados. Ao comparar uma cadeia de caracteres com um número, o JavaScript converte a cadeia de caracteres em um número para fazer a comparação. Uma cadeia de caracteres vazia, por exemplo, é convertida para 0. Uma cadeia de caracteres que contém texto é convertida para NaN, que é false.

Ao comparar duas cadeias de caracteres, "2" será maior que "12", porque, alfabeticamente, 1 é menor que 2. Para obter um resultado correto, as variáveis devem ser convertidas para o tipo de dados certo antes da comparação:

				
					age = Number(age);
					if (isNaN(age)) {
						voteable = "Input is not a number";
					} else {
						voteable = (age < 18) ? "Too young" : "Old enough";
					}

Operador nulo coalescente (??)

O operador ?? retorna o primeiro argumento se ele não for nulo, isto é nulo ou indefinido. Caso contrário, retorna o segundo argumento. Por exemplo:

				
					let name = null;
					let text = "missing";
					let result = name ?? text;

Operador de encadeamento opcional (?.)

O operador ?. retorna undefined se um objeto for indefinido ou nulo, em vez de exibir um erro. Por exemplo:

				
					// Create an object:
					const car = {type:"Fiat", model:"500", color:"white"};
					// Ask for car name:
					document.getElementById("demo").innerHTML = car?.name;

Declarações condicionais

Com muita frequência ao escrever código, podemos querer executar diferentes ações para diferentes condições. Para isso, podemos usar as declarações condicionais. No JavaScript temos as seguintes declarações condicionais:

  • if: define um bloco de código a ser executado se determinada condição for verdadeira.
  • else: define um bloco de código a ser executado se a mesma condição for falsa.
  • else if: define uma nova condição a ser testada se a primeira condição for falsa.
  • switch: define vários blocos de código alternativos a serem executados.

if

Use esta palavra-chave para definir um bloco de código a ser executado se determinada condição for verdadeira.

Sintaxe
						
							if (condição) {
								//  bloco de código a ser executado se determinada condição for verdadeira
							}

Observação: não use maiúsculas na palavra-chave, pois isso pode gerar um erro.

Exemplo
						
							// Make a "Good day" greeting if the hour is less than 18:00:
							if (hour < 18) {
								greeting = "Good day";
							}

else

Use esta palavra-chave para definir um bloco de código a ser executado se a mesma condição definida em if for falsa.

Sintaxe
						
							if (condição) {
								//  código a executar para a condição verdadeira
							} else {
								//  código a executar para a condição falsa
							}
Exemplo
						
							// If the hour is less than 18, create a "Good day" greeting, otherwise "Good evening"
							if (hour < 18) {
								greeting = "Good day";
							} else {
								greeting = "Good evening";
							}

else if

Use estas palavras-chave para definir uma nova condição se a primeira for falsa.

Sintaxe
						
							if (condition1) {
								//  block of code to be executed if condition1 is true
							} else if (condition2) {
								//  block of code to be executed if the condition1 is false and condition2 is true
							} else {
								//  block of code to be executed if the condition1 is false and condition2 is false
							}
Exemplo
						
							// If time is less than 10:00, create a "Good morning" greeting, if not, but time is less than 20:00, create a "Good day" greeting, otherwise a "Good evening"
							if (time < 10) {
								greeting = "Good morning";
							} else if (time < 20) {
								greeting = "Good day";
							} else {
								greeting = "Good evening";
							}

switch

Use esta palavra-chave para realizar diferentes ações com base em diferentes condições. Com ela, é possível selecionar um de vários blocos de código disponíveis para executar.

Sintaxe
						
							switch(expressão) {
								caso x:
									// código a executar
									break;
								caso y:
									// código a executar
									break;
								default:
									// código a executar
							}

Funciona assim:

  • A expressão é avaliada uma vez.
  • O valor da expressão é comparado aos valores de cada caso.
  • Se houver uma correspondência, o bloco de código associado é executado.
  • Se NÃO houver uma correspondência, o bloco de código padrão (default) é executado.

break

Quando o JavaScript atinge a palavra-chave break, ele interrompe a execução de um bloco de código no switch. Não é preciso adicionar esta palavra-chave ao último bloco de código, já que sua execução é interrompida por padrão. Porém, observe que ao omitir esta palavra-chave em um bloco de código, o JavaScript executará o próximo caso mesmo se a avaliação não corresponder ao caso.

default

Esta palavra-chave define o código a ser executado caso não haja correspondência com nenhum outro caso. O caso default não precisa ser o último bloco de código, porém se ele estiver em qualquer outra posição no switch, lembre-se de adicionar a palavra-chave break ao bloco de código.
