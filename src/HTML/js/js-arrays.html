Matrizes

Uma matriz é uma variável especial que pode conter mais de um valor. 

			
				const cars = ["Saab", "Volvo", "BMW"];

Por que usar matrizes?

Armazenar uma lista de variáveis unicamente pode ser muito trabalhoso: 

			
				let car1 = "Saab";
				let car2 = "Volvo";
				let car3 = "BMW";

E se quiséssemos usar um desses itens e nossa lista tivesse 300 itens? É para isso que servem as matrizes!

Ela pode conter muitos valores, com um só nome de variável. E podemos acessar seus valores pelos números de índice.

Para acessar toda a matriz, é só chamar seu nome de variável, como em: 

			
				const cars = ["Saab", "Volvo", "BMW"];
				document.getElementById("demo").innerHTML = cars;

As matrizes são um tipo especial de objeto. O operador typeof retorna "object" para matrizes.

Portanto, para saber se determinada variável é uma matriz, use o método Array.isArray(). Ou use o operador instanceof.

Os elementos de uma matriz podem ser objetos

As variáveis no JavaScript podem ser objetos e as matrizes são um tipo especial de objeto.

Por causa disso, podemos ter tipos diferentes de variáveis na mesma matriz, inclusive objetos, funções e, até, matrizes! 

			
				myArray[0] = Date.now; // myArray contém um objeto Date
				myArray[1] = myFunction; // myArray contém uma função
				myArray[2] = myCars; // myArray contém uma matriz

				console.log(myArray); // [Date.now, myFunction, myCars]

Sintaxe de uma matriz

Use a seguinte sintaxe para criar uma matriz:

const array_name = [item1, item2, ...];

A prática recomendada é declarar uma matriz com const.

O JavaScript não leva em consideração os espaços e as quebras de linha: os itens de uma matriz podem estar em várias linhas. 

			
				const cars = [
					"Saab",
					"Volvo",
					"BMW"
				];

Também é possível criar uma matriz vazia e, depois, fornecer os elementos: 

			
				const cars = [];
					cars[0]= "Saab";
					cars[1]= "Volvo";
					cars[2]= "BMW";

Outra forma de criar matrizes é usando a palavra-chave new: 

			
				const cars = new Array("Saab", "Volvo", "BMW");

Porém, por questão de simplicidade e facilidade para ler o código, recomenda-se não usar a palavra-chave new.

Há também o construtor de matrizes new Array(), mas ele pode (e deve) ser substituído pela sintaxe [], porque pode gerar resultados inesperados.

As duas declarações a seguir geram resultados diferentes:

			
				const points = [40]; // 40
				const points = new Array(40); // undefined

Como acessar os itens de uma matriz

Para acessar os itens de uma matriz, usamos seu número de índice. Vale lembrar que o número de índice no JavaScript começa em 0. 

			
				const cars = ["Saab", "Volvo", "BMW"];
				let car = cars[0];

Para acessar o último elemento, use cars.length - 1.

Acessar todos os itens de uma matriz com um loop

Podemos usar um loop for para acessar todos os itens de uma matriz em uma função, por exemplo. 

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					let fLen = fruits.length;

					let text = "<ul>";
					for (let i = 0; i < fLen; i++) {
						text += "<li>" + fruits[i] + "</li>";
					}
					text += "</ul>";

Ou usando a função Array.forEach():

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];

					let text = "<ul>";
					fruits.forEach(myFunction);
					text += "</ul>";

					function myFunction(value) {
						text += "<li>" + value + "</li>";
					}

O resultado dos dois últimos blocos de código é o mesmo, uma lista de frutas.

Alterar elementos na matriz

A declaração a seguir altera o valor do primeiro elemento na matriz chamada cars: 

			
				const cars = ["Saab", "Volvo", "BMW"];
				cars[0] = "Opel";

				console.log(cars) // ["Opel", "Volvo", "BMW"]

Adicionar elementos a uma matriz

A maneira mais fácil de adicionar elementos a uma matriz é usando o método push(). 

				
					const fruits = ["Banana", "Orange", "Apple"];
					fruits.push("Lemon");  // Adiciona um novo elemento (Lemon) a fruits

Ou podemos adicionar um novo elemento usando a propriedade length.

Adicionar elementos pelo índice pode criar "falhas" na matriz. Sempre observe o comprimento da matriz e adicione o número de índice correto.

Converter uma matriz em uma cadeia de caracteres

O método toString() converte uma matriz em uma cadeia de caracteres, com os valores separados por vírgulas. 

			
				const fruits = ["Banana", "Orange", "Apple", "Mango"];
				document.getElementById("demo").innerHTML = fruits.toString();

				console.log(fruits.toString()) // Banana,Orange,Apple,Mango

Métodos e propriedades de matrizes

A verdadeira utilidade das matrizes no JavaScript são suas propriedades e seus métodos incorporados.

length

Quando usada em uma matriz, esta propriedade retorna seu comprimento, isto é, a quantidade de elementos contidos na matriz. 

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					let length = fruits.length; // 4

toString()

Consulte Converter uma matriz em uma cadeia de caracteres acima.

at()

É o mesmo que usar o número de índice entre colchetes, isto é, retorna o elemento correspondente ao índice.

Há linguagens de programação que permitem o uso de índices negativos, como "[-1]", porém isso não é possível no JavaScript, porque os colchetes são usados para acessar matrizes e objetos. É para isso que serve este método. 

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					let fruit = fruits.at(2); // "Apple"
					let fruit = fruits[2]; // "Apple"

join()

Este método une todos os elementos da matriz em uma cadeia de caracteres. O parâmetro usado entre os parênteses será usado como seu separador. 

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					document.getElementById("demo").innerHTML = fruits.join(" * "); // Banana * Orange * Apple * Mango

pop() e push()

Estes métodos são usados, respectivamente, para remover e adicionar elementos no último índice de uma matriz. Veja também Adicionar elementos a uma matriz.

shift() e unshift()

Esses métodos funcionam como pop() e push(), respectivamente, mas para o primeiro elemento da matriz.

Nos casos de pop() e shift(), usar variável.método() retorna o elemento que foi removido. Nos casos de push() e unshift(), usar variável.método() retorna o comprimento da matriz.

delete()

Não remova elementos de uma matriz. Dê preferência para usar os métodos pop() e shift(), pois este método pode gerar o resultado "undefined" se usado.

concat()

Cria uma nova matriz a partir de duas ou mais matrizes.

				
					const myGirls = ["Cecilie", "Lone"];
					const myBoys = ["Emil", "Tobias", "Linus"];

					const myChildren = myGirls.concat(myBoys); // Cecilie,Lone,Emil,Tobias,Linus

Este método não altera as matrizes existentes, ele cria uma nova. Além disso, é possível usar vários argumentos e, até, cadeias de caracteres: 

				
					const arr1 = ["Cecilie", "Lone"];
					const arr2 = ["Emil", "Tobias", "Linus"];
					const arr3 = ["Robin", "Morgan"];
					const myChildren = arr1.concat(arr2, arr3); // Cecilie,Lone,Emil,Tobias,Linus,Robin,Morgan
					const myChildren = arr1.concat("Peter"); // Cecilie,Lone,Peter

copyWithin()

Copia os elementos de uma matriz para outra posição na mesma matriz, substituindo os valores existentes: 

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					fruits.copyWithin(2, 0); // Copia para a posição 2 todos os elementos a partir do índice 0.

					const fruits = ["Banana", "Orange", "Apple", "Mango", "Kiwi", "Papaya"];
					fruits.copyWithin(2, 0, 2); // Copia para a posição 2 todos os elementos do índice 0 ao 2.

OBSERVAÇÃO: este método substitui os valores existentes, não adiciona itens à matriz e não altera o comprimento da matriz.

flat()

Este método transforma uma matriz multi-dimensional em uma matriz unidimensional: 

				
					const myArr = [[1,2],[3,4],[5,6]];
					const newArr = myArr.flat(); // 1,2,3,4,5,6

flatMap()

Este método mapeia todos os elementos de uma matriz e, depois, cria uma nova matriz unidimensional com os resultados. 

				
					const myArr = [1, 2, 3, 4, 5, 6];
					const newArr = myArr.flatMap(x => [x, x * 10]); // 1,10,2,20,3,30,4,40,5,50,6,60

splice() e slice()

Estes métodos permitem adicionar e remover elementos em uma matriz.

splice() pode ser usado para adicionar ou remover elementos em uma posição específica de uma matriz: 

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					fruits.splice(2, 0, "Lemon", "Kiwi"); // Banana,Orange,Lemon,Kiwi,Apple,Mango

No caso acima, o primeiro parâmetro define onde adicionar os novos elementos, o segundo parâmetro define quantos elementos devem ser removidos e o restante dos parâmetros são os elementos a adicionar. Usar variável.splice() retorna uma matriz com os itens excluídos.

Quando usado de forma correta, o método splice() também pode ser usado para remover elementos da matriz, sem deixar falhas. 

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					fruits.splice(0, 1); // Orange,Apple,Mango

Neste caso, o primeiro parâmetro define onde adicionar os novos elementos e o segundo parâmetro define quantos elementos devem ser removidos. E como não há mais parâmetros, nada é adicionado.

slice() remove o elemento no índice definido no parâmetro entre parênteses e retorna uma nova matriz, sem alterar a matriz original. 

				
					const fruits = ["Banana", "Orange", "Lemon", "Apple", "Mango"];
					const citrus = fruits.slice(3); // Apple,Mango

Este método aceita até dois parâmetros, como em "(1, 3)", sendo o primeiro o índice de início e o segundo o índice de fim, sem incluir este último. No caso de "(1, 3)" no exemplo acima, ficaríamos com: 

				
					const fruits = ["Banana", "Orange", "Lemon", "Apple", "Mango"];
					const citrus = fruits.slice(1, 3); // Orange,Lemon

toSpliced()

Este é um método seguro para cortar (splice) uma matriz sem alterar a matriz original. A diferença entre toSpliced() e splice() é que com este método criamos uma nova matriz, enquanto com splice() altera a matriz original.

toString()

Converte uma matriz em uma cadeia de caracteres separada por vírgulas. É o mesmo que chamar somente o nome de variável da matriz.

indexOf()

Pesquisa pelo valor de um elemento em uma matriz e retorna sua posição. A sintaxe usada é matriz.indexOf(item, início). item é obrigatório, é o termo a pesquisar. início é o índice inicial, que é opcional, mas valores negativos começam a contar na posição definida desde o final da matriz, pesquisando até o final. Se o termo não for encontrado, retorna -1. Se há mais de uma ocorrência, retorna sempre o primeiro resultado. 

				
					const fruits = ["Apple", "Orange", "Apple", "Mango"];
					let position = fruits.indexOf("Apple"); // 0
					let position = fruits.indexOf("Apple", 1); // 2

lastIndexOf()

Pesquisa pelo valor de um elemento em uma matriz e retorna sua última posição. A sintaxe usada é matriz.lastIndexOf(item, início). item é obrigatório, é o termo a pesquisar. início é o índice inicial, que é opcional, mas valores negativos começam a contar na posição definida desde o final da matriz, pesquisando até o começo. Se o termo não for encontrado, retorna -1. Se há mais de uma ocorrência, retorna sempre o primeiro resultado.

includes()

Possibilita verificar se determinado elemento está presente em uma matriz, incluindo NaN, que não é permitido com indexOf(). Sua sintaxe é matriz.includes(item-a-pesquisar).

find()

Retorna o valor do primeiro elemento da matriz que passa em uma função de teste. O exemplo a seguir encontra (isto é, retorna o valor de) o primeiro elemento da matriz que é maior que 18. 

				
					const numbers = [4, 9, 16, 25, 29];
					let first = numbers.find(myFunction);

					function myFunction(value, index, array) {
						return value > 18;
					}

					console.log(first) // 25

Neste caso, a função aceita três argumentos: o valor do item, o índice do item e a matriz a pesquisar.

findIndex()

Retorna o índice do primeiro elemento da matriz que passa em uma função de teste. A função aceita os mesmos argumentos que em find(). O exemplo a seguir encontra o índice do primeiro elemento da matriz que é maior que 18. 

				
					const numbers = [4, 9, 16, 25, 29];
					let first = numbers.findIndex(myFunction);

					function myFunction(value, index, array) {
						return value > 18;
					} // 3

findLast()

Começa a pesquisar pelo final da matriz e retorna o valor do primeiro elemento que satisfaz uma condição. 

				
					const temp = [27, 28, 30, 40, 42, 35, 30];
					let high = temp.findLast(x => x > 40); // 42

findLastIndex()

Faz o mesmo que o método acima, mas retorna o índice correspondente.

sort()

Classifica uma matriz alfabeticamente.

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					fruits.sort();

					console.log(fruits); // Apple,Banana,Mango,Orange

Por padrão, este método classifica os elementos como cadeias de caracteres, porém temos dificuldades com este método para classificar números, já que em uma matriz que contém os números 25 e 100, por exemplo, 100 apareceria antes de 25, porque 2 é maior que 1. Para solucionar esse problema, podemos usar uma função de comparação: 

				
					// Classificar de forma ascendente
					const points = [40, 100, 1, 5, 25, 10];
					points.sort(function(a, b){return a - b});

					console.log(points) // 1,5,10,25,40,100

					// Classificar de forma descendente
					points.sort(function(a, b){return b - a});

					console.log(points) // 100,40,25,10,5,1

A função de comparação retorna um valor negativo, zero ou um valor positivo, dependendo dos parâmetros usados. Ao colocar essa função dentro do método sort(), o método envia o valor à função e classifica o valor retornado. Se o valor é negativo, a é classificado antes de b, se for positivo, b é classificado antes de a, e se for zero o método não altera a ordem de classificação dos dois valores comparados.

Também podemos usar uma função para classificar uma matriz de números em ordem aleatória: 

				
					const points = [40, 100, 1, 5, 25, 10];
					points.sort(function(){return 0.5 - Math.random()}); // 10,25,5,1,100,40
					points.sort(function(){return 0.5 - Math.random()}); // 1,25,5,10,100,40
					points.sort(function(){return 0.5 - Math.random()}); // 5,25,40,10,100,1

Cada ocorrência da função gera uma cadeia de caracteres diferente.

Este método de classificação não é muito preciso, já que favorece alguns números em relação a outros. Para corrigir isto, podemos usar o método de Fisher Yates da seguinte forma: 

				
					const points = [40, 100, 1, 5, 25, 10];

					for (let i = points.length -1; i > 0; i--) {
						let j = Math.floor(Math.random() * (i+1));
						let k = points[i];
						points[i] = points[j];
						points[j] = k;
					}

					console.log(points); // 40,100,1,5,25,10
					console.log(points); // 10,1,40,5,25,100
					console.log(points); // 10,40,100,25,5,1

reverse()

Inverte os elementos de uma matriz.

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					fruits.reverse();

					console.log(fruits); // Mango,Apple,Orange,Banana

Quando combinado com sort(), este método pode ser usado para classificar uma matriz em ordem decrescente.

toSorted()

É o método seguro para classificar uma matriz sem alterar a original. toSorted() cria uma nova matriz, sort() altera a matriz original.

toReversed()

É o método seguro para inverter uma matriz sem alterar a original. toReversed() cria uma nova matriz, reverse() altera a matriz original.

Encontrar o menor e o maior valor da matriz

Não há métodos específicos para encontrar o menor e o maior valor de uma matriz. Entretanto, há três alternativas:

  • Classificar as matriz e ler o primeiro e o último valores, este é a forma menos eficiente
  • Usar os métodos Math.min() e Math.max()
  • Criar uma função exclusiva

Math.min.apply

						
							function myArrayMin(arr) {
								return Math.min.apply(null, arr);
							}

Math.max.apply

						
							function myArrayMax(arr) {
								return Math.max.apply(null, arr);
							}

Função exclusiva

O código abaixo analisa os elementos da matriz e compara cada valor com o menor valor encontrado. 

						
							function myArrayMin(arr) {
								let len = arr.length;
								let min = Infinity;
								while (len--) {
									if (arr[len] < min) {
										min = arr[len];
									}
								}
								return min;
							}

Alterando apenas o símbolo de menor, <, para maior, >, e o nome da variável ("min" para "max"), a função pode ser usada para encontrar o maior valor: 

						
							function myArrayMax(arr) {
								let len = arr.length;
								let max = -Infinity;
								while (len--) {
									if (arr[len] > max) {
										max = arr[len];
									}
								}
								return max;
							}

Classificar objetos de matrizes

No JavaScript, as matrizes podem conter objetos. Mesmo se os objetos forem de diferentes tipos de dados, podemos usar o método sort() para classificar a matriz usando uma função para comparar os valores das propriedades. 

				
					const cars = [
						{type:"Volvo", year:2016},
						{type:"Saab", year:2001},
						{type:"BMW", year:2010}
					];

					cars.sort(function(a, b){return a.year - b.year});
					displayCars();

					function displayCars() {
						cars[0].type + " " + cars[0].year; // Saab 2001
						cars[1].type + " " + cars[1].year; // BMW 2010
						cars[2].type + " " + cars[2].year; // Volvo 2016
					}

Também é possível comparar as cadeias de caracteres em si.

forEach()

Chama uma função de retorno uma vez para cada elemento da matriz. Aceita três argumentos: o valor do item, o índice do item e a matriz a pesquisar. 

				
					const numbers = [45, 4, 9, 16, 25];
					let txt = "";
					numbers.forEach(myFunction);

					function myFunction(value, index, array) {
						txt += value + "
";
					}

map()

Cria uma nova matriz executando uma função em cada elemento da matriz. Este método não executa a função para elementos que não contêm valores e não altera a matriz original. O exemplo a seguir multiplica cada elemento da matriz por 2: 

				
					const numbers1 = [45, 4, 9, 16, 25];
					const numbers2 = numbers1.map(myFunction);

					function myFunction(value, index, array) {
						return value * 2;
					}

flatMap()

Mapeia os elementos de uma matriz multi-dimensional e cria uma matriz unidimensional.

filter()

Cria uma nova matriz com os elementos da matriz original que atendem a uma condição. O exemplo a seguir cria uma matriz com elementos que são maiores que 18: 

				
					const numbers = [45, 4, 9, 16, 25];
					const over18 = numbers.filter(myFunction);

					function myFunction(value, index, array) {
						return value > 18;
					}

reduce() e reduceRight()

Executam uma função em cada elemento de uma matriz para gerar (ou reduzir a) um único valor. reduce() trabalha sempre da esquerda para a direita na matriz e reduceRight(), da direita para a esquerda.

Este método não altera a matriz original. O exemplo a seguir encontra a soma de todos os números na matriz: 

				
					const numbers = [45, 4, 9, 16, 25];
					let sum = numbers.reduce(myFunction);

					function myFunction(total, value, index, array) {
						return total + value;
					}

some()

Verifica se algum (ou alguns) do(s) elemento(s) da matriz atende(m) a uma condição e retorna true ou false. Exemplo.

Array.from()

Cria uma matriz a partir de qualquer objeto com uma propriedade de comprimento ou qualquer objeto que possa ser iterado. 

				
					const myArr = Array.from("ABCDEFG");
					console.log(myArr); // ["A", "B", "C", "D", "E", "F", "G"]

keys()

Retorna um objeto iterador de matriz com as chaves de uma matriz, isto é, retorna os índices. 

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					const keys = fruits.keys();

					for (let x of keys) {
						text += x + "
";
					} // 0, 1, 2, 3

entries()

Cria um iterador de matriz, e itera entre os pares de valor/chave. Este método retorna um objeto com os pares de valor/chave e não altera a matriz original. 

				
					const fruits = ["Banana", "Orange", "Apple", "Mango"];
					const f = fruits.entries();

					for (let x of f) {
						document.getElementById("demo").innerHTML += x;
					}

					///
					Retorna o seguinte:

					0,Banana
					1,Orange
					2,Apple
					3,Mango
					///

with()

É um método seguro para atualizar os elementos de uma matriz sem alterar a matriz original. 

				
					const months = ["Jan", "Feb", "Mar", "Apr"];
					const myMonths = months.with(3, "April"); // ["Jan", "Feb", "Mar", "April"]

O operador de expansão (...)

Este operador expande um objeto iterável (como uma matriz) em mais elementos. 

				
					const q1 = ["Jan", "Feb", "Mar"];
					const q2 = ["Apr", "May", "Jun"];
					const q3 = ["Jul", "Aug", "Sep"];
					const q4 = ["Oct", "Nov", "May"];

					const year = [...q1, ...q2, ...q3, ...q4]; // ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"]

Matrizes associativas

Muitas linguagens de programação aceitam matrizes com índices nomeados, que são chamadas de matrizes associativas (ou hashes). Esse NÃO é o caso do JavaScript, que só aceita matrizes com índices de números.

Ao usar índices nomeados, o JavaScript redefinirá a matriz como um objeto. Devido a isso, alguns métodos e propriedades podem gerar resultados incorretos. 

			
				const person = [];
				person["firstName"] = "John";
				person["lastName"] = "Doe";
				person["age"] = 46;
				person.length;     // Retorna 0
				person[0];         // Retorna undefined

Diferença entre matrizes e objetos

Matrizes usam índices de número, objetos usam índices nomeados.

Use objetos quando precisar que os elementos nomeados sejam cadeias de caracteres (texto), e use matrizes quando precisar que os elementos nomeados sejam números.

Aninhar objetos e matrizes

Os valores de objetos também podem ser matrizes, e vice-versa.

			
				const myObj = {
					name: "John",
					age: 30,
					cars: [
						{name:"Ford", models:["Fiesta", "Focus", "Mustang"]},
						{name:"BMW", models:["320", "X3", "X5"]},
						{name:"Fiat", models:["500", "Panda"]}
					]
				}

Para acessar matrizes dentro de matrizes, use um loop for-in para cada matriz: 

			
				for (let i in myObj.cars) {
					x += "
" + myObj.cars[i].name + "
";
					for (let j in myObj.cars[i].models) {
						x += myObj.cars[i].models[j] + "
";
					}
				}
				
				document.getElementById("demo").innerHTML = x;

Matrizes e a palavra-chave const

Matrizes não são contantes! Apesar de serem declaradas com a palavra chave const, os elementos das matrizes ainda podem ser alterados. A palavra-chave const não define uma matriz constante, mas uma referência constante para uma matriz.

Como vimos, é possível alterar os elementos de uma matriz com os vários métodos apresentados acima. Vejamos uma exemplo: 

			
				// Criar uma matriz constante:
				const cars = ["Saab", "Volvo", "BMW"];

				// Alterar um elemento:
				cars[0] = "Toyota";

				// Adicionar um elemento:
				cars.push("Audi");

Não se esqueça que é preciso declarar a variável (neste caso, uma matriz) ANTES de iniciá-la, isto é, chamá-la. Porém, variáveis (ou matrizes) que usam var podem ser iniciadas antes de serem declaradas. E variáveis declaradas com const têm escopo de bloco, enquanto variáveis criadas com var têm escopo global.

Como redeclarar matrizes

Ao usar var, é possível redeclarar matrizes em qualquer lugar do programa. Entretanto, ao usar const, não é possível redeclarar ou reatribuir uma matriz no mesmo escopo (ou no mesmo bloco), porém é possível fazê-lo em outro escopo.
