Matemática

O objeto Math no JavaScript possibilita realizar cálculos matemáticos com números.

Diferente de outros objetos, o objeto Math não tem construtor, isto é, pode ser usado sem criar um objeto de matemática primeiro. Ele é um objeto estático.

Propriedades de matemática (constantes)

A sintaxe de qualquer propriedade é Math.propriedade. O JavaScript apresenta 8 constantes matemáticas que podem ser acessadas como propriedades:

			
				Math.E        // retorna o número de Euler: 2.718281828459045
				Math.PI       // retorna PI: 3.141592653589793
				Math.SQRT2    // retorna a raiz quadrada de 2: 1.4142135623730951
				Math.SQRT1_2  // retorna a raiz quadrada de 1/2: 0.7071067811865476
				Math.LN2      // retorna o logaritmo natural de 2: 0.6931471805599453
				Math.LN10     // retorna o logaritmo natural de 10: 2.302585092994046
				Math.LOG2E    // retorna o logaritmo de base 2 de E: 1.4426950408889634
				Math.LOG10E   // retorna o logaritmo de base 10 de E: 0.4342944819032518

Métodos de matemática

A sintaxe de qualquer método é Math.método(número).

Math.round()

Arredonda um número para um inteiro. Retorna o inteiro mais próximo:

				
					Math.round(4.6); // 5
					Math.round(4.5); // 5
					Math.round(4.4); // 4

Math.ceil()

Arredonda um número para um inteiro. Retorna o valor do número usado como parâmetro arredondado para cima, para o inteiro mais próximo:

				
					Math.ceil(4.9); // 5
					Math.ceil(4.7); // 5
					Math.ceil(4.4); // 5
					Math.ceil(4.2); // 5
					Math.ceil(-4.2); // -4

Math.floor()

Arredonda um número para um inteiro. Retorna o valor do número usado como parâmetro arredondado para baixo, para o inteiro mais próximo:

				
					Math.floor(4.9); // 4
					Math.floor(4.7); // 4
					Math.floor(4.4); // 4
					Math.floor(4.2); // 4
					Math.floor(-4.2); // -5

Math.trunc()

Arredonda um número para um inteiro. Retorna a parte do número usado como parâmetro que é o inteiro:

				
					Math.trunc(4.9); // 4
					Math.trunc(4.7); // 4
					Math.trunc(4.4); // 4
					Math.trunc(4.2); // 4
					Math.trunc(-4.2); // -4

Math.sign()

Retorna se o número usado como parâmetro é negativo, nulo ou positivo:

				
					Math.sign(-4); // -1
					Math.sign(0); // 0
					Math.sign(4); // 1

Math.pow()

Sintaxe: Math.pow(x, y). Retorna o valor de x elevado à potência de y.

				
					Math.pow(8, 2); // 64

Math.sqrt()

Sintaxe: Math.sqrt(x). Retorna a raiz quadrada de x.

				
					Math.sqrt(64); // 8

Math.abs()

Sintaxe: Math.abs(x). Retorna o valor absoluto (positivo) de x.

				
					Math.abs(-4.7); // 4.7

Math.sin()

Sintaxe: Math.sin(x). Retorna o seno (um valor entre -1 e 1) do ângulo x fornecido em radianos.

É possível usar graus ao invés de radianos, mas é preciso converter o valor: ângulo em radianos = ângulo em graus * PI / 180.

				
					Math.sin(90 * Math.PI / 180); // retorna 1 (o seno de 90 graus)

Math.cos()

Sintaxe: Math.cos(x). Retorna o cosseno (um valor entre -1 e 1) do ângulo x fornecido em radianos.

É possível usar graus ao invés de radianos, mas é preciso converter o valor: ângulo em radianos = ângulo em graus * PI / 180.

				
					Math.cos(0 * Math.PI / 180); // retorna 1 (o cosseno de 0 graus)

Math.min() e Math.max()

Estes métodos podem ser usados para encontrar o menor e o maior valor, respectivamente, em uma lista de parâmetros.

				
					Math.min(0, 150, 30, 20, -8, -200); // -200
					Math.max(0, 150, 30, 20, -8, -200); // 150

Math.random()

Retorna um número aleatório entre 0 (inclusive) e 1 (exclusive). Sempre retorna um número menor que 1.

				
					Math.random(); // 0.9880070722302903
					Math.random(); // 0.14077480138770215
					Math.random(); // 0333259767720322

Você pode usar Math.random() com Math.floor() para obter números inteiros aleatórios. Porém, lembre-se que estamos falando apenas de números sem casas decimais, não números inteiros reais. Vejamos um exemplo:

				
					// Retorna um inteiro aleatório de 0 a 9
					Math.floor(Math.random() * 10); // 0, 4, 5...

					// Retorna um inteiro aleatório de 0 a 10:
					Math.floor(Math.random() * 11); // 9, 6, 1...

					// Retorna um inteiro aleatório de 0 a 99:
					Math.floor(Math.random() * 100); // 79, 81, 73...

					// Retorna um inteiro aleatório de 0 a 100:
					Math.floor(Math.random() * 101); // 66, 80, 42...

					// Retorna um inteiro aleatório de 1 a 10:
					Math.floor(Math.random() * 10) + 1; // 2, 1, 6...

					// Retorna um inteiro aleatório de 1 a 100:
					Math.floor(Math.random() * 100) + 1; // 86, 12, 45...

Uma função verdadeiramente aleatória

Como podemos ver nos exemplos acima, é uma boa ideia criar uma função verdadeiramente aleatória para lidar com propósitos de inteiros aleatórios. Uma função dessa sempre retorna um número aleatório entre os valores mínimo (inclusive) e máximo (exclusive). Por exemplo:

					
						function getRndInteger(min, max) {
							return Math.floor(Math.random() * (max - min) ) + min;
						}

						// 34, 677, 379...

A função abaixo retorna um número aleatório entre os valores mínimo e máximo (ambos inclusos):

					
						function getRndInteger(min, max) {
							return Math.floor(Math.random() * (max - min + 1) ) + min;
						}

						// 45, 60, 73...

Math.log()

Sintaxe: Math.log(x). Retorna o logaritmo natural de x. O logaritmo natural retorna o tempo necessário para atingir um certo valor de crescimento:

				
					Math.log(1); // 0
					Math.log(2); // 0.6931471805599453
					Math.log(3); // 1.0986122886681096

Math.E e Math.log() são gêmeos. Por exemplo, quantas vezes precisamos multiplicar Math.E para obter 10?

				
					Math.log(10); // 2.302585092994046

Math.log2()

Sintaxe: Math.log2(x). Retorna o logaritmo de base 2 de x. Por exemplo, quantas vezes precisamos multiplicar 2 para obter 8?

				
					Math.log2(8); // 3

Math.log10()

Sintaxe: Math.log10(x). Retorna o logaritmo de base 10 de x. Por exemplo, quantas vezes precisamos multiplicar 10 para obter 1000?

				
					Math.log10(1000); // 3

cbrt(x) Retorna a raiz cúbica de x

cosh(x) Retorna o cosseno hiperbólico de x
exp(x) Retorna o valor de Ex
floor(x) Retorna x arredondado para o inteiro mais próximo abaixo
log(x) Retorna o logaritmo natural (base E) de x

pow(x, y) Retorna o valor de x à potência de y
random() Retorna um número aleatório entre 0 e 1
round(x) Arredonda x para o inteiro mais próximo
sign(x) Retorna se x é negativo, nulo ou positivo (-1, 0, 1)
sin(x) Retorna o seno de x (x deve estar em radianos ou ser convertido)
sinh(x) Retorna o seno hiperbólico de x
sqrt(x) Retorna a raiz quadrada de x
