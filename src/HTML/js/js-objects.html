Objetos

Na vida real, objetos são coisas, como casas, carros, pessoas, animais ou qualquer outro. Vamos pegar o exemplo de um carro:

Objeto Propriedades Métodos
Carro
car.name = Fiat
car.model = 500
car.weight = 850 Kg
car.color = white		 car.start()
car.drive()
car.brake()
car.stop()

As propriedades de um carro de verdade são coisas como peso e cor. Todos os objetos "carro" têm as mesmas propriedades, mas valores diferentes para elas.

Os métodos de um carro de verdade são coisas como partida e frear. Todos os objetos "carro" têm os mesmos métodos, mas eles acontecem em momentos diferentes.

Objetos vs. variáveis

Variáveis em JavaScript são contêineres de dados. Objetos também são variáveis, mas eles contêm muitos valores:

			
				// Uma variável comum:
				let car = "Fiat";

				// Um objeto:
				const car = {type:"Fiat", model:"500", color:"white"};

Costuma-se declarar objetos com a palavra-chave const.

Definição de objetos

Definir objetos usando literais

Uma "literal de objeto" (ou um inicializador de objeto) é uma lista de pares de nome:valor (ou chave:valor) dentro de chaves ({ }). Por exemplo:

			
				{firstName:"John", lastName:"Doe", age:50, eyeColor:"blue"}

Ao declarar uma literal de objeto, os espaços e quebras de linha não têm efeito. É como se tudo estivesse em uma só linha.

Também é possível criar um objeto vazio e adicionar propriedades a ele posteriormente: 

			
				// Criar o objeto
				const person = {};

				// Adicionar as propriedades
				person.firstName = "John";
				person.lastName = "Doe";
				person.age = 50;
				person.eyeColor = "blue";

Definir objetos usando a palavra-chave new

A sintaxe usando a palavra-chave new é similar à usar literais:

			
				// Criar o objeto
				const person = new Object();

				// Adicionar as propriedades
				person.firstName = "John";
				person.lastName = "Doe";
				person.age = 50;
				person.eyeColor = "blue";

Portanto, é melhor usar o método das literais para definir objetos, já que isso melhora a leitura do código, sua simplicidade e velocidade de execução.

Propriedades de um objeto

Em objetos de JavaScript, os valores nomeados se chamam propriedades.

Um objeto é um conjunto não ordenado de propriedades. As propriedades são a parte mais importante de um objeto em JavaScript. Elas podem ser alteradas, adicionadas e excluídas, e algumas são apenas para leitura.

Propriedade Valor
firstName John
lastName Doe
age 50
eyeColor blue

Objetos escritos com pares de nome e valor são similares a:

  • Matrizes associativas em PHP
  • Dicionários em Python
  • Tabelas hash em C
  • Mapas hash em Java
  • Hashes em Ruby e Perl

Como acessar as propriedades de um objeto

Há duas maneiras de acessar as propriedades de um objeto. Pela notação de ponto:

			
				nomeObjeto.nomePropriedade

E pela notação de colchetes:

			
				nomeObjeto["nomePropriedade"]

Também é possível atribuir uma variável a uma propriedade e chamar a variável nas notações mencionadas acima.

Como adicionar novas propriedades

Para adicionar novas propriedades a um objeto existente, só é preciso fornecer um valor:

			
				// nomeObjeto.nomePropriedade = "valor";
				person.nationality = "English";

Como excluir propriedades

Use a palavra-chave delete para excluir propriedades de um objeto:

			
				const person = {
					firstName: "John",
					lastName: "Doe",
					age: 50,
					eyeColor: "blue"
				};
				
				delete person.age;
				// ou delete person["age"];

Esta palavra-chave exclui o valor e a propriedade em si. Para usar a propriedade novamente após a exclusão, é preciso adicioná-la novamente ao objeto.

Objetos aninhados

Os valores de uma propriedade também podem ser objetos.

			
				myObj = {
					name:"John",
					age:30,
					myCars: {
						car1:"Ford",
						car2:"BMW",
						car3:"Fiat"
					}
				}

E essas propriedades aninhadas podem ser acessadas com notação de ponto ou de colchete:

			
				myObj.myCars;
				myObj.myCars.car1;
				myObj["myCars"]["car3"];

Métodos de objeto

Métodos são ações que se pode realizar em objetos. São definições de funções armazenadas como valores de propriedades.

Propriedade Valor da propriedade
firstName John
lastName Doe
age 50
eyeColor blue
fullName function() {return self.firstName + " " + self.lastName;}

No exemplo acima, self refere-se ao objeto da pessoa. Quer dizer, self.firstName e self.lastName referem-se, respectivamente, a firstName e lastName da pessoa.

Note que self não é tão amplamente usado mais, a prática recomendada é usar self. Porém, é importante observar que esta pode ser qualquer palavra, como "s_", "proto$", "item", "instance",etc.

Como acessar métodos de um objeto

Use a sintaxe nomeObjeto.nomeMétodo() para acessar os métodos de um objeto. Chamar uma propriedade seguida de parênteses, como em person.firstName(), faz com que a propriedade seja executada como uma função, e usa a mesma sintaxe com chaves. Acessar uma propriedade sem os parênteses, como em person.firstName, retorna a definição da função, ou o código em si.

Adicionar um método a um objeto

É muito fácil adicionar um método a um objeto:

			
				person.name = function () {
					return self.firstName + " " + self.lastName;
				};

Como usar métodos

O exemplo a seguir usa o método to UpperCase() para converter um texto para letras maiúsculas:

			
				person.name = function () {
					return (self.firstName + " " + self.lastName).toUpperCase();
				};

Primitivos

Um valor primitivo não tem propriedades ou métodos. 3.14 é um valor primitivo.

Um tipo de dado primitivo é um dado que tem um valor primitivo. O JavaScript tem 7 tipos de dados primitivos:

  • string
  • number
  • boolean
  • null
  • undefined
  • symbol
  • bigint

Valores primitivos são imutáveis, isto é não podem ser alterados, são "hardcoded". Se x = 3.14, é possível alterar o valor de x, mas não o de 3.14.

Objetos são mutáveis

Objetos são mutáveis porque são chamados pela referência, não pelo valor.

Se "pessoa" é um objeto, a declaração a seguir não cria uma cópia de "pessoa".

			
				const x = person;

O objeto x não é uma cópia de "pessoa", o objeto x é pessoa. O objeto x e o objeto pessoa têm o mesmo endereço na memória. Quaisquer alterações feitas a x, também alteram pessoa:

			
				// Criar um objeto
				const person = {
					firstName:"John",
					lastName:"Doe",
					age:50, eyeColor:"blue"
				}

				// Criar uma cópia
				const x = person;

				// Alterar a idade em ambos
				x.age = 10;

Exibição de objetos

Se tentarmos inserir um objeto no HTML, o JavaScript escreve, literalmente, "[object Object]". Para evitar isso, devemos fazer uma das seguintes coisas:

  • Exibir a propriedade do objeto
  • Exibir as propriedades do objeto em um loop
  • Exibir o objeto chamando Object.values()
  • Exibir o objeto usando JSON.stringify()

Exibir as propriedades de um objeto

As propriedades de um objeto podem ser exibidas como uma sequência de caracteres:

			
				// Criar um objeto
				const person = {
					name: "John",
					age: 30,
					city: "New York"
				};

				// Exibir as propriedades
				document.getElementById("demo").innerHTML =
				person.name + "," + person.age + "," + person.city;

Exibir as propriedades de um objeto em um loop

Pode-se usar um loop para chamar as propriedades de um objeto.

			
				// Criar um objeto
				const person = {
					name: "John",
					age: 30,
					city: "New York"
				};

				// Criar o texto
				let text = "";
				for (let x in person) {
					text += person[x] + " ";
				};

				// Exibir o texto
				document.getElementById("demo").innerHTML = text;

Observação: é obrigatório usar person[x] no loop. person.x não funciona, porque x é a variável do loop.

Exibir o objeto chamando Object.values()

Isso cria uma matriz para os valores das propriedades:

			
				// Criar um objeto
				const person = {
					name: "John",
					age: 30,
					city: "New York"
				};

				// Criar uma matriz
				const myArray = Object.values(person);

				// Exibir a matriz
				document.getElementById("demo").innerHTML = myArray;

Também é possível usar Object.entries() para facilitar o uso do objeto com um loop:

			
				const fruits = {Bananas:300, Oranges:200, Apples:500};

				let text = "";
				for (let [fruit, value] of Object.entries(fruits)) {
					text += fruit + ": " + value + "
";
				}

Exibir o objeto usando JSON.stringify()

Objetos JavaScript podem ser convertidos em uma sequência de caracteres com o método JSON JSON.stringify(). Ele está incluso com o JavaScript e é aceito pela maioria dos navegadores. O resultado deste método será uma sequência de caracteres em notação JSON: {"name":"John","age":50,"city":"New York"}.

			
				// Criar um objeto
				const person = {
					name: "John",
					age: 30,
					city: "New York"
				};

				// Usar stringify
				let myString = JSON.stringify(person);

				// Exibir a sequência de caracteres
				document.getElementById("demo").innerHTML = myString;

Funções construtoras de objetos

Algumas vezes precisamos criar várias funções do mesmo tipo. Para criar um tipo de objeto, usamos funções construtoras de objetos. A prática recomendada é começar o nome da função deve com letra maiúscula. Por exemplo:

			
				// Função construtora para os objetos de pessoa
				function Person(first, last, age, eye) {
					self.firstName = first;
					self.lastName = last;
					self.age = age;
					self.eyeColor = eye;
				}

				// Criar dois objetos de pessoa
				const myFather = new Person("John", "Doe", 50, "blue");
				const myMother = new Person("Sally", "Rally", 48, "green");

				// Exibir a idade
				document.getElementById("demo").innerHTML =
				"My father is " + myFather.age + " years old. My mother is " + myMother.age + " years old.";

Valores padrão de propriedades

Um valor fornecido para uma propriedade será o valor padrão para todos os objetos criados pelo construtor. Por exemplo:

			
				function Person(first, last, age, eyecolor) {
					self.firstName = first;
					self.lastName = last;
					self.age = age;
					self.eyeColor = eyecolor;
					self.nationality = "English";
				}

Neste caso, todos os objetos criados terão a nacionalidade "English".

Adicionar uma nova propriedade a um objeto

Após criar o construtor, para adicionar uma nova propriedade, é só fazer o seguinte:

			
				// Função construtora para objetos de pessoa
				function Person(first, last, age, eye) {
					self.firstName = first;
					self.lastName = last;
					self.age = age;
					self.eyeColor = eye;
				}

				// Criar dois objetos de pessoa
				const myFather = new Person("John", "Doe", 50, "blue");
				const myMother = new Person("Sally", "Rally", 48, "green");

				// Adicionar a nacionalidade ao primeiro objeto
				myFather.nationality = "English";

				// Exibir a nacionalidade
				document.getElementById("demo").innerHTML =
				"My father is " + myFather.nationality;

Note que a nova propriedade é adicionada somente ao objeto myFather, e a nenhum outro.

Adicionar uma nova propriedade a todos os objetos

NÃO é possível adicionar uma nova propriedade a um construtor de objetos. Em vez disso, é preciso adicioná-la ao protótipo da função construtora:

			
				// NÃO podemos fazer isto
				Person.nationality = "English";

				// Mas podemos fazer isto
				Person.prototype.nationality = "English";

Métodos construtores de objetos

Uma função construtora também pode ter métodos:

			
				function Person(first, last, age, eyecolor) {
					self.firstName = first;
					self.lastName = last;
					self.age = age;
					self.eyeColor = eyecolor;
					self.fullName = function() {
						return self.firstName + " " + self.lastName;
					};
				}

Adicionar um método a um objeto

			
				myMother.changeName = function (name) {
					self.lastName = name;
				}

Adicionar um método a todos os objetos

Não é possível adicionar um método a uma função construtora de objeto, isso gera um erro (TypeError). É preciso adicionar o método ao protótipo da função construtora:

			
				// Não podemos fazer isto
				Person.changeName = function (name) {
					self.lastName = name;
				}
				
				myMother.changeName("Doe"); //TypeError: myMother.changeName is not a function

				// Mas podemos fazer isto
				Person.prototype.changeName = function (name) {
					self.lastName = name;
				}
				
				myMother.changeName("Doe");

A função changeName() atribui o valor de name à propriedade lastName da pessoa, substituindo self por myMother.

Construtores que acompanham o JavaScript

O JavaScript já tem construtores para todos os objetos:

  • new Object(): cria um objeto em um Objeto
  • new Array(): cria um objeto de Matriz
  • new Map(): cria um objeto de Mapa
  • new Set(): cria um objeto de Conjunto
  • new Date(): cria um objeto de Data
  • new RegExp(): cria um objeto de Expressão Regular
  • new Function(): cria um objeto de Função

O objeto Math() não está na lista porque é um objeto global. A palavra-chave new não pode ser usada com Math.
