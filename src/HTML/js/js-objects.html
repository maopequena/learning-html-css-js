Objetos

Na vida real, objetos são coisas, como casas, carros, pessoas, animais ou qualquer outro. Vamos pegar o exemplo de um carro:

Objeto Propriedades Métodos
carro
carro.nome = Fiat
carro.modelo = 500
carro.peso = 850 Kg
carro.cor = white		 carro.partida()
carro.dirigir()
carro.frear()
carro.desligar()

As propriedades de um carro de verdade são coisas como peso e cor. Todos os objetos "carro" têm as mesmas propriedades, mas valores diferentes para elas.

Os métodos de um carro de verdade são coisas como partida e frear. Todos os objetos "carro" têm os mesmos métodos, mas eles acontecem em momentos diferentes.

Objetos vs. variáveis

Variáveis em JavaScript são contêineres de dados. Objetos também são variáveis, mas eles contêm muitos valores:

				
					// Uma variável comum:
					let carro = "Fiat";

					// Um objeto:
					const carro = {tipo:"Fiat", modelo:"500", cor:"white"};

Costuma-se declarar objetos com a palavra-chave const.

Definição de objetos

Os métodos para definir objetos no JavaScript são:

  • Usar um literal de objeto
  • Usar a palavra-chave new
  • Usar um construtor de objeto
  • Usar Object.assign()
  • Usar Object.create()
  • Usar Object.fromEntries()

Definir objetos usando literais

Uma "literal de objeto" (ou um inicializador de objeto) é uma lista de pares de nome:valor (ou chave:valor) dentro de chaves ({ }). Por exemplo:

					
						{primeiroNome:"John", sobrenome:"Doe", idade:50, corOlhos:"azul"}

Ao declarar uma literal de objeto, os espaços e quebras de linha não têm efeito. É como se tudo estivesse em uma só linha.

Também é possível criar um objeto vazio e adicionar propriedades a ele posteriormente: 

					
						// Criar o objeto
						const pessoa = {};

						// Adicionar as propriedades
						pessoa.primeiroNome = "John";
						pessoa.sobrenome = "Doe";
						pessoa.idade = 50;
						pessoa.corOlhos = "azul";

Definir objetos usando a palavra-chave new

A sintaxe usando a palavra-chave new é similar a usar literais:

					
						// Criar o objeto
						const pessoa = new Object();

						// Adicionar as propriedades
						pessoa.primeiroNome = "John";
						pessoa.sobrenome = "Doe";
						pessoa.idade = 50;
						pessoa.corOlhos = "azul";

Portanto, é melhor usar o método das literais para definir objetos, já que isso melhora a leitura do código, sua simplicidade e velocidade de execução.

Propriedades de um objeto

Em objetos de JavaScript, os valores nomeados se chamam propriedades.

Um objeto é um conjunto não ordenado de propriedades. As propriedades são a parte mais importante de um objeto em JavaScript. Elas podem ser alteradas, adicionadas e excluídas, e algumas são apenas para leitura.

Propriedade Valor
primeiroNome John
sobrenome Doe
idade 50
corOlhos azul

Objetos escritos com pares de nome e valor são similares a:

  • Matrizes associativas em PHP
  • Dicionários em Python
  • Tabelas hash em C
  • Mapas hash em Java
  • Hashes em Ruby e Perl

Como acessar as propriedades de um objeto

Há duas maneiras de acessar as propriedades de um objeto. Pela notação de ponto:

					
						nomeObjeto.nomePropriedade

E pela notação de colchetes:

					
						nomeObjeto["nomePropriedade"]

Também é possível atribuir uma variável a uma propriedade e chamar a variável com as notações mencionadas acima.

Como adicionar novas propriedades

Para adicionar novas propriedades a um objeto existente, só é preciso fornecer um valor:

					
						// nomeObjeto.nomePropriedade = "valor";
						pessoa.nacionalidade = "Britânico";

Como excluir propriedades

Use a palavra-chave delete para excluir propriedades de um objeto:

					
						const pessoa = {
							primeiroNome: "John",
							sobrenome: "Doe",
							idade: 50,
							corOlhos: "azul"
						};
						
						delete pessoa.idade;
						// ou delete pessoa["idade"];

Esta palavra-chave exclui o valor e a propriedade em si. Para usar a propriedade após a exclusão, é preciso adicioná-la novamente ao objeto.

Objetos aninhados

Os valores de uma propriedade também podem ser objetos.

				
					meuObjeto = {
						nome:"John",
						idade:30,
						meusCarros: {
							carro1:"Ford",
							carro2:"BMW",
							carro3:"Fiat"
						}
					}

E essas propriedades aninhadas podem ser acessadas com notação de ponto ou de colchete:

				
					meuObjeto.meusCarros;
					meuObjeto.meusCarros.carro1;
					meuObjeto["meusCarros"]["carro3"];

Métodos de objeto

Métodos são ações que se pode realizar em objetos. São definições de funções armazenadas como valores de propriedades.

Propriedade Valor da propriedade
primeiroNome John
sobrenome Doe
idade 50
corOlhos azul
nomeCompleto function() {return self.primeiroNome + " " + self.sobrenome;}

No exemplo acima, self refere-se ao objeto da pessoa. Quer dizer, self.primeiroNome e self.sobrenome referem-se, respectivamente, a primeiroNome e sobrenome da pessoa.

Note que self não é tão amplamente usado mais, a prática recomendada é usar self. Porém, é importante observar que esta pode ser qualquer palavra, como "s_", "proto$", "item", "instance", etc.

Como acessar métodos de um objeto

Use a sintaxe nomeObjeto.nomeMétodo() para acessar os métodos de um objeto. Chamar uma propriedade seguida de parênteses, como em pessoa.primeiroNome(), faz com que a propriedade seja executada como uma função, e usa a mesma sintaxe com chaves. Acessar uma propriedade sem os parênteses, como em pessoa.primeiroNome, retorna a definição da função, ou o código em si.

Adicionar um método a um objeto

É muito fácil adicionar um método a um objeto:

					
						pessoa.nome = function () {
							return self.primeiroNome + " " + self.sobrenome;
						};

Como usar métodos

O exemplo a seguir usa o método to UpperCase() para converter um texto para letras maiúsculas:

					
						pessoa.nome = function () {
							return (self.primeiroNome + " " + self.sobrenome).toUpperCase();
						};

Primitivos

Um valor primitivo não tem propriedades ou métodos. 3.14 é um valor primitivo.

Um tipo de dado primitivo é um dado que tem um valor primitivo. O JavaScript tem 7 tipos de dados primitivos:

  • string (cadeia de caracteres)
  • number (número)
  • boolean (booleano)
  • null (nulo)
  • undefined (indefinido)
  • symbol (símbolo)
  • bigint (inteiro grande)

Valores primitivos são imutáveis, isto é não podem ser alterados, são "hardcoded". Se x = 3.14, é possível alterar o valor de x, mas não o de 3.14.

Objetos são mutáveis

Objetos são mutáveis porque são chamados pela referência, não pelo valor.

Se "pessoa" é um objeto, a declaração a seguir não cria uma cópia de "pessoa".

				
					const x = pessoa;

O objeto x não é uma cópia de "pessoa", o objeto x é pessoa. O objeto x e o objeto pessoa têm o mesmo endereço na memória. Quaisquer alterações feitas a x, também alteram pessoa:

				
					// Criar um objeto
					const pessoa = {
						primeiroNome:"John",
						sobrenome:"Doe",
						idade:50, corOlhos:"azul"
					}

					// Criar uma cópia
					const x = pessoa;

					// Alterar a idade em ambos
					x.idade = 10;

Exibição de objetos

Se tentarmos inserir um objeto no HTML, o JavaScript escreve, literalmente, "[object Object]". Para evitar isso, devemos fazer uma das seguintes coisas:

  • Exibir a propriedade do objeto
  • Exibir as propriedades do objeto em um loop
  • Exibir o objeto chamando Object.values()
  • Exibir o objeto usando JSON.stringify()

Exibir as propriedades de um objeto

As propriedades de um objeto podem ser exibidas como uma sequência de caracteres:

					
						// Criar um objeto
						const pessoa = {
							nome: "John",
							idade: 30,
							cidade: "Nova York"
						};

						// Exibir as propriedades
						document.getElementById("demo").innerHTML =
						pessoa.nome + "," + pessoa.idade + "," + pessoa.cidade;

Exibir as propriedades de um objeto em um loop

Pode-se usar um loop para chamar as propriedades de um objeto.

					
						// Criar um objeto
						const pessoa = {
							nome: "John",
							idade: 30,
							cidade: "Nova York"
						};

						// Criar o texto
						let texto = "";
						for (let x in pessoa) {
							texto += pessoa[x] + " ";
						};

						// Exibir o texto
						document.getElementById("demo").innerHTML = texto;

Observação: é obrigatório usar pessoa[x] no loop. pessoa.x não funciona, porque x é a variável do loop.

Exibir o objeto chamando Object.values()

Isso cria uma matriz para os valores das propriedades:

					
						// Criar um objeto
						const pessoa = {
							nome: "John",
							idade: 30,
							cidade: "Nova York"
						};

						// Criar uma matriz
						const minhaMatriz = Object.values(pessoa);

						// Exibir a matriz
						document.getElementById("demo").innerHTML = minhaMatriz;

Também é possível usar Object.entries() para facilitar o uso do objeto com um loop:

					
						const frutas = {Bananas:300, Laranjas:200, Macas:500};

						let texto = "";
						for (let [fruta, valor] of Object.entries(frutas)) {
							texto += fruta + ": " + valor + "
";
						}

Exibir o objeto usando JSON.stringify()

Objetos JavaScript podem ser convertidos em uma sequência de caracteres com o método JSON.stringify(). Ele está incluso com o JavaScript e é aceito pela maioria dos navegadores. O resultado deste método será uma sequência de caracteres em notação JSON: {"nome":"John","idade":50,"cidade":"Nova York"}.

					
						// Criar um objeto
						const pessoa = {
							nome: "John",
							idade: 30,
							cidade: "Nova York"
						};

						// Usar stringify
						let minhaString = JSON.stringify(pessoa);

						// Exibir a sequência de caracteres
						document.getElementById("demo").innerHTML = minhaString;

Funções construtoras de objetos

Algumas vezes precisamos criar várias funções do mesmo tipo. Para criar um tipo de objeto, usamos funções construtoras de objetos. A prática recomendada é começar o nome da função deve com letra maiúscula. Por exemplo:

				
					// Função construtora para o objeto "pessoa"
					function Pessoa(nome, sobrenome, idade, olhos) {
						this.primeiroNome = nome;
						this.sobrenome = sobrenome;
						this.idade = idade;
						this.corOlhos = olhos;
					}

					// Agora é possível usar new Pessoa() para criar vários objetos de pessoas.

					// Criar objetos de pessoa
					const meuPai = new Pessoa("John", "Doe", 50, "azul");
					const minhaMae = new Pessoa("Sally", "Rally", 48, "verde");
					const minhaIrma = new Pessoa("Anna", "Rally", 18, "verde");
					const euMesmo = new Pessoa("Johnny", "Rally", 22, "verde");

					// Exibir a idade
					document.getElementById("demo").innerHTML =
					"Meu pai tem " + meuPai.idade + " anos. Minha mãe tem " + minhaMae.idade + " anos.";

Valores padrão de propriedades

Um valor fornecido para uma propriedade será o valor padrão para todos os objetos criados pelo construtor. Por exemplo:

					
						function Pessoa(nome, sobrenome, idade, corOlhos) {
							self.primeiroNome = nome;
							self.sobrenome = sobrenome;
							self.idade = idade;
							self.corOlhos = corOlhos;
							self.nacionalidade = "britânico";
						}

Neste caso, todos os objetos criados terão a nacionalidade "britânico".

Adicionar uma nova propriedade a um objeto

Após criar o construtor, para adicionar uma nova propriedade, é só fazer o seguinte:

					
						// Função construtora para o objeto "pessoa"
						function Pessoa(nome, sobrenome, idade, olhos) {
							self.primeiroNome = nome;
							self.sobrenome = sobrenome;
							self.idade = idade;
							self.corOlhos = olhos;
						}

						// Criar dois objetos de pessoa
						const meuPai = new Pessoa("John", "Doe", 50, "azul");
						const minhaMae = new Pessoa("Sally", "Rally", 48, "verde");

						// Adicionar a nacionalidade ao primeiro objeto
						meuPai.nacionalidade = "britânico";

						// Exibir a nacionalidade
						document.getElementById("demo").innerHTML =
						"My eu pai é " + meuPai.nacionalidade;

Note que a nova propriedade é adicionada somente ao objeto meuPai, e a nenhum outro.

Adicionar uma nova propriedade a todos os objetos

NÃO é possível adicionar uma nova propriedade a um construtor de objetos. Em vez disso, é preciso adicioná-la ao protótipo da função construtora:

					
						// NÃO podemos fazer isto
						Pessoa.nacionalidade = "britânico";

						// Mas podemos fazer isto
						Pessoa.prototype.nacionalidade = "britânico";

Métodos construtores de objetos

Uma função construtora também pode ter métodos:

				
					function Pessoa(nome, sobrenome, idade, corOlhos) {
						self.primeiroNome = nome;
						self.sobrenome = sobrenome;
						self.idade = idade;
						self.corOlhos = corOlhos;
						self.nomeCompleto = function() {
							return self.primeiroNome + " " + self.sobrenome;
						};
					}

Adicionar um método a um objeto

					
						minhaMae.alterarNome = function (nome) {
							self.sobrenome = nome;
						}

Adicionar um método a todos os objetos

Não é possível adicionar um método a uma função construtora de objeto, isso gera um erro (TypeError). É preciso adicionar o método ao protótipo da função construtora:

					
						// Não podemos fazer isto
						Pessoa.alterarNome = function (nome) {
							self.sobrenome = nome;
						}
						
						minhaMae.alterarNome("Doe"); // TypeError: minhaMae.alterarNome is not a function

						// Mas podemos fazer isto
						Pessoa.prototype.alterarNome = function (nome) {
							self.sobrenome = nome;
						}
						
						minhaMae.alterarNome("Doe");

A função alterarNome() atribui o valor de nome à propriedade sobrenome da pessoa, substituindo self por minhaMae.

Construtores que acompanham o JavaScript

O JavaScript já tem construtores para todos os objetos:

  • new Object(): cria um objeto em um Objeto
  • new Array(): cria um objeto de Matriz
  • new Map(): cria um objeto de Mapa
  • new Set(): cria um objeto de Conjunto
  • new Date(): cria um objeto de Data
  • new RegExp(): cria um objeto de Expressão Regular
  • new Function(): cria um objeto de Função

O objeto Math() não está na lista porque é um objeto global. A palavra-chave new não pode ser usada com Math.

Você sabia?

Use literais de objeto ({}) em vez de new Object().

Use literais de matriz ([]) em vez de new Array().

Use literais de padrão (/()/) em vez de new RegExp().

Use expressões de função (() {}) em vez de new Function().

Métodos de objetos

Métodos de objeto no JavaScript podem ser agrupados em:

  • Métodos gerais
  • Métodos de gestão de propriedades
  • Métodos de proteção de objetos

Métodos gerais

					
						// Copia as propriedades de um objeto para outro
						Object.assign(destino, origem)

						// Cria um objeto a partir de outro já existente
						Object.create(objeto)

						// Retorna uma matriz de pares chave/valor de um objeto
						Object.entries(objeto)

						// Cria um objeto a partir de uma lista de pares chave/valor
						Object.fromEntries()

						// Retorna uma matriz das chaves de um objeto
						Object.keys(objeto)

						// Retorna uma matriz dos valores de propriedades de um objeto
						Object.values(objeto)

						// Agrupa elementos de um objeto de acordo com uma função
						Object.groupBy(objeto, retorno)

Saiba mais sobre Métodos gerais de objetos no JavaScript.

Métodos de gestão de propriedades

					
						// Adicionar ou alterar uma propriedade de objeto
						Object.defineProperty(objeto, propriedade, descritor)

						// Adicionar ou alterar propriedades de um objeto
						Object.defineProperties(objeto, descritores)

						// Acessar uma propriedade
						Object.getOwnPropertyDescriptor(objeto, propriedade)

						// Acessar propriedades
						Object.getOwnPropertyDescriptors(objeto)

						// Retornar todas as propriedades como uma matriz
						Object.getOwnPropertyNames(objeto)

						// Acessar o protótipo
						Object.getPrototypeOf(objeto)

Saiba mais sobre Métodos de gestão de propriedades de objetos.

Métodos de proteção de objetos

					
						// Impedir a reatribuição
						const carro = {tipo:"Fiat", modelo:"500", cor:"branco"};

						// Impedir a adição de propriedades ao objeto
						Object.preventExtensions(objeto)

						// Retornar "true" se é possível adicionar propriedades ao objeto
						Object.isExtensible(objeto)

						// Impedir a adição e a exclusão de propriedades
						Object.seal(objeto)

						// Retornar "true" se o objeto estiver selado (bloqueado)
						Object.isSealed(objeto)

						// Impedir qualquer alteração em um objeto
						Object.freeze(objeto)

						// Retornar "true" se o objeto estiver congelado
						Object.isFrozen(objeto)

Lembre-se que o método mais comum para proteger objetos é usar a palavra-chave const, que não permite reatribuir um objeto, mas ainda permite adicionar e excluir propriedades, além de alterar os valores de uma propriedade.

Saiba mais sobre Métodos de proteção de objetos.
