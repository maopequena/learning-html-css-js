Loops

Loops são úteis para executar o mesmo código várias vezes, sempre com um valor diferente. Por exemplo, ao invés de escrever:

			
				texto += carros[0] + "
";
				texto += carros[1] + "
";
				texto += carros[2] + "
";
				texto += carros[3] + "
";
				texto += carros[4] + "
";
				texto += carros[5] + "
";

Podemos escrever:

			
				for (let i = 0; i < carros.length; i++) {
					texto += carros[i] + "
";
				}

Em que i significa instance (instância).

Diferentes tipos de loop

O JavaScript oferece suporte a diferentes tipos de loops:

  • for: repete um bloco de código uma determinada quantidade de vezes.
  • for/in: percorre as propriedades de um objeto.
  • for/of: percorre os valores de um objeto iterável (repetível).
  • while: repete um bloco de código enquanto uma determinada condição for verdadeira.
  • do/while: faz o mesmo que o caso acima.

O loop for

Esta declaração cria um loop com três expressões opcionais:

					
						for (expressão 1; expressão 2; expressão 3) {
							// bloco de código a executar
						}

A expressão 1 é executada uma vez antes de executar o bloco de código, a expressão 2 define a condição para executar o bloco de código, e a expressão 3 é executada sempre após a execução do bloco de código. Vejamos um exemplo:

					
						for (let i = 0; i < 5; i++) {
							texto += "O número é " + i + ".<br>";
						}

Neste caso, a expressão 1 define uma variável antes de o loop começar (let i=0), a expressão 2 define a condição para executar o loop (i deve ser menor que 5) e a expressão 3 aumenta o valor de i a cada execução do bloco de código no loop.

Expressão 1

Normalmente usamos essa expressão para iniciar a variável que será usada no loop (let i=0), mas não é sempre assim. O JavaScript não se importa, a expressão 1 é opcional. Podemos iniciar vários valores nessa expressão, sempre separando-os com vírgulas:

						
							for (let i = 0, len = carros.length, texto = ""; i < len; i++) {
								texto += carros[i] + "<br>";
							}

E podemos omiti-la por completo se os valores forem definidos antes de o loop começar:

						
							let i = 2;
							let len = carros.length;
							let texto = "";
							for (; i < len; i++) {
								texto += carros[i] + "<br>";
							}

Expressão 2

É usada para avaliar a condição da variável inicial. Essa expressão também é opcional. Se retornar true, o loop começa de novo; se retornar false, o loop é encerrado. Se esta expressão for omitida, é preciso usar a palavra-chave break dentro do loop, caso contrário, o loop nunca terminará e o navegador pode travar.

Expressão 3

Esta expressão geralmente incrementa o valor da variável inicial. Ela também é opcional. É possível usar incrementação negativa (como i--), positiva (como i++) ou qualquer outra coisa. Também é possível emitir esta expressão, por exemplo ao incrementar os valores dentro do loop.

						
							let i = 0;
							let len = carros.length;
							let texto = "";
							for (; i < len; ) { // Note os espaços em branco antes do primeiro ponto-e-vírgula e depois do segundo
								texto += carros[i] + "
";
								i++;
							}

Escopo do loop

No exemplo abaixo, usamos var, a variável é declarada no loop e redeclarada fora dele.

					
						var i = 5;

						for (var i = 0; i < 10; i++) {
							// some code
						}

						// Here i is 10

No exemplo a seguir, usamos let, a variável declarada no loop não é redeclarada fora dele.

					
						let i = 5;

						for (let i = 0; i < 10; i++) {
							// some code
						}

						// Here i is 5

Isto é, ao usar let, a variável declarada no loop só fica visível dentro do loop.

O loop for/in

Este tipo de loop repete as propriedades de um objeto. Esta é a sintaxe:

					
						for (chave in objeto) {
							// bloco de código a executar
						}

Por exemplo:

					
						const person = {fname:"John", lname:"Doe", age:25};

						let texto = "";
						for (let x in person) {
							texto += person[x];
						}

No exemplo acima, o loop for in itera o objeto person, cada iteração retorna uma chave (x), que é usada para acessar o seu valor, que no caso é person[x].

For/in em matrizes

Com este tipo de loop também podemos repetir as propriedades de uma matriz. Vejamos a sintaxe:

						
							for (variável in matriz) {
								código a executar
							}
						
					
						
							const numbers = [45, 4, 9, 16, 25];

							let txt = "";
							for (let x in numbers) {
								txt += numbers[x];
							}

Observação: não use este tipo de loop em uma matriz quando a ordem do índice for importante. A ordem do índice depende de implementação e os valores da matriz podem não ser acessados na ordem que você deseja. Quando a ordem for importante, é melhor usar for, for of ou Matriz.forEach().

Matriz.forEach()

Este método chama uma função de retorno uma vez para cada elemento da matriz.

					
						const numeros = [45, 4, 9, 16, 25];

						let texto = "";
						numero.forEach(minhaFuncao);

						function minhaFuncao(valor, índice, matriz) {
							texto += valor + "
";
						}

Observe que a função aceita três argumentos: o valor, o índice e a matriz. No exemplo acima usamos somente o valor, então podemos reescrever o código como:

					
						const numeros = [45, 4, 9, 16, 25];

						let texto = "";
						numero.forEach(minhaFuncao);

						function minhaFuncao(valor) {
							texto += valor + "
";
						}

O loop for/of

Esta declaração repete os valores de um objeto iterável, permitindo passar por estruturas de dados como matrizes, sequências de caracteres (strings), mapas, listaas de nós, etc. A sintaxe é:

					
						for (variável of objeto iterável) {
							// bloco de código a executar
						}

No caso acima, para variável, a cada iteração o valor da próxima propriedade é atribuído à variável. Uma variável, nesta situação, pode ser declarada com const, let ou var. O objeto iterável é o objeto que tem propriedades que podem ser repetidas.

Exemplos

Loop em uma matriz:

						
							const carros = ["BMW", "Volvo", "Mini"];

							let texto = "";
							for (let x of carros) {
								texto += x + "
";
							}

							// Resultado:

							BMW
							Volvo
							Mini

Loop em uma string:

						
							let linguagem = "JavaScript";

							let texto = "";
							for (let x of linguagem) {
							texto += x + "
";
							}

							// Resultado:

							J
							a
							v
							a
							S
							c
							r
							i
							p
							t

O loop while

Esta declaração cria um loop que repete enquanto uma determinada condição for verdadeira. A sintaxe é:

					
						while (condição) {
							// bloco de código a executar
						}

Exemplos

No exemplo a seguir, o código no loop será executado repetidamente enquanto a variável (i) for menor que 10:

						
							let texto = "";
							let i = 0;

							while (i < 10) {
								texto += "<br>O número é " + i;
								i++;
							}

							// Resultado:

							O número é 0
							O número é 1
							O número é 2
							O número é 3
							O número é 4
							O número é 5
							O número é 6
							O número é 7
							O número é 8
							O número é 9

Observação: se você esquecer de aumentar a variável ("i++") usada na condição, o loop nunca terminará, o que pode travar seu navegador.

O loop do-while

Esta é uma variante do loop while. Ele executa o bloco de código uma vez, verifica se a condição ainda é verdadeira, e executa o código novamente enquanto a condição for verdadeira. Sintaxe:

					
						do {
							// bloco de código a executar
						}
						while (condição);

Exemplos

No exemplo abaixo, o loop sempre será executado uma vez, mesmo que a condição seja falsa, porque o bloco de código é executado antes de a condição ser testada:

						
							let texto = "";
							let i = 0;

							do {
								texto += "O número é " + i;
								i++;
							}
							while (i < 10);

							// Resultado:

							O número é 0
							O número é 1
							O número é 2
							O número é 3
							O número é 4
							O número é 5
							O número é 6
							O número é 7
							O número é 8
							O número é 9

Observação: lembre-se sempre de aumentar a variável ("i++") usada na condição, senão o loop nunca terminará, o que pode travar seu navegador.

Comparação entre for e while

O loop while é muito parecido com o loop for, se omitirmos as declarações 1 e 3. O exemplo a seguir usa um loop for para coletar nomes de carros da matriz carros:

					
						const carros = ["BMW", "Volvo", "Saab", "Ford"];
						let i = 0;
						let texto = "";

						for (;carros[i];) {
							texto += carros[i];
							i++;
						}

E o exemplo abaixo usa um loop while para fazer a mesma coisa:

					
						const carros = ["BMW", "Volvo", "Saab", "Ford"];
						let i = 0;
						let texto = "";

						while (carros[i]) {
							texto += carros[i];
							i++;
						}

O resultado dos dois loops é o mesmo:

					
						BMW
						Volvo
						Saab
						Ford

Break e Continue

A declaração break "quebra" o loop e a declaração continue pula uma iteração do loop.

Break

Esta declaração pode ser usada para "quebrar" um loop ou uma declaração switch(). No exemplo abaixo, usamos a palavra-chave break para sair do loop quando o número for 3:

						
							for (let i = 0; i < 10; i++) {
								if (i === 3) { break; }
								texto += "O número é " + i + "
";
							}

							// Resultado:

							O número é 0
							O número é 1
							O número é 2

Continue

Esta declaração pula uma iteração do loop se a condição especificada for verdadeira, continuando na iteração seguinte. No exemplo abaixo, usamos a palavra-chave continue para pular o loop quando o número for 3:

						
							for (let i = 0; i < 10; i++) {
								if (i === 3) { continue; }
								texto += "O número é " + i + "
";
							}

							// Resultado:

							O número é 0
							O número é 1
							O número é 2
							O número é 4
							O número é 5
							O número é 6
							O número é 7
							O número é 8
							O número é 9

Etiquetas

É possível usar as palavras-chave break e continue com uma referência a uma etiqueta. No caso de continue, com ou sem a etiqueta, ela só pula uma iteração do loop. Entretanto, para break, sem a etiqueta, ela só quebra o loop ou switch. Com a etiqueta, pode ser usada para sair de qualquer bloco de código (o que está entre as chaves). Por exemplo:

					
						const carros = ["BMW", "Volvo", "Saab", "Ford"];
						let texto = "";

						lista: {
							texto += carros[0] + "
"; 
							texto += carros[1] + "
"; 
							break lista;
							texto += carros[2] + "
"; 
							texto += carros[3] + "
"; 
						}

						// Resultado:

						BMW
						Volvo

Objetos iteráveis

Objetos iteráveis são objetos que podem ser repetidos em um loop usando, por exemplo, o loop for/of.

Iterar significa aplicar repetidamente um mesmo código em uma sequência de elementos, por exemplo, em uma sequência de caracteres (string) ou uma matriz.

Iteradores

O protocolo iterador define como gerar uma sequência de valores a partir de um objeto. Um objeto se torna um iterador quando implementa um método next(). Esse método deve retornar um objeto com duas propriedades:

  • value (o próximo valor): o valor retornado pelo iterador (pode ser omitido se "done" for verdadeiro)
  • done (verdadeiro ou falso): true (verdadeiro) se o iterador está concluído, false (falso) se o iterador gerou um novo valor

Tecnicamente, os objetos iteráveis devem implementar o método Symbol.iterator. Sequências de caracteres (strings), matrizes (arrays), matrizes tipadas (TypedArrays), mapas (Maps) e conjuntos (Sets) são objetos iteráveis, porque seus objetos prototípicos têm o método Symbol.iterator.

Objetos iteráveis criados do zero

É possível, sim, criar um objeto iterável com um tipo diferente dos mencionados acima. Porém, eles não oferecem suporte à declaração for/of. A função a seguir retorna múltiplos de 10 ininterruptamente sempre que o método next() é chamado:

					
						// Iterável do zero
						function meusNumeros() {
							let n = 0;
							return {
								next: function() {
									n += 10;
									return {value:n, done:false};
								}
							};
						}

						// Create Iterable
						const n = meusNumeros();
						n.next(); // Retorna 10
						n.next(); // Retorna 20
						n.next(); // Retorna 30

Também podemos usar o código for (const x of iterable) { } para gerar objetos iteráveis:

					
						// Criar um objeto
						meusNumeros = {};

						// Iteração
						meusNumeros[Symbol.iterator] = function() {
							let n = 0;
							done = false;
							return {
								next() {
									n += 10;
									if (n == 100) {done = true}
									return {value:n, done:done};
								}
							};
						}

						// Uso de for/of
						for (const num of meusNumeros) {
							// bloco de código a executar
						}

No código acima, o método Symbol.iterator é chamado automaticamente por for/of, mas também pode ser chamado manualmente:

					
						let iterator = meusNumeros[Symbol.iterator]();

						while (true) {
							const result = iterator.next();
							if (result.done) break;
							// Bloco de código
						}
