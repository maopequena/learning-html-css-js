Loops

Loops executam um bloco de código várias vezes. Eles são úteis para executar o mesmo código várias vezes, sempre com um valor diferente. Por exemplo, ao invés de escrever:

			
				text += cars[0] + "
";
				text += cars[1] + "
";
				text += cars[2] + "
";
				text += cars[3] + "
";
				text += cars[4] + "
";
				text += cars[5] + "
";

Podemos escrever:

			
				for (let i = 0; i < cars.length; i++) {
					text += cars[i] + "
";
				}

Em que i significa instance (instância).

Diferentes tipos de loop

O JavaScript oferece suporte a diferentes tipos de loops:

  • for: repete um bloco de código uma determinada quantidade de vezes.
  • for/in: percorre as propriedades de um objeto.
  • for/of: percorre os valores de um objeto iterável (repetível).
  • while: repete um bloco de código enquanto uma determinada condição for verdadeira.
  • do/while: faz o mesmo que o caso acima.

O loop for

Esta declaração cria um loop com três expressões opcionais:

					
						for (expressão 1; expressão 2; expressão 3) {
							// bloco de código a executar
						}

A expressão 1 é executada uma vez antes de executar o bloco de código, a expressão 2 define a condição para executar o bloco de código, e a expressão 3 é executada sempre após a execução do bloco de código. Vejamos um exemplo:

					
						for (let i = 0; i < 5; i++) {
							text += "O número é " + i + ".<br>";
						}

Neste caso, a expressão 1 define uma variável antes de o loop começar (let i=0), a expressão 2 define a condição para executar o loop (i deve ser menor que 5) e a expressão 3 aumenta o valor de i a cada execução do bloco de código no loop.

Expressão 1

Normalmente usamos essa expressão para iniciar a variável que será usada no loop (let i=0), mas não é sempre assim. O JavaScript não se importa, a expressão 1 é opcional. Podemos iniciar vários valores nessa expressão, sempre separando-os com vírgulas:

						
							for (let i = 0, len = cars.length, text = ""; i < len; i++) {
								text += cars[i] + "<br>";
							}

E podemos omiti-la por completo se os valores forem definidos antes de o loop começar:

						
							let i = 2;
							let len = cars.length;
							let text = "";
							for (; i < len; i++) {
								text += cars[i] + "<br>";
							}

Expressão 2

É usada para avaliar a condição da variável inicial. Essa expressão também é opcional. Se retornar true, o loop começa de novo; se retornar false, o loop é encerrado. Se esta expressão for omitida, é preciso usar a palavra-chave break dentro do loop, caso contrário, o loop nunca terminará e o navegador pode travar.

Expressão 3

Esta expressão geralmente incrementa o valor da variável inicial. Ela também é opcional. É possível usar incrementação negativa (como i--), positiva (como i++) ou qualquer outra coisa. Também é possível emitir esta expressão, por exemplo ao incrementar os valores dentro do loop.

						
							let i = 0;
							let len = cars.length;
							let text = "";
							for (; i < len; ) { // Note os espaços em branco antes do primeiro ponto-e-vírgula e depois do segundo
								text += cars[i] + "
";
								i++;
							}

Escopo do loop

No exemplo abaixo, usamos var, a variável é declarada no loop e redeclarada fora dele.

					
						var i = 5;

						for (var i = 0; i < 10; i++) {
							// some code
						}

						// Here i is 10

No exemplo a seguir, usamos let, a variável declarada no loop não é redeclarada fora dele.

					
						let i = 5;

						for (let i = 0; i < 10; i++) {
							// some code
						}

						// Here i is 5

Isto é, ao usar let, a variável declarada no loop só fica visível dentro do loop.

O loop for/in

Este tipo de loop repete as propriedades de um objeto. Esta é a sintaxe:

					
						for (chave in objeto) {
							// bloco de código a executar
						}

Por exemplo:

					
						const person = {fname:"John", lname:"Doe", age:25};

						let text = "";
						for (let x in person) {
							text += person[x];
						}

No exemplo acima, o loop for in itera o objeto person, cada iteração retorna uma chave (x), que é usada para acessar o seu valor, que no caso é person[x].

For/in em matrizes

Com este tipo de loop também podemos repetir as propriedades de uma matriz. Vejamos a sintaxe:

						
							for (variável in matriz) {
								código a executar
							}
						
					
						
							const numbers = [45, 4, 9, 16, 25];

							let txt = "";
							for (let x in numbers) {
								txt += numbers[x];
							}

Observação: não use este tipo de loop em uma matriz quando a ordem do índice for importante. A ordem do índice depende de implementação e os valores da matriz podem não ser acessados na ordem que você deseja. Quando a ordem for importante, é melhor usar for, for of ou Matriz.forEach().

Matriz.forEach()

Este método chama uma função de retorno uma vez para cada elemento da matriz.

					
						const numeros = [45, 4, 9, 16, 25];

						let texto = "";
						numero.forEach(minhaFuncao);

						function minhaFuncao(valor, índice, matriz) {
							texto += valor + "
";
						}

Observe que a função aceita três argumentos: o valor, o índice e a matriz. No exemplo acima usamos somente o valor, então podemos reescrever o código como:

					
						const numeros = [45, 4, 9, 16, 25];

						let texto = "";
						numero.forEach(minhaFuncao);

						function minhaFuncao(valor) {
							texto += valor + "
";
						}
