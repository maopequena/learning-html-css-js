JavaScript

O JavaScript é a linguagem de programação mais popular do mundo e é a linguagem de programação da Web. É uma das três principais linguagens que todos os desenvolvedores Web devem aprender: HTML, CSS e JavaScript.

Introdução

O JavaScript é gratuito e não precisa ser baixado ou instalado, ele já está em execução nos navegadores de computadores, tablets, etc.

A tag <script>

Para inserir um código JavaScript no documento HTML, use a tag <script>.

Observação: exemplos antigos de JavaScript podem usar um atributo de tipo: <script type="text/javascript">. Esse atributo não é obrigatório, já que o JS é a linguagem de script padrão para HTML.

Onde colocar a tag <script>?

Dentro da tag <body> ou dentro da tag <head>? Ambas as opções são aceitas, porém se for no corpo do documento, o ideal é colocar a tag no final do código HTML, porque isso melhora a velocidade de exibição da página.

Podemos também criar um arquivo .js externo para conter o código JavaScript. Isso é útil quando um código JS é usado em várias páginas. Nesses arquivos, não se deve usar a tag <script>, somente o código JS.

Para usar um arquivo de scripts externo, coloque o nome do arquivo no atributo src da tag <script>: <script src="myScript.js"></script>. É possível adicionar várias dessas tags para vários arquivos diferentes.

Independentemente de onde o script for colocado, ele se comportará como se estivesse localizado exatamente onde a tag <script> está.

Vantagens de um arquivo externo

Colocar os scripts em arquivos externos tem algumas vantagens:

  • O HTML e o código JS ficam separados.
  • É mais fácil ler e manter ambas as linguagens.
  • Arquivos JS em cache podem acelerar o carregamento e processamento de uma página da Web.

Há três maneiras de chamar scripts externos:

  • Com um URL completo: <script src="https://www.w3schools.com/js/myScript.js"></script>.
  • Com um caminho de arquivo: <script src="/js/myScript.js"></script>.
  • Sem qualquer caminho: <script src="myScript.js"></script>.'

Funções e eventos

Uma função é um bloco de código JS que pode ser executado ao ser chamado. Por exemplo, podemos chamar uma função quando ocorre um evento, como ao clicar em um botão.
