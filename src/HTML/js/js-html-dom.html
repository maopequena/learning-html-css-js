DOM do HTML

O DOM do HTML

Usando o DOM (Document Object Model, modelo de objetos do documento) do HTML, o JavaScript pode acessar e alterar todos os elementos de um documento HTML.

O Modelo de objetos do documento (DOM) da W3C é uma plataforma e interface de linguagem neutra que possibilitaque programas e scripts acessem e atualizem dinamicamente o conteúdo, a estrutura e o estilo de um documento.

Há 3 partes no DOM padrão da W3C:

  • DOM essencial: modelo padrão para todos os tipos de documento
  • DOM XML: modelo padrão para documentos XML
  • DOM HTML: modelo padrão para documentos HTML

Ao carregar uma página da Web, o navegador cria um Modelo de objetos do documento da página, que é uma árvore de objetos.

Com esse modelo, o JavaScript tem tudo o que precisa para criar páginas HTML dinâmicas:

  • Pode alterar todos os elementos HTML na página
  • Pode alterar todos os atributos HTML na página
  • Pode alterar todos os estilos CSS na página
  • Pode remover os elementos e atributos HTML existentes
  • Pode adicionar novos elementos e atributos HTML
  • Pode reagir a todos os eventos HTML existentes na página
  • Pode criar novos eventos HTML na página

O DOM do HTML define:

  • Os elementos HTML como objetos
  • As propriedades de todos os elementos HTML
  • Os métodos para acessar todos os elementos HTML
  • Os eventos para todos os elementos HTML

Resumindo: o DOM é um padrão para obter, alterar, adicionar ou excluir elementos HTML.

Métodos do DOM

Métodos são ações que se pode realizar em elementos HTML. Propriedades são os valores dos elementos HTML que se pode alterar ou definir.

A interface de programação do DOM

O DOM do HTML pode ser acessado com JavaScript (e outras linguagens de programação); nele, todos os elementos HTML são definidos como objetos.

A interface de programação são as propriedades e métodos de cada objeto.

Uma propriedade é um valor que se pode obter ou definir (como alterar o conteúdo de um elemento HTML). Um método é uma ação que se pode executar (como adicionar ou excluir um elemento HTML).

Exemplo

O exemplo a seguir altera o conteúdo (a tag innerHTML) do elemento <p> com id="demo":

				
					<html>
					<body>

						<p id="demo"></p>

						<script>
						document.getElementById("demo").innerHTML = "Olá, mundo!";
						</script>

					</body>
					</html>

getElementById é um método, innerHTML é uma propriedade.

A maneira mais comum de acessar um elemento HTML é usando a sua id. No exemplo acima, o método getElementById usou id="demo" para localizar o elemento.

A maneira mais fácil de obter o conteúdo de um elemento é usando a propriedade innerHTML, que é bastante útil para obter ou substituir o conteúdo de elementos HTML.

O DOM é o proprietário de todos os outros objetos na página Web.

O objeto do documento representa a página da Web. Se você quiser acessar qualquer elemento em uma página HTML, sempre precisa acessar primeiro o objeto do documento. Eis alguns exemplos de como usar o objeto do documento para acessar e manipular elementos HTML:

Elementos do DOM

Localizar elementos

Há várias maneira de localizar elementos no DOM:

  • Pelo identificador
  • Pelo nome da tag
  • Pelo nome da classe
  • Pelos seletores de CSS
  • Pelas coleções de objetos HTML

Localizar elementos pelo identificador

O exemplo abaixo encontra o elemento pelo identificador intro:

					
						const element = document.getElementById("intro");

Se o elemento for encontrado, o método o retorna como um objeto (na variável element). Caso contrário, element conterá null.

Localizar elementos pelo nome da tag

O exemplo abaixo localiza todos os elementos <p> no documento:

					
						const element = document.getElementsByTagName("p");

O exemplo abaixo localiza todos os elementos com a id main e todos os elementos <p> dentro de main:

					
						const x = document.getElementById("main");
						const y = x.getElementsByTagName("p");

Localizar elementos pelo nome da classe

O exemplo abaixo retorna todos os elementos com a classe intro:

					
						const x = document.getElementsByClassName("intro");

Localizar elementos pelos seletores de CSS

É possível localizar qualquer seletor usado no CSS, incluindo id, nomes de classes, tipos, atributos, valores de atributos, etc. O exemplo abaixo lista todos os elementos <p> com a classe intro:

					
						const x = document.querySelectorAll("p.intro");

Pelas coleções de objetos HTML

O exemplo abaixo localiza o elemento de formulário com o identificador frm1 e exibe todos os seus valores:

					
						const x = document.forms["frm1"];
						let texto = "";
						for (let i = 0; i < x.length; i++) {
							text += x.elements[i].value + "<br>";
						}
						document.getElementById("demo").innerHTML = texto;

Também é possível acessar âncoras, o corpo do documento, embeds, cabeçalhos, imagens, links, etc.

Alterar o HTML

Há várias maneira de alterar o conteúdo HTML em uma página:

  • Alterar o conteúdo HTML
  • Alterar o valor de um atributo
  • Conteúdo HTML dinâmico
  • document.write()

Alterar o conteúdo HTML

Sintaxe: document.getElementById(id).innerHTML = novo HTML

A maneira mais fácil de alterar o conteúdo de um elemento HTML é com a propriedade innerHTML. O exemplo abaixo altera o conteúdo de um elemento <p>:

					
						
							<body>

							<p id="p1">Olá, mundo!</p>

							<script>
								document.getElementById("p1").innerHTML = "Novo texto!";
							</script>

							</body>
							</html>

O exemplo abaixo altera o conteúdo de um elemento <h1>:

					
						
							<body>

							<h1 id="id01">Cabeçalho velho</h1>

							<script>
								const element = document.getElementById("id01");
								element.innerHTML = "Cabeçalho novo";
							</script>

							</body>
							</html>

Alterar o valor de um atributo

Sintaxe: document.getElementById(id).atributo = novo valor

O exemplo abaixo altera o valor do atributo src de um elemento <img>:

					
						...
						<img id="minhaImagem" src="smiley.gif">

						<script>
							document.getElementById("minhaImagem").src = "landscape.jpg";
						</script>
						...

Conteúdo HTML dinâmico

É possível criar conteúdo HTML dinâmico com o JavaScript.

					
						...
						<script>
							document.getElementById("demo").innerHTML = "Data : " + Date(); 
						</script>
						...

Este exemplo exibe a data e a hora do carregamento da página no elemento com o identificador demo.

document.write()

Podemos usar document.write() para escrever diretamente no fluxo de saída do HTML:

					
						...
						<p>Lorem ipsum dolor sit amet consectetur adipisicing elit.</p>

						<script>
							document.write(Date());
						</script>

						<p>Nesciunt fugit magni ipsa architecto veniam saepe quia expedita.</p>
						...

Porém, note que nunca se deve usar este método após o documento ser carregado, já que isso pode sobrescrevê-lo.

Formulários no JavaScript

Validação de formulários

Se um campo de formulário estiver vazio, o exemplo a seguir envia uma mensagem de alerta e retorna false para impedir que o formulário seja enviado:

					
						function validarForm() {
							let x = document.forms["meuForm"]["fname"].value;
							if (x == "") {
								alert("O campo Nome deve estar preenchido");
								return false;
							}
						}

Em seguida, é só chamar a função ao enviar o formulário:

					
						<form name="meuForm" action="/action_page.php" onsubmit="return validarForm()" method="post">
							Nome: <input type="text" name="fname">
						<input type="submit" value="Enviar">
						</form>

Validação automática

O navegador pode validar formulários automaticamente. Se um campo de formulário estiver vazio, o atributo required impede que o formulário seja enviado:

						
							<form action="/action_page.php" method="post">
								<input type="text" name="fname" required>
								<input type="submit" value="Enviar">
							</form>

Validação de números

Também podemos usar JavaScript para validar a digitação de números em formulários:

					
						<p>Insira um número entre 1 e 10:</p>

						<input id="numb">

						<button type="button" onclick="minhaFuncao()">Enviar</button>

						<p id="demo"></p>

						<script>
						function minhaFuncao() {
							// Obter o valor do campo com o identificador numb
							let x = document.getElementById("numb").value;
							// Se x is não for um número, for menor que um ou maior que 10
							let texto;
							if (isNaN(x) || x < 1 || x > 10) {
								texto = "Valor inválido";
							} else {
								texto = "Valor aceito";
							}
							document.getElementById("demo").innerHTML = texto;
						}
						</script>

Validação de dados

Validação de dados é o processo que garante que o que foi digitado pelo usuário é útil, correto e claro. Algumas tarefas de validação comuns são:

  • O usuário preencheu todos os campos obrigatórios?
  • O usuário inseriu uma data válida?
  • O usuário inseriu texto em um campo numérico?

Na maioria dos casos, o propósito da validação dos dados é garantir que o usuário preencha corretamente os campos. Há várias maneira de definir a validação, e de implementá-la.

A validação no lado do servidor é feita por um servidor da Web, após as informações serem enviadas ao servidor. A validação no lado do cliente é feita pelo navegador, antes das informações serem enviadas ao servidor.

  • Atributos de input no HTML
  • Pseudo-seletores do CSS
  • Propriedades e métodos do DOM

Alterar o CSS

Sintaxe: document.getElementById(id).style.propriedade = novo estilo

O exemplo a seguir altera o estilo de um elemento <p>:

				
					<p id="p2">Olá, mundo!</p>

					<script>
						document.getElementById("p2").style.color = "blue";
						document.getElementById("p2").style.fontFamily = "Arial";
						document.getElementById("p2").style.fontSize = "larger";
					</script>

Uma outra forma de alterar o CSS é ocultar um elemento HTML no carregamento da página e fornecer um botão (ou outro elemento), que altera sua visibilidade:

				
					<body onload="document.getElementById('p1').style.visibility='hidden'">

					<p id="p1">Este texto está oculto ao carregar a página, mas ao clicar no botão "Clique aqui!", ele aparece.</p>
					
					<input type="button" value="Clique aqui!" onclick="document.getElementById('p1').style.visibility='visible'">

					</body>

Saiba mais. Para obter uma lista de todas as propriedades de estilo do DOM, consulte a Referência de objetos de estilo do DOM.

Animações

Vejamos as etapas de um exemplo simples de como criar uma animação com JavaScript:

  • 1. Criar uma página básica. Para isso, digite ! no Visual Studio Code.
  • 2. Crie um contêiner para a animação. Um elemento div com o identificador animation dentro de um elemento div com o identificador container é suficiente.
  • 3. Estilize os elementos. O div externo deve ter position: relative, o interno deve ter position: absolute
  • 4. Crie o código da animação. Para isso, programe alterações graduais no estilo de um elemento. Essas alterações serão acionadas por um temporizador e, quando o intervalo de tempo é pequeno o suficiente, a animação parece algo contínuo.
  • 5. Crie uma forma de acionar a animação. Um elemento button deve bastar. Chame a função da animação no botão.
				
					<!DOCTYPE html>
					<html>

					<head>
					<style>
						#container {
							width: 400px;
							height: 400px;
							position: relative;
							background: yellow;
						}
						#animate {
							width: 50px;
							height: 50px;
							position: absolute;
							background: red;
						}
					</style>
					</head>

					<body>

						<h1>Minha primeira animação em JavaScript</h1>

						<div id="container">
							<div id="animate">Minha animação aparecerá aqui!</div>
						</div>

						<button onclick="minhaAnimacao()">Iniciar animação</button>

						<script>
							function minhaAnimacao() {
								let id = null;
								const elem = document.getElementById("animate");
								let pos = 0;
								clearInterval(id);
								id = setInterval(frame, 5);
								function frame() {
									if (pos == 350) {
										clearInterval(id);
									} else {
										pos++;
										elem.style.top = pos + 'px';
										elem.style.left = pos + 'px';
									}
								}
							}
						</script>

					</body>
					</html>

Eventos

Exemplos de eventos HTML que podem ser manipulados:

  • O usuário clica com o mouse (onclick, onmousedown ou onmouseup)
  • Ao carregar uma página da Web (onload e onunload)
  • Ao carregar uma imagem (onload e onunload)
  • Quando o mouse passa sobre um elemento (onmouseover ou onmouseout)
  • Ao alterar um campo de entrada (oninput ou onchange)
  • Ao enviar um formulário HTML (onsubmit)
  • Quando o usuário pressiona uma tecla (onkeydown, onkeypress ou onkeyup)
  • Quando um elemento recebe o foco (onfocus)

E há muitos mais! Para saber mais sobre eventos HTML e como manipular o DOM, consulte a Referência de objetos de eventos do DOM.

addEventListener()

O método addEventListener() incorpora um manipulador de eventos ao elemento especificado, sem sobrescrever os manipuladores existentes. É possível adicionar vários manipuladores de eventos a um elemento, sejam do mesmo tipo ou diferentes. E podemos adicioná-los também a qualquer objeto do DOM, não só a elementos HTML.

Este método facilita controlar como os eventos reagem com os eventos pais.

Ao usar este método, o JavaScript é separado da marcação HTML para permitir melhor legibilidade, o que possibilita adicionar manipuladores de eventos mesmo quando você não tem controle sobre a marcação HTML.

Para remover um manipulador de eventos, use o método removeEventListener().

Sintaxe: elemento.addEventListener(evento, função, useCapture);. O primeiro parâmetro é o tipo de evento que se deseja manipular (como "click", "mousedown" ou qualquer outro evento do DOM HTML). O segundo parâmetro é a função que se deseja chamar quando o evento ocorrer. O terceiro parâmetro, que é opcional, é um valor booleano que define se o evento deve ser executado no pai ou nos filhos. Note que aqui não se deve usar "on" antes do nome do evento. É "click", não "onclick".

Bubbling e capturing

Há duas maneiras de propagar eventos no DOM do HTML: bubbling (para cima, para o pai) e capturing (para baixo, para os filhos). Isso define a ordem dos elementos quando o evento ocorre. Se há um elemento <p> dentro de um elemento <div> e o usuário clica no elemento <p>, qual evento de clique do elemento deve ser alterado primeiro?

Em bubbling, o evento no elemento mais interno é alterado primeiro, depois o externo.

Em capturing, o evento no elemento mais externo é alterado primeiro, depois o interno.

Com o método addEventListener() podemos definir o tipo de propagação com o parâmetro useCapture. O padrão desse parâmetro é false, que significa usar bubbling. Ao defini-lo como true, o evento usará capturing.

Navegação no DOM

Podemos navegar pela árvore de nós do DOM HTML usando os relacionamentos entre os nós. Tudo em um documento HTML é um nó:

  • Todo o documento é um nó de documento.
  • Cada elemento HTML é um nó de elemento.
  • O texto dentro dos elementos HTML são nós de texto.
  • Cada atributo HTML é um nó de atributo (obsoleto).
  • All comments are comment nodes

Todos os nós podem ser acessados, alterados, adicionados ou excluídos pelo JavaScript.

Relacionamentos entre nós

Há uma relação hierárquica entre os nós da árvore. Usamos os termos "pais", "filhos" e "irmãos" para descrever os relacionamentos:

  • O nó mais superior é chamado de raiz (root).
  • Cada nó tem exatamente um pai, exceto o raiz, que não tem pais.
  • Um nó pode ter vários filhos.
  • Irmãos são nós que têm os mesmos pais.

Sabendo disso, podemos usar as seguintes propriedades para navegar entre os nós com o JavaScript:

  • parentNode
  • childNodes[número_do_nó]
  • firstChild
  • lastChild
  • lastChild
  • previousSibling

E há duas propriedades especiais que dão acesso ao documento completo:

  • document.body: o corpo do documento.
  • document.documentElement: o documento completo.

nodeName

Essa propriedade especifica o nome de um nó:

  • Ela é somente leitura.
  • O nodeName de um nó de elemento é o mesmo que o nome da tag.
  • O nodeName de um nó de atributo é o nome do atributo.
  • O nodeName de um nó de texto é sempre #text.
  • O nodeName de um nó de documento é sempre #document.

nodeValue

Esta propriedade especifica o valor de um nó:

  • O nodeValue de nós de elementos é null.
  • O nodeValue de nós de texto é o texto em si.
  • O nodeValue de nós de atributo é o valor do atributo.

nodeType

Esta propriedade é somente leitura e retorna o tipo de um nó. Os nodeType mais importantes são:

Nó Tipo Exemplo
ELEMENT_NODE 1 <h1 class="heading">W3Schools</h1>
ATTRIBUTE_NODE 2  class = "heading" (deprecated)
TEXT_NODE 3 W3Schools
COMMENT_NODE 8 <!-- This is a comment -->
DOCUMENT_NODE 9 The HTML document itself (the parent of <html>)
DOCUMENT_TYPE_NODE 10 <!Doctype html>

Como criar e remover nós

Para adicionar um novo elemento ao DOM, é preciso criá-lo primeiro e, então, anexá-lo a um elemento existente.

			
				<div id="div1">
					<p id="p1">Isto é um parágrafo.</p>
					<p id="p2">Este é outro parágrafo.</p>
				</div>
				
				<script>
				const para = document.createElement("p");
				const node = document.createTextNode("Isto é novo.");
				para.appendChild(node);
				
				const element = document.getElementById("div1");
				element.appendChild(para);
				</script>

Explicação:

O código const para = document.createElement("p"); cria um novo elemento.

Para adicionar texto ao elemento recém-criado, é preciso primeiro criar um nós de texto. O código const node = document.createTextNode("Isto é novo."); faz isso.

Em seguida, precisamos anexar o nó de texto ao elemento <p>; para tanto, usamos o código para.appendChild(node);.

Por fim, precisamos anexar o novo elemento a um elemento existente. É para isso que servem as linhas de código const element = document.getElementById("div1"); e element.appendChild(para);.

insertBefore()

O método appendChild() do exemplo anterior anexou o novo elemento como o último filho do pai. Mas podemos usar o método insertBefore() para anexá-lo em qualquer posição:

				
					<div id="div1">
						<p id="p1">Isto é um parágrafo.</p>
						<p id="p2">Este é outro parágrafo.</p>
					</div>
					
					<script>
					const para = document.createElement("p");
					const node = document.createTextNode("Isto é novo.");
					para.appendChild(node);
					
					const element = document.getElementById("div1");
					const child = document.getElementById("p1");
					element.insertBefore(para, child);
					</script>

Remover elementos

Use o método remove() para excluir um elemento HTML:

				
					<div>
						<p id="p1">Isto é um parágrafo.</p>
						<p id="p2">Este é outro parágrafo.</p>
					</div>
					
					<script>
						const elmnt = document.getElementById("p1"); elmnt.remove();
					</script>

Explicação:

O documento HTML contém um div com dois nós filhos:
<div>
<p id="p1">Isto é um parágrafo.</p>
<p id="p2">Este é outro parágrafo.</p>
</div>

O código const elmnt = document.getElementById("p1"); localiza o elemento a excluir.

Depois é só executar o método no elemento: elmnt.remove();.

removeChild()

Alguns navegadores mais antigos não aceitam o método remove(). Neste caso, encontre o pai do elemento que deseja excluir e use o método removeChild().

					
						<div id="div1">
							<p id="p1">Isto é um parágrafo.</p>
							<p id="p2">Este é  outro parágrafo.</p>
						</div>
						
						<script>
						const parent = document.getElementById("div1");
						const child = document.getElementById("p1");
						parent.removeChild(child);
						</script>

Explicação:

O documento HTML contém um div com dois nós filhos:
<div>
<p id="p1">Isto é um parágrafo.</p>
<p id="p2">Este é outro parágrafo.</p>
</div>

O código const parent = document.getElementById("div1"); localiza o elemento com identificador div1 e o código const child = document.getElementById("p1"); localiza o elemento com identificador p1.

O código parent.removeChild(child); remove o filho do pai.

Também podemos usar a propriedade parentNode do elemento filho para localizar seu pai:

						
							const child = document.getElementById("p1");
							child.parentNode.removeChild(child);

Substituir elementos

Para substituir elementos no DOM, use o método replaceChild():

					
						<div id="div1">
							<p id="p1">Isto é um parágrafo.</p>
							<p id="p2">Este é outro parágrafo.</p>
						</div>
						
						<script>
						const para = document.createElement("p");
						const node = document.createTextNode("Isto é novo.");
						para.appendChild(node);
						
						const parent = document.getElementById("div1");
						const child = document.getElementById("p1");
						parent.replaceChild(para, child);
						</script>

Coleções do DOM

O objeto HTMLCollection

O método getElementsByTagName() retorna um objeto HTMLCollection, que é uma lista em formato de matriz (também conhecida como coleção) de elementos HTML.

O código const myCollection = document.getElementsByTagName("p"); seleciona todos os elementos <p> em um documento. É possível acessar os elementos de uma coleção com um número de índice. Então, para acessar o segundo elemento <p>, podemos usar minhaColecao[1]. Lembre-se que os índices no JavaScript começam em 0.

A propriedade length define a quantidade de elementos em um HTMLCollection. Ela é útil quando se deseja fazer um loop pelos elementos de uma coleção, por exemplo, alterar a cor de texto de todos os elementos <p>:

				
					const minhaColecao = document.getElementsByTagName("p");
					for (let i = 0; i < minhaColecao.length; i++) {
						minhaColecao[i].style.color = "red";
					}

Note que um HTMLCollection NÃO é uma matriz. Podemos fazer loop por sua lista e nos referir aos elementos com um índice, como em uma matriz, mas não é possível usar métodos de matrizes, como valueOf(), pop(), push() ou join().

Listas de nós do DOM

O objeto NodeList

Um objeto NodeList é uma lista (ou coleção) de nós extraída de um documento, e é bem similar ao objeto HTMLCollection.

Alguns navegadores mais antigos retornam um objeto NodeList ao invés de HTMLCollection ao usar métodos como getElementsByClassName(). Todos os navegadores retornam este objeto para a propriedade childNodes. E a maioria dos navegadores o retorna para o método querySelectorAll().

Assim como o HTMLCollection, é possível usar um índice com NodeList e a propriedade length (para loops).

Diferença entre HTMLCollection e NodeList

Então qual a diferença entre os dois? HTMLCollection é uma coleção de elementos do documento, enquanto NodeList é uma coleção de nós do documento (nós de elementos, de atributo e de texto).

Os itens da HTMLCollection podem ser acessados pelo nome, identificador ou índice, os itens da NodeList só podem ser acessados pelo índice.

A HTMLCollection é dinâmica, enquanto a NodeList é estática. Por exemplo, ao adicionar um elemento <li> a uma lista no DOM, a lists na HTMLCollection também muda. Entretanto, ao adicionar o mesmo elemento a uma NodeList, a lista permanece inalterada.

Os métodos getElementsByClassName() e getElementsByTagName() retornam uma HTMLCollection dinâmica, querySelectorAll() retorna uma NodeList estática e a propriedade childNodes retorna uma NodeList dinâmica.
