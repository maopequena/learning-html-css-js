DOM do navegador

O BOM do navegador

Usando o BOM (Browser Object Model, modelo de objetos do navegador), o JavaScript pode "falar" com o navegador.

Não há um padrão oficial para o BOM. Como os navegadores modernos implementaram (quase) os mesmos métodos e propriedades para interagir com o JavaScript, eles geralmente são chamados de métodos e propriedades do BOM.

O objeto Window

Todos os navegadores oferecem suporte para o objeto window; ele representa a janela do navegador. Todos os objetos, funções e variáveis globais do JavaScript automaticamente se tornam membros deste objeto.

As variáveis globais são propriedades e funções globais são métodos desse objeto. Até o objeto do documento (o DOM do HTML) é uma propriedade do objeto window: window.document.getElementById("header"); é o mesmo que document.getElementById("header");.

Tamanho da janela

Há duas propriedades para determinar o tamanho da janela, que retornam o tamanho em pixels:

  • window.innerHeight: a altura interna da janela do navegador (em pixels)
  • window.innerWidth: a largura interna da janela do navegador (em pixels)

Note que esses valores não incluem o menu de ferramentas ou a barra de rolagem.

Outros métodos da janela do navegador

Alguns outros métodos:

  • window.open(): abre uma nova janela.
  • window.close(): fecha a janela atual.
  • window.moveTo(): move a janela atual.
  • window.resizeTo(): redimensiona a janela atual.

window.screen

Este objeto contém informações sobre a tela do usuário e pode ser escrito sem o prefixo window. Suas propriedades são:

  • screen.width
  • screen.height
  • screen.availWidth
  • screen.availHeight
  • screen.colorDepth
  • screen.pixelDepth

screen.width

Esta propriedade retorna a largura da tela do visitante em pixels.

						
							document.getElementById("demo").innerHTML =
							"Screen Width: " + screen.width; // Screen Width: 1920

screen.height

Esta propriedade retorna a altura da tela do visitante em pixels.

						
							document.getElementById("demo").innerHTML =
							"Screen Height: " + screen.height; // Screen Width: 1080

screen.availWidth

Esta propriedade retorna a largura disponível na tela do visitante, em pixels, menos os recursos da interface, como a barra de tarefas do Windows.

						
							document.getElementById("demo").innerHTML =
							"Available Screen Width: " + screen.availWidth; // Available Screen Width: 1920

screen.availHeight

Esta propriedade retorna a altura disponível na tela do visitante, em pixels, menos os recursos da interface, como a barra de tarefas do Windows.

						
							document.getElementById("demo").innerHTML =
							"Available Screen Height: " + screen.availHeight; // Available Screen Height: 1050

screen.colorDepth

Esta propriedade retorna a quantidade de bits usada para exibir uma cor. Todos os computadores modernos usam hardware de 24 bits ou 32 bits para a resolução de cores: 24 bits = 16.777.216 cores diferentes, 32 bits = 4.294.967.296 cores diferentes. Computadores mais antigos têm uma resolução de 16 bits: 65.536 "cores" diferentes. Computadores e celulares muito antigos usavam 8 bits = 256 cores diferentes.

						
							document.getElementById("demo").innerHTML =
							"Screen Color Depth: " + screen.colorDepth; // Screen Color Depth: 24

screen.pixelDepth

Esta propriedade retorna a profundidade de pixels da tela.

						
							document.getElementById("demo").innerHTML =
							"Screen Pixel Depth: " + screen.pixelDepth; // Screen Pixel Depth: 24

Note que, em computadores modernos, pixelDepth e colorDepth são a mesma coisa.

window.location

Este objeto pode ser usado para obter o endereço da página atual (o URL) e para redirecionar o navegador para outra página. E pode ser escrito sem o prefixo window. Por exemplo:

  • window.location.href retorna o href (URL) da página atual
  • window.location.hostname retorna o nome de domínio do host da Web
  • window.location.pathname retorna o caminho e o nome de arquivo da página atual
  • window.location.protocol retorna o protocolo Web usado (http: ou https:)
  • window.location.assign() carrega um novo documento

window.location.href

Esta propriedade retorna o href (URL) da página atual.

						
							// Exibir o URL da página atual
							document.getElementById("demo").innerHTML =
							"O local da página é " + window.location.href; // O local da página é https://www.w3schools.com/js/js_window_location.asp

window.location.hostname

Esta propriedade retorna o nome do host de Internet.

						
							// Exibir o nome do host
							document.getElementById("demo").innerHTML =
							"O nome do host da página é " + window.location.hostname; // O nome do host da página é www.w3schools.com

window.location.pathname

Esta propriedade retorna o nome de arquivo da página atual.

						
							document.getElementById("demo").innerHTML =
							"O caminho da página é " + window.location.pathname; // O caminho da página é /js/js_window_location.asp

window.location.protocol

Esta propriedade retorna o protocolo Web da página atual.

						
							document.getElementById("demo").innerHTML =
							"O protocolo da página é " + window.location.protocol; // O protocolo da página é https:

window.location.port

Esta propriedade retorna o número de porta do host de Internet da página atual. Porém, note que a maioria dos navegadores não exibe números de porta padrão, como 80 (http) ou 443 (https).

						
							document.getElementById("demo").innerHTML =
							"O número da porta é " + window.location.port; // O número da porta é https:

window.location.assign()

Este método carrega um novo documento. Veja o exemplo em: Load a new document (em inglês).

window.history

Este objeto contém o histórico do navegador e também pode ser escrito sem o prefixo.

Para proteger a privacidade dos usuários, há limites para como o JavaScript pode acessar este objeto. Veja exemplos deste objeto em JavaScript Window History.

history.back()

Este método carrega o URL anterior no histórico e é o mesmo que clicar na seta para voltar na janela do navegador.

history.forward()

Este método carrega o próximo URL no histórico e é o mesmo que clicar na seta para frente na janela do navegador.

window.navigator

Este objeto contém informações sobre o navegador do visitante da página e pode ser escrito com ou sem o prefixo.

Cookies do navegador

A propriedade cookieEnabled retorna true se os cookies estiverem habilitados no navegador. Caso contrário, retorna false.

Idioma do navegador

A propriedade language retorna o idioma do navegador.

Online ou offline

A propriedade onLine retorna true se o navegador estiver online e false se estiver offline.

Nome do aplicativo

A propriedade appName retorna o nome do aplicativo do navegador. Esta propriedade está obsoleta, porque a maioria dos navegadores retorna Netscape como o nome.

Nome de código do aplicativo

A propriedade appCodeName retorna o nome de código do navegador. Esta propriedade está obsoleta, porque a maioria dos navegadores retorna Mozilla como o nome.

Mecanismo do navegador

A propriedade product retorna o nome de produto do mecanismo do navegador. Esta propriedade está obsoleta, porque a maioria dos navegadores retorna Gecko como o nome.

Versão do navegador

A propriedade appVersion retorna informações sobre a versão do navegador. Esta propriedade está obsoleta e você não deve confiar nestas informações.

Agente do navegador

A propriedade userAgent retorna o cabeçalho user-agent enviado pelo navegador ao servidor.

Plataforma do navegador

A propriedade platform retorna o sistema operacional do navegador. Esta propriedade está obsoleta e você não deve confiar nestas informações.

Com ou sem Java

O método javaEnabled retorna true se o Java estiver habilitado e false se estiver desabilitado. Este método está obsoleto e sempre retornará false.

Informações deste objeto podem estar incorretas! Este objeto não deve ser usado para detectar informações sobre versões do navegador porque:

  • Diferentes navegadores podem ter o mesmo nome
  • Os dados do navigator podem ser alterador pelo proprietário do navegador
  • Alguns navegadores se identificam incorretamente para passar em testes de sites
  • Os navegadores não podem informar sistemas operacionais novos, lançados após o navegador

Caixas popup

Há três tipos de caixas popup no JavaScript: alertas, confirmação e prompt.

Alertas

Geralmente usamos caixas de alerta para garantir que uma informação seja exibida ao usuário. Quando ela aparece, o usuário precisa clicar em "OK" para prosseguir.

Sintaxe:

							
								window.alert("texto a exibir no popup");

Também é possível usar este método sem o prefixo:

							
								alert("texto a exibir no popup");

Confirmação

Geralmente usamos caixas de confirmação para que o usuário verifique ou aceite algo. Quando ela aparece, o usuário precisa clicar em "OK" ou em "Cancelar" para prosseguir. Se clicar em "OK", a caixa retorna true, caso contrário, retorna false.

Sintaxe:

							
								window.confirm("texto a exibir no popup");

Também é possível usar este método sem o prefixo:

							
								if (confirm("Clique em um dos botões!")) {
									txt = "Você clicou em OK!";
								} else {
									txt = "Você clicou em Cancelar!";
								}

Prompt

Geralmente usamos caixas de prompt para que o usuário digite algo antes de abrir uma página. Quando ela aparece, o usuário precisa clicar em "OK" ou em "Cancelar" para prosseguir após digitar um valor. Se o usuário clicar em "OK", a caixa retorna o valor digitado, caso contrário, retorna null.

Sintaxe:

							
								window.prompt("texto a exibir no popup", "valor padrão");

Também é possível usar este método sem o prefixo:

							
								let pessoa = prompt("Digite seu nome", "Harry Potter");
								let texto;
								if (pessoa == null || person == "") {
									text = "O usuário cancelou o prompt.";
								} else {
									text = "Olá " + pessoa + "! Você está bem?";
								}

Quebras de linha

Para exibir quebras de linha em uma caixa popup, use uma barra invertida (\) e o caractere n.

						
							alert("Olá\nComo você está?");

Eventos de temporização

O objeto window permite executar código em intervalos definidos. Esses intervalos chamam-se eventos de temporização. Os dois principais métodos são:

  • setTimeout(função, milissegundos): executa uma função após esperar uma determinada quantidade de milissegundos.
  • setInterval(função, milissegundos): executa uma função após esperar uma determinada quantidade de milissegundos, mas repete essa execução continuamente.

Ambos são objetos do objeto Window do DOM HTML.

setTimeout()

Este método pode ser usado sem o prefixo window. Exemplo:

						
							<button onclick="setTimeout(myFunction, 3000)">Try it</button>

							<script>
							function myFunction() {
								alert('Hello');
							}
							</script>

Como interromper a execução?

O método clearTimeout() pode ser usado para interromper a execução de um evento de temporização. Exemplo: clearTimeout(variávelDeTempo). A variávelDeTempo é retornada pelo setTimeout(). É possível interromper a execução chamando este método mesmo que a função ainda não tenha sido executada.

setInterval()

Este método repete a execução de uma função a intervalos definidos. Pode ser usado sem o prefixo window. Exemplo:

						
							setInterval(meuTemporizador, 1000);

							function meuTemporizador() {
								const d = new Date();
								document.getElementById("demo").innerHTML = d.toLocaleTimeString();
							}

Não se esqueça: 1000 milissegundos = 1 segundo!

Cookies

Os cookies nos permitem armazenar informações em páginas da Web. Cookies são dados armazenados em pequenos arquivos de texto, em formato de pares nome=valor, em seu computador. Quando um servidor da web envia uma página para um navegador, a conexão é finalizada e o servidor se esquece de tudo sobre o usuário. Os cookies resolvem esse problema.

Quando o usuário visita uma página, seu nome pode ser armazenado em um cookie. Da próxima vez que o usuário visitar a mesma página, o cookie "se lembra" do nome do usuário.

Quando o navegador solicita uma página do servidor, os cookies que pertencem à página são adicionados à solicitação. Dessa forma, o servidor obtém os dados necessários para "lembrar" de informações sobre o usuário.

Observação: os exemplos abaixo não funcionarão se os cookies locais não estiverem habilitados em seu navegador.

Como criar um cookie com JavaScript

O JavaScript pode criar, ler e excluir cookies com a propriedade document.cookie.

Criar cookies

							
								document.cookie = "nomeusuario=John Doe; expires=Thu, 18 Dec 2013 12:00:00 UTC; path=/";

O cookie acima conterá o nome do usuário, expirará em 18 de dezembro de 2013 e o caminho de acesso será / (a raiz do site em questão). Por padrão o cookie pertence à página atual.

Ler cookies

							
								let x = document.cookie;

Ao ler os cookies, esta propriedade retorna uma única string com todos os cookies do navegador: cookie1=valor; cookie2=valor; cookie3=valor;.

Alterar cookies

Para alterar um cookie, use a mesma sintaxe de criação: document.cookie = "username=John Smith; expires=Thu, 18 Dec 2013 12:00:00 UTC; path=/";, e o cookie antigo será substituído.

Excluir cookies

É muito simples excluir cookies, não é preciso definir um valor, apenas defina a data de validade ("expires") para uma data no passado. Por exemplo:

							
								document.cookie = "username=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/;";

Sempre defina um caminho para o cookie, para garantir que excluirá o cookie certo. Alguns navegadores não permitem excluir cookies se o caminho não estiver especificado.

A sequência de caracteres de cookies

A propriedade document.cookie parece um sequência de texto normal, mas não é. Mesmo que você escreva uma string de cookie completa na propriedade document.cookie, ao lê-la só será possível ver o par de nome-valor. Se definir um novo cookie, os mais antigos não serão substituídos. O novo cookie será adicionado ao document.cookie, então, ao lê-lo novamente, você verá algo como: cookie1 = value; cookie2 = value;. Se quiser encontrar o valor de um cookie específico, precisará escrever uma função do JavaScript que pesquisa pelo valor do cookie na sequência de caracteres.

Exemplo de cookie

No exemplo a seguir, criaremos um cookie que armazena o nome de um visitante. Na primeira vez que o visitante acessa a página, ele será solicitado a digitar seu nome, que será armazenado em um cookie. Da próxima vez que ele acessar a página, receberá uma mensagem de boas vindas. Para isso, criaremos três funções JavaScript:

  1. Uma função para definir o cookie
  2. Uma função para ler o valor do cookie
  3. Uma função para verificar o valor do cookie

1. Definir o cookie:

							
								function definirCookie(nomec, valorc, validade) {
									const d = new Date();
									d.setTime(d.getTime() + (validade*24*60*60*1000));
									let expira = "expires="+ d.toUTCString();
									document.cookie = nomec + "=" + valorc + ";" + expira + ";path=/";
								}

Explicação: os parâmetros da função acima são o nome do cookie (nomec), o valor do cookie (valorc) e em quantos dias o cookie perde a validade (validade). A função define um cookie concatenando seu nome, seu valor e a data de validade como uma sequência de caracteres.

2. Ler o cookie:

							
								function lerCookie(nomec) {
									let nome = nomec + "=";
									let cookieDecodificado = decodeURIComponent(document.cookie);
									let ca = decodedCookie.split(';');
									for(let i = 0; i < ca.length; i++) {
										let c = ca[i];
										while (c.charAt(0) == ' ') {
											c = c.substring(1);
										}
										if (c.indexOf(nome) == 0) {
											return c.substring(nome.length, c.length);
										}
									}
									return "";
								}

Explicação: pega o nome do cookie como um parâmetro (nomec), cria uma variável (nome) com o texto a pesquisar (nomec + "="). Decodifica a sequência de caracteres do cookie para lidar com caracteres especiais (p.ex. "$"). Divide document.cookie, usando ponto-e-vírgula, em uma matriz chamada ca (ca = decodedCookie.split(';'). Percerre um loop pela matriz ca (i = 0; i < ca.length; i++) e lê cada valor (c = ca[i]). Se o cookie for encontrado (c.indexOf(nome) == 0), retorna o valor do cookie (c.substring(nome.length, c.length)). Se não for encontrado, retorna "".

3. Verificar o cookie:

							
								function verificarCookie() {
									let nomeusuario = lerCookie("nomeusuario");
									if (nomeusuario != "") {
										alert("Bem-vindo(a) de volta " + nomeusuario + "!");
									} else {
										nomeusuario = prompt("Digite seu nome:", "");
										if (nomeusuario != "" && nomeusuario != null) {
											definirCookie("nomeusuario", nomeusuario, 365);
										}
									}
								}

Explicação: se o cookie estiver definido, exibe uma saudação. Caso contrário, exibe uma caixa de prompt solicitando que o usuário digite seu nome, e armazena essa informação no cookie "nomeusuario" por 365 dias chamando a função definirCookie.
