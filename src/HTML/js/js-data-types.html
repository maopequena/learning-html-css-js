Tipos de dados

Em programação, o conceito de tipos de dados é muito importante. Sem entender os tipos de dados, o computador não conseguiria resolver a expressão a seguir, nem você.

			
				let x = 16 + "Volvo";

Qual o resultado da expressão anterior? Essa soma faz sentido?

O JavaScript trata qualquer soma que contenha strings como se todos os operandos fossem strings, então o resultado seria o mesmo que:

" " 
			
				let x = "16" + "Volvo";

O JavaScript avalia a expressão da esquerda para a direita, então sequências diferentes produzem resultados diferentes.

			
				let x = 16 + 4 + "Volvo"; // 20Volvo
				let x = "Volvo" + 16 + 4; // Volvo164

Os tipos de dados em JavaScript são dinâmicos, o que significa que a mesma variável pode conter diferentes tipos de dados:

			
				let x;       // x está indefinido
				x = 5;       // Agora x é um número
				x = "John";  // Agora x é uma sequência de caracteres

Há sete tipos de dados simples em JavaScript:

  • sequência de caracteres (string)
  • números
  • bigint
  • booleanos
  • indefinido
  • nulo
  • símbolos

E um tipo de dado complexo: objeto. Todos os outros tipos de dados complexos, como matrizes, mapas, conjuntos e funções, são apenas diferentes tipos de objetos.

Sequência de caracteres

Uma sequência de caracteres, string ou um texto é um grupo de letras, como "John Doe". Ela pode conter 0 ou mais caracteres, sempre entre aspas, simples ou duplas:

			
				// Com aspas duplas:
				let carName1 = "Volvo XC60";

				// Com aspas simples:
				let carName2 = 'Volvo XC60';

Para usar aspas dentro de uma string, use o símbolo inverso:

			
				// Aspas simples dentro de aspas duplas:
				let answer1 = "It's alright";

				// Aspas simples dentro de aspas duplas:
				let answer2 = "He is called 'Johnny'";

				// Aspas duplas dentro de aspas simples:
				let answer3 = 'He is called "Johnny"';

Também é possível "escapar" os caracteres de aspas:

			
				let answer1 = "It\'s alright";
				let answer2 = "He is called \"Johnny\"";
				let answer3 = 'He is called \'Johnny\'';

Strings complexas

As template strings (ou string templates, ou template literals) são definidas pelo acento da crase (` `) e possibilitam usar aspas simples e duplas sem o "escape". Por exemplo:

let text = `He's often called "Johnny"`;

Dessa forma, podemos escrever o código em várias linhas e o HTML quebra o texto de acordo:

			
				let text =
				`The quick
				brown fox
				jumps over
				the lazy dog`;

Interpolação

Com as strings complexas é possível interpolar facilmente variáveis e expressões em sequências de caracteres. A sintaxe é ${...}.

Interpolar é usar as variáveis dentro das sentenças, assim:

			
				let firstName = "John";
				let lastName = "Doe";
				let greeting = "Welcome"

				let text = `${greeting}, ${firstName} ${lastName}!`; // Welcome, John Doe!

Também podemos criar cálculos com as strings complexas:

			
				let price = 10;
				let VAT = 0.25;

				let total = `Total: ${(price * (1 + VAT)).toFixed(2)}`; // Total: 12.50

Dessa forma, é possível criar todo o código HTML dentro da string complexa, inclusive inserindo variáveis:

			
				<script>
					let header = "Template Strings";
					let tags = ["template strings", "javascript", "es6"];
					
					let html = `<h2>${header}</h2><ul>`;
					
					for (const x of tags) {
						html += `<li>${x}</li>`;
					}
					
					html += `</ul>`;
					document.getElementById("demo").innerHTML = html;
				</script>

Caracteres de escape

Como as sequências de caracteres devem ser escritas com aspas, o JavaScript pode interpretar incorretamente a seguinte frase:

			
				let text = "We are the so-called "Vikings" from the north.";

Ela será cortada logo após "so-called ". Para resolver isso, podemos usar os caracteres de escape (\):

Código Resultado Descrição
\' ' Aspas simples
\" " Aspas duplas
\\ \ Barra invertida

Há seis outras sequências de escape válidas, que originalmente controlavam máquinas de escrever, teletipos e máquinas de fax. Hoje em dia elas não fazem muito sentido, especialmente no HTML.

Código Resultado
\b Retorno
\f Alimentação de formulário
\n Nova linha
\r Enter
\t Tabulação horizontal
\v Tabulação vertical

Quebras de linhas longas

Devido à legibilidade, os programadores costumam evitar linhas de código muito longas. Para quebrar uma linha de código com segurança, faça-o depois do operador:

			
				document.getElementById("demo").innerHTML =
				"Hello Dolly!";

No caso de sequências de caracteres, use o operador de concatenação (operador de adição):

			
				document.getElementById("demo").innerHTML = "Hello " +
				"Dolly!";

Sequências de caracteres como objetos

Normalmente, as sequências de caracteres são valores primitivos, criadas a partir de literais, mas também podem ser definidas como objetos, com a palavras-chave new.

			
				let x = "John";
				let y = new String("John");

Métodos de sequências de caracteres

Strings no JavaScript são primitivas e imutáveis. Todos os métodos apresentados a seguir geram uma nova sequência de caracteres sem alterar a original.

length()

A propriedade length retorna o comprimento de uma sequência de caracteres:

			
				let text = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
				let length = text.length; // 26

charAt()

Este método retorna o caractere no índice (posição) especificado de uma string:

			
				let text = "HELLO WORLD";
				let char = text.charAt(0); // H

charCodeAt()

Este método retorna um código UTF-16 (um inteiro entre 0 e 65535) do caractere no índice (posição) especificado de uma string:

			
				let text = "HELLO WORLD";
				let char = text.charCodeAt(0); // 72

at()

Obtém o caractere no índice (posição) especificado de uma string:

			
				// Obter a terceira letra em "name":
				const name = "W3Schools";
				let letter = name.at(2);

				// Que também pode ser escrito assim:*
				const name = "W3Schools";
				let letter = name[2];

Este método possibilita usar índices negativos, coisa que charAt() não faz, então é possível usar myString.at(-2) em vez de charAt(myString.length-2).

*O acesso às propriedades desta maneira pode ser um pouco imprevisível, pois faz com que as strings pareçam-se com matrizes, apesar de não serem, se não houver um caractere no índice especificado (como um espaço), ele retorna undefined, enquanto charAt() retorna uma string vazia e é um método apenas para leitura, isto é, str[0] = "A" não exibe um erro, mas não funciona.

slice()

Este método extrai uma parte da string e retorna a parte extraída em uma nova sequência de caracteres. Ele aceita dois parâmetros, a posição inicial e a posição final, que não é inclusa:

			
				let text = "Apple, Banana, Kiwi";
				let part = text.slice(7, 13);

Se o parâmetro final não for definido, todo o restante da string é cortado. Um parâmetro negativo começa a contar do final da string.

substring()

Similar a slice(), porém os valores inicial e final menores que 0 são considerados como 0. Se o segundo parâmetro não for definido, todo o restante da string é cortado:

			
				let str = "Apple, Banana, Kiwi";
				let part = str.substring(7, 13);

substr()

Similar a slice(), porém o segundo parâmetro define o comprimento da parte extraída. Se o segundo parâmetro não for definido, todo o restante da string é cortado:

			
				let str = "Apple, Banana, Kiwi";
				let part = str.substr(7, 6);

Se o primeiro parâmetro for negativo, o JavaScript começa a conta do final da string.

toUpperCase() e toLowerCase()

Estes métodos convertem todas as letras de uma string, respectivamente, para maiúsculas e para minúsculas:

			
				let text1 = "Hello World!";
				let text2 = text1.toUpperCase(); // "HELLO WORLD!"

				let text1 = "Hello World!";
				let text2 = text1.toLowerCase(); // hello world!

concat()

Este método une duas ou mais strings:

			
				let text1 = "Hello";
				let text2 = "World";
				let text3 = text1.concat(" ", text2); // Hello World

É a mesma coisa que usar o operador de adição (+):

			
				let text1 = "Hello";
				let text2 = "World";
				let text3 = text1.concat(" ", text2); // Hello World
				let text4 = text1 + " " + text2; // Hello World

trim()

Este método remove os espaços em branco no início e no final da string:

			
				let text1 = "      Hello World!      ";
				let text2 = text1.trim(); // Hello World!

Da mesma forma que trim(), temos trimStart() e trimEnd() que excluem, respectivamente, os espaços em branco no início e no fim da string.

padStart() e padEnd()

Estes métodos adicionam o segundo parâmetro fornecido a quantidade de vezes especificada no primeiro parâmetro ao início ou ao final da string, respectivamente:

			
				let text = "5";
				let padded = text.padStart(4,"0"); // 0005

				let text = "5";
				let padded = text.padStart(4,"x"); // xxx5

				let text = "5";
				let padded = text.padEnd(4,"0"); // 5000

				let text = "5";
				let padded = text.padEnd(4,"x"); // 5xxx

Note que estes métodos funcionam somente com strings. Para colocar padding para números, é preciso primeiro transformá-los em strings com o método toString().

repeat()

Este método retorna a string repetida o número de vezes definido no parâmetro:

			
				let text = "Hello world!";
				let result = text.repeat(2); // Hello world!Hello world!

replace()

Este método substitui um valor especificado por outro em uma string:

			
				let text = "Please visit Microsoft!";
				let newText = text.replace("Microsoft", "W3Schools"); // Please visit W3Schools!

Este método não altera a string original e altera somente a primeira ocorrência encontrada. Se quiser substituir todas as ocorrências de determinado valor, use uma expressão regular com a flag "/g".

replace() diferencia maiúsculas de minúsculas. No exemplo acima, se o primeiro parâmetro fosse "MICROSOFT", não funcionaria. Também é possível usar a flag "/i" para ignorar essa regra.

replaceAll()

Este método possibilita substituir todas as ocorrências de uma string E definir uma expressão regular ao invés de uma string para substituir. Se usar uma expressão regular, é preciso definir a flag "/g", caso contrário ocorre um TypeError.

split()

Também é possível trabalhar com strings transformando-as em matrizes, este método possibilita fazer isso.

			
				let text = "a,b,c,d,e,f";
				const myArray = text.split(",");

				console.log(myArray[2]); // c

Se omitir o separador, a matriz retornada conterá toda a string no índice 0. Se o separador for "", a matriz retornada conterá cada caractere da string.

indexOf() e lastIndexOf()

Estes métodos retornam o índice da primeira e da última ocorrência de um valor especificado na string, respectivamente. Se o valor na string não for encontrado, o método retorna -1.

			
				let text = "Please locate where 'locate' occurs!";
				let index = text.indexOf("locate");

				console.log(index); // 7

				let text = "Please locate where 'locate' occurs!";
				let index = text.lastIndexOf("locate");

				console.log(index); // 21

É possível também definir um segundo parâmetro para estes métodos, que define a posição inicial para a pesquisa.

			
				let text = "Please locate where 'locate' occurs!";
				let index = text.indexOf("locate", 15); // 21
				let index2 = text.lastIndexOf("locate", 15); // 7

search()

Este método pesquisa a string (ou expressão regular) definida como parâmetro e retorna o índice da primeira ocorrência.

			
				let text = "Please locate where 'locate' occurs!";

				console.log(text.search(/locate/)); // 7

Note que os métodos indexOf() e search() são similares, mas têm duas diferenças:

  • search() não aceita um segundo argumento de posição inicial.
  • indexOf() não aceita valores de pesquisa complexos, como expressões regulares.

match()

Este método retorna uma matriz com todas as ocorrências de uma string (ou expressão regular) em uma string.

			
				let text = "The rain in SPAIN stays mainly in the plain";

				let result1 = text.match("ain");
				let result2 = text.match(/ain/);
				let result3 = text.match(/ain/g);
				let result4 = text.match(/ain/gi);
				
				console.log(result1); // 1 ain
				console.log(result2); // 1 ain
				console.log(result3); // 3 ain,ain,ain
				console.log(result4); // 4 ain,ain,ain,ain

Se a expressão regular não incluir a flag "/g", o método retorna apenas a primeira ocorrência.

matchAll()

Este método retorna um iterador com os resultados de correspondência de uma string em relação a outra (ou a uma expressão regular).

			
				let text = "I love cats. Cats are very easy to love. Cats are very popular."
				const iterator = text.matchAll("Cats");
				
				for (const match of iterator) {
					console.log(match);
				}

				// Outputs Cats in index 13 and Cats in index 41

Assim como com outros casos de uso de expressões regulares, é preciso definir as flags "/g" e "/i" para pesquisa global e que não diferencia maiúsculas de minúsculas, respectivamente. Note que este método, originalmente, diferencia maiúsculas e minúsculas.

includes()

Este método retorna true se uma string contiver um valor especificado. Caso contrário, retorna false.

			
				let text = "Hello world, welcome to the universe.";
				text.includes("world"); // true

				let text = "Hello world, welcome to the universe.";
				text.includes("world", 12); // false

Este método também diferencia maiúsculas de minúsculas.

startsWith() e endsWith()

Estes métodos retornam true se, respectivamente, a string começa ou termina com o valor especificado.

Também é possível definir um índice inicial para a pesquisa. Estes métodos diferenciam maiúsculas de minúsculas.

			
				let text1 = "Hello world, welcome to the universe.";
				console.log(text1.startsWith("Hello")); // true

				let text2 = "Hello world, welcome to the universe.";
				console.log(text2.startsWith("world")); // false

				let text3 = "Hello world, welcome to the universe.";
				console.log(text3.startsWith("world", 5)); // false

				let text4 = "John Doe";
				console.log(text4.endsWith("Doe")); // true

				let text5 = "Hello world, welcome to the universe.";
				console.log(text5.endsWith("world", 11)); // true

Saiba mais sobre strings, suas propriedades e métodos.

Números

Números em JavaScript são armazenados como decimais (também conhecidos como números flutuantes) e podem ser escritos com ou sem as casas decimais.

			
				// Com decimais:
				let x1 = 34.00;

				// Sem decimais:
				let x2 = 34;

Números muito grandes ou muito pequenos podem ser escritos com notação científica.

			
				let y = 123e5;    // 12300000
				let z = 123e-5;   // 0.00123

Diferente de outras linguagens de programação, o JavaScript não define diferentes tipos de números, como inteiros, curtos, longos, flutuantes, etc. TODOS os números são pontos flutuantes de 64 bits, isto é, são armazenados como números com precisão de duas casas, de acordo com o padrão internacional IEEE 754. Este formato armazena os números em 64 bits, em que o número (a fração) é armazenado em bits de 0 a 51, o exponente em bits de 52 a 62 e o bit de sinal 63.

Precisão dos inteiros

Os números inteiros, isto é, sem casas decimais ou notação de exponente, tem precisão de até 15 dígitos. E o número máximo de decimais é 17.

			
				let x = 999999999999999;   // x será 999999999999999
				let y = 9999999999999999;  // y será 10000000000000000

O cálculo de decimais nem sempre é preciso:

			
				let x = 0.2 + 0.1; // 0.30000000000000004

Para solucionar esse problema, use multiplicação e divisão:

			
				let x = (0.2 * 10 + 0.1 * 10) / 10; // 0.3

Soma

LEMBRE-SE que o JavaScript usa o operador + para soma e concatenação. Números são somados, strings são concatenadas.

A soma de dois números resulta em um número. A soma de duas strings resulta em uma concatenação das strings. A soma de um número e uma string resulta em uma concatenação de strings.

Como as strings também podem ser números, é preciso ter cuidado ao usar os operadores aritméticos. Lembre-se também que os cálculos vão da esquerda para a direita. Durante um cálculo aritmético de subtração, multiplicação ou divisão, o JavaScript tenta transformar strings em números, se possível, mas não na soma.

NaN: Not a Number

NaN é uma palavra reservada no JavaScript que indica que um número não é válido. Tentar fazer cálculos com uma string não numérica resulta em NaN. No entanto, NaN é considerado um número: typeof NaN resulta em number.

			
				let x = 100 / "Apple"; // NaN

Entretanto, se a string for um número, como vimos antes, o resultado é um número.

A função global isNaN() testa se um número é válido.

			
				let x = 100 / "Apple";
				console.log(isNaN(x)); // true

Ao usar NaN em um cálculo, o resultado será NaN ou será concatenado com a outra string.

Infinity

Infinity (ou -Infinity) é o valor que o JavaScript retorna ao calcular um número que vai além do maior número possível. A divisão por 0 também gera o resultado Infinity. typeof Infinity resulta em number.

			
				let myNumber = 2;
				// Executar até Infinity
				while (myNumber != Infinity) {
					myNumber = myNumber * myNumber;
				}

				console.log(myNumber) // Infinity

Hexadecimais

O JavaScript interpreta constantes numéricas como hexadecimais se tiverem o prefixo 0x.

			
				let x = 0xFF; // 255

NUNCA escreva números com 0 na frente, como 07, porque algumas versões do JavaScript interpretam isso como octais.

Por padrão, o JavaScript exibe os números como decimais de base 10, mas podemos usar o método toString() para exibir números de base 2 a base 36. Hexadecimais são base 16, decimais são base 10, octais são base 8 e binários são base 2.

			
				let myNumber = 32;
				document.getElementById("demo").innerHTML =
				"Decimal 32 = " + "<br><br>" + 
				"Hexatrigesimal (base 36): " + myNumber.toString(36) + "<br>" + 
				"Duotrigesimal (base 32): " + myNumber.toString("32) + "<br>" +
				"Hexadecimal (base 16): " + myNumber.toString(1"6) + "<br>" +
				"Duodecimal (base 12): " + myNumber.toString("12) + "<br>" +
				"Decimal (base 10): " + myNumber.toString(10") + "<br>" +
				"Octal (base 8): " + myNumber.toString(8)" + "<br>" +
				"Binary (base 2): " + myNumber.toString(2);

O resultado do código acima é:

			
				Decimal 32 = 
				Hexatrigesimal (base 36): w
				Duotrigesimal (base 32): 10
				Hexadecimal (base 16): 20
				Duodecimal (base 12): 28
				Decimal (base 10): 32
				Octal (base 8): 40
				Binary (base 2): 100000

Números como objetos

Normalmente, números no JavaScript são valores primitivos criados a partir de literais, mas também podem ser definidos como objetos com a palavra-chave new.

			
				// x é um número
				let x = 123;
				// y é um objeto de número
				let y = new Number(123);

				console.log(typeof x); // número
				console.log(typeof y); // objeto

Porém, a recomendação é não usar essa forma para criar números, porque isso complica o código e diminui a velocidade de execução. Além disso, isso pode gerar resultados inesperados, em que um objeto e um número, quando comparados com ==, geram o resultado true e, quando comparados com ===, geram o resultado false. E ao comparar dois objetos criados dessa forma, o resultado, independentemente do operador, é sempre false.

Métodos de números e BigInt

O JavaScript apresenta vários métodos para manipular números, e dois deles manipulam também os BigInt.

Todos os métodos podem ser usados em todos os tipos de números: literais, variáveis e expressões.

toString()

Retorna um número como uma string.

				
					let x = 123;

					x.toString(); // "123"
					(123).toString(); // "123"
					(100 + 23).toString(); // "123"

toExponential()

Retorna uma string, com um número arredondado e escrito em notação exponencial. O parâmetro define a quantidade de caracteres após o ponto decimal, este parâmetro é opcional e, se não definido, o JavaScript não arredonda o número.

				
					let x = 9.656;

					x.toExponential(); // 9.656e+0
					x.toExponential(2); // 9.66e+0
					x.toExponential(4); // 9.6560e+0
					x.toExponential(6); // 9.656000e+0

toFixed()

Retorna uma string, com o número escrito com uma quantidade especificada de caracteres decimais. Este método é ótima para lidar com valores monetários.

				
					let x = 9.656;

					x.toFixed(0); // 10
					x.toFixed(2); // 9.66
					x.toFixed(4); // 9.6560
					x.toFixed(6); // 9.656000

toPrecision()

Retorna uma string com um número escrito com uma quantidade especificada de dígitos.

				
					let x = 9.656;

					x.toPrecision(); // 9.656
					x.toPrecision(2); // 9.7
					x.toPrecision(4); // 9.656
					x.toPrecision(6); // 9.65600

valueOf()

Retorna um número como número. Em JavaScript, um número pode ser um valor primitivo (typeof = number) ou um objeto (typeof = object). Este método é usado pelo JavaScript para converter objetos em valores primitivos, mas não é necessário usá-lo.

Todos os tipos de dados em JavaScript aceitam os métodos valueOf() e toString().

				
					let x = 123;

					x.valueOf(); // 123
					(123).valueOf(); // 123
					(100 + 23).valueOf(); // 123

Converter variáveis em números

Você pode usar um dos três métodos abaixo para converter variáveis em números, porém note que estes métodos não são exclusivos para números, são métodos globais.

Number()

Retorna um número convertido a partir de um argumento.

				
					Number(true); // 1
					Number(false); // 0
					Number("10"); // 10
					Number("  10"); // 10
					Number("10  "); // 10
					Number(" 10  "); // 10
					Number("10.33"); // 10.33
					Number("10,33"); // NaN
					Number("10 33"); // NaN
					Number("John"); // NaN

Observe que se a variável não pode ser convertida, é exibido NaN.

Também é possível usar este método para converter uma data em um número.

				
					Number(new Date("1970-01-01")) // 0
					Number(new Date("1970-01-02")) // 86400000
					Number(new Date("2017-09-30")) // 253402214400000

Observe que o método Date() retorna a quantidade de milissegundos desde 01/01/1970.

parseInt()

Analisa uma string e retorna um número inteiro. É permitido usar espaços, mas apenas o primeiro número será exibido.

Se o número não pode ser convertido, é exibido NaN.

				
					parseInt("-10"); // -10
					parseInt("-10.33"); // -10
					parseInt("10"); // 10
					parseInt("10.33"); // 10
					parseInt("10 20 30"); // 10
					parseInt("10 years"); // 10
					parseInt("years 10"); // NaN

parseFloat()

Analisa uma string e retorna um número. É permitido usar espaços, mas apenas o primeiro número será exibido.

Se o número não pode ser convertido, é exibido NaN.

				
					parseFloat("10"); // 10
					parseFloat("10.33"); // 10.33
					parseFloat("10 20 30"); // 10
					parseFloat("10 years"); // 10
					parseFloat("years 10"); // NaN

Métodos do objeto de número

Os métodos descritos a seguir pertencem ao objeto de número e só podem ser acessados com notação de ponto (p.ex. Number.isInteger()).

Não é possível usar X.isInteger(), em que "X" é uma variável. Isso retorna um erro: TypeError X.isInteger is not a function.

Os métodos de número NÃO podem ser usados em variáveis.

Number.isInteger()

Retorna true se o argumento é um número inteiro.

				
					Number.isInteger(10); // true
					Number.isInteger(10.5); // false

Number.isSafeInteger()

Um inteiro seguro é um número inteiro que pode ser representado como um número com precisão de duas casas. Este método retorna true se o argumento é um número inteiro seguro.

Os números inteiros seguros estão entre -(253 - 1) e +(253 - 1)

				
					Number.isSafeInteger(10); // true
					Number.isSafeInteger(12345678901234567890); // false

Number.parseFloat()

Analisa uma string e retorna um número. É permitido usar espaços, mas apenas o primeiro número será exibido.

Se o número não pode ser convertido, é exibido NaN.

				
					Number.parseFloat("10"); // 10
					Number.parseFloat("10.33"); // 10.33
					Number.parseFloat("10 20 30"); // 10
					Number.parseFloat("10 years"); // 10
					Number.parseFloat("years 10"); // NaN

Number.parseInt()

Analisa uma string e retorna um número inteiro. É permitido usar espaços, mas apenas o primeiro número será exibido.

Se o número não pode ser convertido, é exibido NaN.

				
					Number.parseInt("-10"); // -10
					Number.parseInt("-10.33"); // -10
					Number.parseInt("10"); // 10
					Number.parseInt("10.33"); // 10
					Number.parseInt("10 20 30"); // 10
					Number.parseInt("10 years"); // 10
					Number.parseInt("years 10"); // NaN

Propriedades de números

Estas propriedades NÃO podem ser usadas com variáveis.

EPSILON

Esta propriedade retorna a diferença entre o menor número decimal maior que 1 e 1.

				
					let x = Number.EPSILON; // 2.220446049250313e-16

MAX_VALUE

É uma constante que representa o maior número possível no JavaScript.

				
					let x = Number.MAX_VALUE; // 1.7976931348623157e+308

MIN_VALUE

É uma constante que representa o menor número possível no JavaScript.

				
					let x = Number.MIN_VALUE; // 5e-324

MAX_SAFE_INTEGER

Representa o número inteiro máximo no JavaScript, que é (253 - 1).

				
					let x = Number.MAX_SAFE_INTEGER; // 9007199254740991

MIN_SAFE_INTEGER

Representa o número inteiro mínimo no JavaScript, que é -(253 - 1).

				
					let x = Number.MIN_SAFE_INTEGER; // -9007199254740991

POSITIVE_INFINITY e NEGATIVE_INFINITY

Retornam Infinity e -Infinity quando usadas. Também são exibidas em divisões por 0.

				
					let x = Number.POSITIVE_INFINITY; // Infinity
					let x = Number.NEGATIVE_INFINITY; // -Infinity
					let x = 1 / 0; // Infinity
					let x = -1 / 0; // -Infinity

NaN - Not a Number

É uma palavra reservada no JavaScript para um número inválido. Tentar fazer uma operação aritmética com uma cadeia de caracteres não numérica também resulta em NaN.

				
					let x = Number.NaN; // NaN
					let x = 100 / "Apple"; // NaN

BigInt

Todos os números em JavaScript são armazenados em formato de número flutuante com 64 bits. O BigInt é um novo tipo de dado que pode ser usado para armazenar valores que são muito grandes para serem representados por um número normal do JavaScript.

			
				let x = BigInt("123456789012345678901234567890");

Assim como os números inteiros, o BigInt tem precisão de até 15 dígitos.

Como os números são armazenados em formato de ponto flutuante de 64 bits, inteiros muito grandes não podem ser representados com exatidão e são arredondados. Por causa disso, o JavaScript só pode representar com segurança inteiros até 9007199254740991 +(253-1) e -9007199254740991 -(253-1).

Não é possível executar cálculos entre um BigInt e um número. Para usar um BigInt em um cálculo, use o método Number().

			
				let x = 5n;
				let y = Number(x) / 2;

Como criar um BigInt

Para criar um BigInt, coloque "n" no final do número ou chame o método BigInt():

			
				let x = 9999999999999999; // 10000000000000000
				let y = 9999999999999999n; // 9999999999999999n

				let x = 1234567890123456789012345; // 1.2345678901234568e+24
				let y = BigInt(1234567890123456789012345) // 1234567890123456824475648n

Todos os operadores que usamos com números podem ser usados com BigInt, exceto pelo deslocamento não atribuído à direita (>>>), porque o BigInt não tem uma largura fixa.

O BigInt não pode ter decimais.

Hexadecimais, binários e octais

Os BigInt também podem ser escritos com notação hexadecimal, binária e octal:

			
				let hex = 0x20000000000003n; // 9007199254740995
				let oct = 0o400000000000000003n; // 9007199254740995
				let bin = 0b100000000000000000000000000000000000000000000000000011n; // 9007199254740995

Observação: o arredondamento pode prejudicar a segurança do programa:

			
				// Is 9007199254740992 equal to 9007199254740993?

				let x = 9007199254740992 === 9007199254740993;
				console.log(x) // true

Números inteiros seguros máximo e mínimo

Use os métodos MAX_SAFE_INTEGER e MIN_SAFE_INTEGER para relembrar os números máximo e mínimo que se pode usar com segurança.

Booleanos

Booleanos só aceitam dois valores: true ou false e são usados para testes condicionais.

Matrizes

Matrizes são escritas com colchetes e seus itens são separados por vírgulas. O código a seguir declara (ou cria) uma matriz chamada "cars" que contém três itens (os nomes dos carros):

			
				const cars = ["Saab", "Volvo", "BMW"];

Como em Python, o índice das matrizes começa em 0.

Como reconhecer uma matriz?

Use o método Array.isArray():

				
					// Criar uma matriz
					const frutas = ["maçãs", "bananas", "laranjas"];
					Array.isArray(frutas); // true

Objetos

Objetos são escritos com chaves e suas propriedades são escritas como pares de nome:valor, separadas por vírgulas.

			
				const person = {firstName:"John", lastName:"Doe", age:50, eyeColor:"blue"};

O objeto acima tem quatro propriedades: firstName, lastName, age e eyeColor.

O operador typeof

Podemos usar este operador para descobrir o tipo de dado de uma variável.

			
				typeof "John"         // Retorna "string"
				typeof ("John"+"Doe") // Retorna "string"
				typeof 3.14           // Retorna "number"
				typeof 33             // Retorna "number"
				typeof (33 + 66)      // Retorna "number"
				typeof true           // Retorna "boolean"
				typeof false          // Retorna "boolean"
				typeof 1234n          // Retorna "bigint"
				typeof Symbol()       // Retorna "symbol"
				typeof x              // Retorna "undefined"
				typeof null           // Retorna "object"
				typeof {name:'John'}  // Retorna "object"
				typeof [1,2,3,4]      // Retorna "object"
				typeof new Map()      // Retorna "object"
				typeof new Set()      // Retorna "object"
				typeof function (){}  // Retorna "function"

Para tipos de dados complexos, este operador retorna apenas dois tipos: object e function. Não é possível diferenciar uma matriz e uma data, por exemplo, usando este operador.

Indefinido

Uma variável sem valor é considerada "indefinida" e, portanto, tem o tipo undefined. Podemos, também, definir o valor como undefined para esvaziar uma variável.

			
				let car;    // Como o valor é indefinido, o tipo também é
				car = undefined;    // Idem

Valores vazios

Um valor vazio não é indefinido. Uma sequência de caracteres vazia tem um valor legal e um tipo:

			
				let car = "";    // O valor é "", o typeof é "string"

Você sabia?

É muito importante lembrar que o índice no JavaScript começa em 0!

Conversão de tipos de dados

Nesta seção veremos como converter o seguinte:

  • Sequências de caracteres em números
  • Números em sequências de caracteres
  • Datas em números
  • Números em datas
  • Booleanos em números
  • Números em booleanos

É possível converter variáveis do JavaScript para uma nova variável e para outros tipos de dados usando uma função do JavaScript ou automaticamente.

Converter sequências de caracteres em números

O método global Number() converte uma variável (ou valor) em um número. Uma sequência de caracteres numérica, como "3.14", é convertida para um número, como 3.14. Uma sequência de caracteres vazia, como "", é convertida para 0. Uma sequência de caracteres não numérica, como "John Doe", é convertida para NaN. Por exemplo:

				
					Number("3.14") // 3.14
					Number(Math.PI) // 3.141592653589793
					Number(" ") // 0
					Number("") // 0
					Number("99 88") // NaN
					Number("John") // NaN

Há outros métodos para converter strings em números na seção Métodos de números e BigInt, na seção Números.

Método Descrição
Number() Retorna um número, convertido de seus argumentos
parseFloat() Analisa uma string e retorna um número de ponto flutuante
parseInt() Analisa uma string e retorna um inteiro

O operador unário +

O operador unário + pode ser usado para converter uma variável em um número:

					
						let y = "5";      // y é uma string
						let x = + y;      // x é um número

Porém, se a variável não puder ser convertida, o resultado é NaN, que ainda é considerado do tipo número:

					
						let y = "John";   // y é uma string
						let x = + y;      // x é um número (NaN)

Converter números em sequências de caracteres

O método global String() pode converter números em sequências de caracteres. Com ele podemos converter qualquer tipo de número, literais, variáveis ou expressões. Por exemplo:

				
					String(x)         // retorna uma string da variável numérica x
					String(123)       // retorna uma string do literal numérico 123
					String(100 + 23)  // retorna uma string de uma expressão numérica

O método toString() faz a mesma coisa:

				
					x.toString()
					(123).toString()
					(100 + 23).toString()

Há outros métodos para converter strings em números na seção Métodos de números e BigInt, na seção Números.

Método Descrição
toExponential() Retorna uma string com um número arredondado e escrito usando notação exponencial.
toFixed() Retorna uma string com um número arredondado e escrito com uma quantidade específica de casas decimais.
toPrecision() Retorna uma string com um número escrito com um comprimento específico.

Converter datas em números

O método Number() pode converter datas em números. Por exemplo:

				
					d = new Date();
					Number(d) // retorna 1404568027739

O método getTime() faz o mesmo:

				
					d = new Date();
					d.getTime() // retorna 1404568027739

Converter datas em sequências de caracteres

O método global String() pode converter datas em sequências de caracteres:

				
					String(Date()) // retorna "Thu Jul 17 2014 15:38:19 GMT+0200 (W. Europe Daylight Time)"

O método toString() faz o mesmo:

				
					Date().toString()  // retorna "Thu Jul 17 2014 15:38:19 GMT+0200 (W. Europe Daylight Time)"

Há outros métodos para converter datas em sequências de caracteres na seção Métodos de data.

Método Descriçaõ
getDate() Obtém o dia como um número (1-31)
getDay() Obtém o dia da semana como um número (0-6)
getFullYear() Obtém um ano com quatro dígitos (aaaa)
getHours() Obtém a hora (0-23)
getMilliseconds() Obtém os milissegundos (0-999)
getMinutes() Obtém os minutos (0-59)
getMonth() Obtém o mês (0-11)
getSeconds() Obtém os segundos (0-59)
getTime() Obtém a hora completa (em milissegundos, desde 01 de janeiro de 1970)

Converter booleanos em números

O método global Number() pode converter booleanos em números. Por exemplo:

				
					Number(false) // retorna 0
					Number(true) // retorna 1

Converter booleanos em sequências de caracteres

O método global String() converte booleanos em strings:

				
					String(false) // retorna "false"
					String(true) // retorna "true"

O método toString() faz o mesmo:

				
					false.toString() // retorna "false"
					true.toString() // retorna "true"

Conversão automática de tipos

Quando o JavaScript tenta manipular um tipo de dado "errado", ele tenta convertê-lo para o tipo "certo". O resultado nem sempre é o que se espera:

				
					5 + null    // retorna 5 porque null é convertido para um número, 0
					"5" + null  // retorna "5null" porque null é convertido para uma string, "null"
					"5" + 2     // retorna "52" porque 2 é convertido para uma string, "2"
					"5" - 2     // retorna 3 porque "5" é convertido para um número, 5
					"5" * "2"   // retorna 10 porque "5" e "2" são convertidos em números, 5 e 2
					"5" / "2"   // retorna 2.5 porque "5" e "2" são convertidos em números, 5 e 2

Conversão automática em sequências de caracteres

O JavaScript chama automaticamente a função toString() para uma variável quando você tenta exibir um objeto ou uma variável:

					
						document.getElementById("demo").innerHTML = minhaVar;

						// if minhaVar = {name:"Fjohn"}  // toString converte para "[object Object]"
						// if minhaVar = [1,2,3,4]       // toString converte para "1,2,3,4"
						// if minhaVar = new Date()      // toString converte para "Fri Jul 18 2014 09:08:55 GMT+0200"

Isso também ocorre com números e booleanos, apesar de não ser tão fácil de reconhecer:

					
						// if minhaVar = 123             // toString converte para "123"
						// if minhaVar = true            // toString converte para "true"
						// if minhaVar = false           // toString converte para "false"
