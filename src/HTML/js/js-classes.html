Classes

Classes são modelos para objetos. Uma classe pode ser usada para criar vários objetos com propriedades e comportamentos semelhantes.

Sintaxe

Use a palavra-chave class para criar uma classe e sempre adicione um método chamado constructor().

				
					class NomeClasse {
						constructor() { ... }
					}

Vejamos um exemplo, em que criamos uma classe chamada Carro com duas propriedades: nome e ano.

				
					class Carro {
						constructor(nome, ano) {
							this.nome = nome;
							this.ano = ano;
						}
					}

Observe que uma classe NÃO É um objeto, mas sim um modelo para objetos.

Como usar uma classe

Após criar a classe, podemos usá-la para criar objetos:

				
					const meuCarro1 = new Carro("Ford", 2014);
					const meuCarro2 = new Carro("Audi", 2019);

					document.getElementById("demo").innerHTML = meuCarro1.nome + ", " + meuCarro1.ano + "
" + meuCarro2.nome + ", " + meuCarro2.ano;
					// Exibe "Ford, 2014
									  Audi, 2019"

A classe chama automaticamente o método constructor() ao criar um novo objeto. Este é um método especial:

  • Ele precisa ter o nome exato "constructor"
  • Ele precisa ser executado automaticamente ao criar um novo objeto
  • Ele é usado para inicializar propriedades de objetos

Se você não definir este método, o JavaScript adicionará um método constructor() vazio.

Métodos de classes

Um método de classe é uma função declarada dentro de uma classe. Para criá-lo, use a mesma sintaxe dos métodos de objetos:

				
					class NomeDaClasse {
						constructor() { ... }
						metodo_1() { ... }
						metodo_2() { ... }
						metodo_3() { ... }
					}

Sempre use o método constructor() e a palavra-chave class para criar métodos de classes. Por exemplo, vamos criar um método idade que retorna a idade de um carro:

				
					class Carro {
						constructor(nome, ano) {
							this.nome = nome;
							this.ano = ano;
						}
						idade() {
							const data = new Date();
							return data.getFullAno() - this.ano;
						}
					}
					
					const meuCarro = new Carro("Ford", 2014);
					document.getElementById("demo").innerHTML =
					"Meu carro tem " + meuCarro.idade() + " anos."; // Exibe "Meu carro tem 10 anos."

Também é possível adicionar parâmetros aos métodos de classes:

				
					class Carro {
						constructor(nome, ano) {
							this.nome = nome;
							this.ano = ano;
						}
						idade(x) {
							return x - this.ano;
						}
					}
					
					const data = new Date();
					let ano = data.getFullYear();
					
					const meuCarro = new Carro("Ford", 2014);
					document.getElementById("demo").innerHTML=
					"Meu carro tem " + meuCarro.idade(ano) + " anos."; // Exibe "Meu carro tem 10 anos."

A sintaxe de classes deve ser escrita no modo restrito. Você receberá um erro se não declarar uma variável antes de usá-la:

				
					class Carro {
						constructor(nome, ano) {
							this.nome = nome;

Herança de classes

Para criar uma herança de classe, use a palavra-chave extends. Use a palavra-chave super para chamar o construtor da classe pai. Uma classe criada com herança herda todos os métodos de outra classe:

			
				class Carro {
					constructor(marca) {
						this.nomecarro = marca;
					}
					present() {
						return 'Eu tenho um ' + this.nomecarro;
					}
				}
				
				class Modelo extends Carro {
					constructor(marca, mod) {
						super(marca);
						this.modelo = mod;
					}
					show() {
						return this.present() + ', é da marca ' + this.modelo;
					}
				}
				
				let meuCarro = new Modelo("Ford", "Mustang");
				document.getElementById("demo").innerHTML = meuCarro.show(); // Exibe "Eu tenho um Ford, é da marca Mustang"

A herança é útil em casos em que precisamos reutilizar o código, como os métodos e propriedades de uma classe existente, ao criar uma nova classe.

Obtentores e definidores

As classes também nos permitem usar obtentores (getters) e definidores (setters).

Pode ser bom usá-los para as propriedades, especialmente se quisermos fazer algo especial com o valor antes de retorná-los ou defini-los. Para adicionar obtentores ou definidores a uma classe, use as palavras-chave get e set, respectivamente.

			
				class Carro {
					constructor(marca) {
						this.nomecarro = marca;
					}
					get cnom() {
						return this.nomecarro;
					}
					set cnom(x) {
						this.nomecarro = x;
					}
				}
				
				const meuCarro = new Carro("Ford");
				
				document.getElementById("demo").innerHTML = meuCarro.cnom; // Exibe "Ford"

Mesmo se o obtentor for um método, não use parênteses quando quiser obter o valor da propriedade.

O nome do método obtentor/definidor não pode ser igual ao nome da propriedade, então muitos programadores usam um sublinhado (_) antes do nome da propriedade para diferenciá-la do nome do obtentor/definidor. Usando o mesmo exemplo acima, ficaríamos com:

			
				...
				constructor(marca) {
					this._nomecarro = marca;
				}
				get nomecarro() {
					return this._nomecarro;
				}
				set nomecarro(x) {
					this._nomecarro = x;
				}
				...

Para usar um definidor, use a mesma sintaxe que se usa ao definir um valor de propriedade, mas sem os parênteses. Usando o mesmo exemplo acima, ficaríamos com:

			
				...
				const meuCarro = new Carro("Ford");
				meuCarro.nomecarro = "Volvo";
				document.getElementById("demo").innerHTML = meuCarro.nomecarro; // Exibe "Volvo"

Içamento

Diferente de funções e de outras declarações no JavaScript, as declarações de classes não são içadas. Quer dizer, precisamos declarar uma classe antes de poder usá-la:

			
				// Aqui ainda não podemos usar a classe.
				// meuCarro = new Carro("Ford") exibirá um erro.

				class Carro {
					constructor(marca) {
						this.nomecarro = marca;
					}
				}

				// Agora podemos usar a classe:
				const meuCarro = new Carro("Ford")

Métodos estáticos

Métodos de classe estáticos são definidos na própria classe. Não é possível chamar um método estático em um objeto, apenas em uma classe de objeto. Vejamos um exemplo:

			
				class Carro {
					constructor(nome) {
						this.nome = nome;
					}
					static hello() {
						return "Hello!!";
					}
				}
				
				const meuCarro = new Carro("Ford");
				
				// Podemos chamar 'hello()' na classe Carro:
				document.getElementById("demo").innerHTML = Carro.hello();
				
				// Mas NÃO em um objeto Carro:
				// document.getElementById("demo").innerHTML = meuCarro.hello();
				// Isso exibe um erro.

				// Se quiser usar o objeto meuCarro dentro do método static, envie-o como um parâmetro:
				document.getElementById("demo").innerHTML = Carro.hello(meuCarro);
