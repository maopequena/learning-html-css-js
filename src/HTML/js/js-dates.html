Datas

Os objetos de data no JavaScript nos permitem trabalhar com datas e horas. Objetos de data são estáticos, isto é, o "relógio" não é ao vivo. O relógio do computador é ao vivo, mas não o de objetos de data.

Resultado de data

Por padrão, o JavaScript usará o fuso horário do navegador para exibir uma data como uma cadeia de caracteres de texto:

Wed Oct 09 2024 14:40:57 GMT-0300 (Horário Padrão de Brasília)

Criar objetos de data

Há nove maneiras de criar objetos de data, todos usam a o formato new Date(), o que muda são os parâmetros:

			
				new Date()
				new Date(date string) // no formato "yyyy-mm-dd hh:mm:ss:ms"

				new Date(year,month)
				new Date(year,month,day)
				new Date(year,month,day,hours)
				new Date(year,month,day,hours,minutes)
				new Date(year,month,day,hours,minutes,seconds)
				new Date(year,month,day,hours,minutes,seconds,ms)

				new Date(milliseconds)

new Date()

Sem parâmetros, este construtor gera a data e hora atuais:

			
				const d = new Date(); // 2024-10-09T17:51:19.372Z

new Date(date string)

É possível definir uma cadeia de caracteres específica para a data:

			
				const d = new Date("October 13, 2014 11:13:00"); // 2014-10-13T14:13:00.000Z
				const e = new Date("2022-03-25"); // 2022-03-25T00:00:00.000Z

Note que acima a hora solicitada no parâmetro foi 11h13, mas o resultado exibiu 14h13, porque o fuso horário do Brasil (minha localidade) está três horas à frente do fuso horário de GMT.

new Date(year, month, ...)

É possível especificar também qualquer dos elementos de uma data (até os milissegundos!) especificando até 7 números, que identificam, em ordem, o ano, o mês, o dia, a hora, os minutos, os segundos e os milissegundos. É possível também especificar de 2 a 6 números. Porém, NÃO É POSSÍVEL usar menos de dois parâmetros, neste caso, o parâmetro será considerado como milissegundos.

			
				const d = new Date(2018, 11, 24, 10, 33, 30, 0); // 2018-12-24T12:33:30.000Z

Observe que acima o mês é solicitado como 11, mas o resultado exibiu 12. Isso ocorre porque o JavaScript conta os meses de 0 até 11, isto é Janeiro é 0 e Dezembro é 11. Se definirmos o mês como um número maior que 11, o JavaScript não exibirá um erro, apenas transferirá para o ano seguinte ao solicitado no parâmetro (ou o ano atual se nenhum for definido). Os dois exemplos a seguir significam a mesma coisa:

			
				const d = new Date(2018, 15, 24, 10, 33, 30); // 2019-04-24T13:33:30.000Z
				const e = new Date(2019, 3, 24, 10, 33, 30); // 2019-04-24T13:33:30.000Z

O caso é o mesmo para a data solicitada nos parâmetros!

			
				const d = new Date(2018, 5, 35, 10, 33, 30); // 2018-07-05T13:33:30.000Z
				const e = new Date(2018, 6, 5, 10, 33, 30); // 2018-07-05T13:33:30.000Z

Ao usar um ou dois dígitos para o ano, o JavaScript interpreta o valor como 19xx.

			
				const d = new Date(99, 11, 24); // 1999-12-24T02:00:00.000Z
				const e = new Date(9, 11, 24); // 1909-12-24T03:06:28.000Z

O JavaScript armazena datas como milissegundos contando desde 01 de janeiro de 1970!

A hora zero é 01 de janeiro de 1970 00:00:00 UTC. Um dia (24 horas) contém 86.400 milissegundos. A data atual está a 1.728.498.766.372 milissegundos da hora zero.

new Date(milliseconds)

Ao definir milissegundos como o parâmetro, é criado um objeto de data com os milissegundos além da hora zero:

			
				// 01 de janeiro de 1970 MAIS 100 000 000 000 milissegundos
				const d = new Date(100000000000); // 1973-03-03T09:46:40.000Z
				// 01 de janeiro de 1970 MENOS 100 000 000 000 milissegundos
				const d = new Date(-100000000000); // 1966-10-31T14:13:20.000Z
				// 01 de janeiro de 1970 MAIS 24 horas
				const d = new Date(24 * 60 * 60 * 1000); // 1970-01-02T00:00:00.000Z
				// Ou
				const d = new Date(86400000); // 1970-01-02T00:00:00.000Z
				// 01 de janeiro de 1970 MAIS 0 milissegundos
				const d = new Date(0); // 1970-01-01T00:00:00.000Z

Métodos de data

Métodos de data nos permitem manipular os objetos de data criados. Podemos obter ou definir o ano, o mês, o dia, a hora, os minutos, os segundos e os milissegundos usando a hora local ou UTC (também conhecido como hora universal ou GMT).

Exibir datas

Por padrão, o JavaScript usa o método toString() para exibir datas. Isso exibe uma representação em cadeia de caracteres da data, incluindo o fuso horário. O formato é: Wed Oct 09 2024 14:40:57 GMT-0300 (Horário Padrão de Brasília). Veja um exemplo. Ao exibir um objeto de data no HTML, ele é automaticamente convertido para uma cadeia de caracteres com esse método.

O método toDateString() converte uma data em um formato mais fácil de ler. Veja um exemplo.

O método toUTCString() converte uma data em uma cadeia de caracteres usando o padrão UTC. Veja um exemplo.

O método toISOString() converte uma data em uma cadeia de caracteres usando o padrão ISO. Veja um exemplo.

Formatos de data

Há três tipos de formatos de inserção de data aceitos no JavaScript:

Tipo Exemplo
Data ISO "2015-03-25" (o padrão internacional)
Data abreviada "03/25/2015"
Data longa "Mar 25 2015" ou "25 Mar 2015"

Há outros padrões, mas eles não são tão bem definidos e podem depender do navegador para funcionar.

Independente do formato de inserção, os formatos de saída são exibidos como uma cadeia de caracteres completa no seguinte formato: Wed Oct 09 2024 16:31:06 GMT-0300 (Horário Padrão de Brasília).

Datas ISO

A norma ISO 8601 é o padrão internacional para a representação de datas e horas. O JavaScript também prefere este padrão ("YYYY-MM-DD") para os formatos de data. Não se esqueça das aspas!

Também é possível usar somente o ano e o mês, "2015-03", ou somente o ano, "2015", no padrão ISO.

Lembre-se que o fuso horário afeta o resultado exibido.

Para definir também as horas, minutos e segundos, use a sintaxe "YYYY-MM-DDTHH:MM:SSZ". Note que a data e a hora são separadas por um "T" maiúsculo e a hora UTC é definida pelo "Z" maiúsculo. Para definir um fuso horário diferente de UTC, remova o Z e adicione "+HH:MM" ou "-HH:MM", dependendo do fuso horário escolhido.

Observe que se omitirmos o T e o Z na sintaxe, diferentes navegadores gerarão diferentes resultados.

Datas abreviadas

A sintaxe para datas abreviadas é "MM/DD/YYYY".

			
				const d = new Date("03/25/2015"); // 2015-03-25T03:00:00.000Z

Datas longas

A sintaxe para datas longas geralmente é "MMM DD YYYY". O dia e o mês podem vir em qualquer ordem. O mês pode ser escrito por extenso, como "January", ou abreviado, como "Jan". As vírgulas são desconsideradas e não importa se as letras estão em minúsculas, maiúsculas ou usam ambas.

			
				const d = new Date("Mar 25 2015"); // 2015-03-25T03:00:00.000Z
				const e = new Date("25 Mar 2015"); // 2015-03-25T03:00:00.000Z

Inserção de datas: análise de datas

Se uma cadeia de caracteres é válida, use o método Date.parse() para convertê-la em milissegundos. Este método retorna a quantidade de milissegundos entre a data definida e 01 de janeiro de 1970.

			
				let msec = Date.parse("March 21, 2012"); // 1332298800000

Em seguida, podemos converter a variável em um objeto de data.

			
				const d = new Date(msec); // 2012-03-21T03:00:00.000Z

Métodos de obtenção de data

Para hora local

Método Descrição Exemplo
getFullYear() Obtém o ano como um número de quatro dígitos (yyyy) 
						
						const d = new Date();
						const e = d.getFullYear(); // 2024
getMonth()* Obtém o mês como um número de 0 a 11 
					
					const f = new Date();
					const g = f.getMonth(); // 9
getDate() Obtém o dia como um número de 1 a 31 
					
					const i = new Date("10/10/2024");
					const j = i.getDate(); // 10
getDay()** Obtém o dia da semana como um número de 0 a 6 
					
					const k = new Date("10/10/2024");
					const l = k.getDay(); // 4
getHours() Obtém a hora (0-23) 
					
					const m = new Date();
					const n = m.getHours(); // 17
getMinutes() Obtém os minutos (0-59) 
					
					const o = new Date();
					const p = o.getMinutes(); // 58
getSeconds() Obtém os segundos (0-59) 
					
					const q = new Date();
					const r = q.getSeconds(); // 1
getMilliseconds() Obtém os milissegundos (0-999) 
					
					const s = new Date();
					const t = s.getMilliseconds(); // 378
getTime() Obtém a hora em milissegundos desde 1 de janeiro de 1970 
					
					const v = new Date();
					const x = v.getTime(); // 1728594262212

Note que os métodos do tipo get retornam informações de objetos de data existentes. O objeto de data tem o tempo fixo, ou estático, isto é, o relógio não é "ao vivo". A hora de um objeto de data não é o mesmo que a hora atual.

Códigos JavaScript antigos podem ainda usar o método getYear(), que está deprecado. Este método retorna o ano com dois dígitos.

* É possível usar uma matriz de nomes para obter o mês como uma palavra:

			
				const months = ["January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December"];

				const h = new Date();
				let month = months[h.getMonth()]; // October

** No JavaScript, o primeiro dia da semana é domingo (o dia 0). Alguns países, como o Brasil, consideram segunda-feira o primeiro dia da semana. É possível usar uma matriz de nomes para obter o mês como uma palavra:

			
				const days = ["Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"];

				const d = new Date();
				let day = days[d.getDay()]; // Thursday

Date.now()

Retorna a quantidade de milissegundos desde 1 de janeiro de 1970. Este é um método estático do objeto de data, então não é possível usá-lo em um objeto de data, como myDate.now(). A sintaxe deve ser sempre Date.now().

				
					const date = Date.now(); // 1728845376930
					const minute = 1000 * 60; // 60000
					const hour = minute * 60; // 3600000
					const day = hour * 24; // 86400000
					const year = day * 365; // 31536000000
					let years = Math.round(Date.now() / year); // 55

Para hora UTC

Os métodos para hora UTC usam o horário coordenado universal, também conhecido como GMT (Greenwich Mean Time). A diferença da hora local para a hora UTC pode ser de até 24 horas.

Método É o mesmo que Descrição
getUTCDate() getDate() Retorna a data em UTC
getUTCFullYear() getFullYear() Retorna o ano em UTC
getUTCMonth() getMonth() Retorna o mês em UTC
getUTCDay() getDay() Retorna o dia da semana em UTC
getUTCHours() getHours() Retorna a hora em UTC
getUTCMinutes() getMinutes() Retorna os minutos em UTC
getUTCSeconds() getSeconds() Retorna os segundos em UTC
getUTCMilliseconds() getMilliseconds() Retorna os milissegundos em UTC

getTimezoneOffset()

Este método retorna a diferença (em minutos) entre a hora local e a hora UTC.

				
					const d = new Date("2024-10-13");
					let diff = d.getTimezoneOffset(); // 180

Métodos de definição de data

Os métodos desta seção possibilitam definir valores de datas (anos, meses, dias, horas, minutos, segundos e milissegundos) para um objeto de data, isto é são usados para definir parte de uma data.

Método Descrição
setDate() Define o dia como um número (1-31)
setFullYear() Define o ano (com a opção de definir também o mês e o dia)
setHours() Define a hora (0-23)
setMilliseconds() Define os milissegundos (0-999)
setMinutes() Define os minutos (0-59)
setMonth() Define o mês (0-11)
setSeconds() Define os segundos (0-59)
setTime() Define o horário (em milissegundos desde 1 de janeiro de 1970)

setFullYear()

Define o ano de um objeto de data; no exemplo a seguir, usamos o ano 2020:

				
					const d = new Date();
					d.setFullYear(2020); // 2020-10-13T19:11:56.522Z

Com este método também é possível definir o mês e o dia:

				
					const d = new Date();
					d.setFullYear(2020, 11, 3); // 2020-12-03T19:13:16.169Z

setMonth()

Define o mês de um objeto de data, com valores de 0 a 11. Lembre-se que no JavaScript, contamos o mês de janeiro como 0.

				
					const d = new Date();
					d.setMonth(11); // 2024-12-13T19:15:43.402Z

setDate()

Define o dia de um objeto de data, com valores de 1 a 31.

				
					const d = new Date();
					d.setDate(15); // 2024-10-15T19:16:44.162Z

Também pode ser usado para adicionar dias a uma data:

				
					const d = new Date();
					d.setDate(d.getDate() + 50); // 2024-12-02T19:17:37.527Z

Se estiver adicionando dias à data e o mês ou o ano mudar, as alterações são feitas automaticamente pelo objeto de data.

setHours()

Define a hora de um objeto de data, com valores de 0 a 23.

				
					const d = new Date();
					d.setHours(22); // 2024-10-14T01:19:32.932Z

setMinutes()

Define os minutos de um objeto de data, com valores de 0 a 59.

				
					const d = new Date();
					d.setMinutes(30); // 2024-10-13T19:30:40.167Z

setSeconds()

Define os segundos de um objeto de data, com valores de 0 a 59.

				
					const d = new Date();
					d.setSeconds(30); // 2024-10-13T19:21:30.283Z

Comparação de datas

O código a seguir nos ensina a comparar datas com facilidade:

					
						let text1 = "";
						const today1 = new Date();
						const someday1 = new Date();
						someday1.setFullYear(2100, 0, 14);

						if (someday1 > today1) {
							text1 = "Today is before January 14, 2100.";
						} else {
							text1 = "Today is after January 14, 2100.";
						}

						// Today is before January 14, 2100.

						let text2 = "";
						const today2 = new Date();
						const someday2 = new Date();
						someday2.setFullYear(1979, 5, 6);

						if (someday2 > today2) {
							text2 = "Today is before June 6, 1979.";
						} else {
							text2 = "Today is after June 6, 1979.";
						}

						// Today is after June 6, 1979.

Fusos horários

Ao definir uma data sem especificar o fuso horário, o JavaScript usa o fuso horário do navegador do usuário. Ao obter ou definir uma data sem especificar o fuso horário, o resultado é convertido para o fuso horário do navegador.

Avisos importantes

Em alguns navegadores, definir o mês ou ou dia sem 0 à esquerda pode gerar erros: "2015-3-25".

O comportamento da sintaxe "YYYY/MM/DD" é indefinido. Alguns navegadores tentam adivinhar o formato, outros retornam NaN.

O comportamento da sintaxe "DD-MM-YYYY" também é indefinido. Alguns navegadores tentam adivinhar o formato, outros retornam NaN.
