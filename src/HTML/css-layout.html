Layout

A seguir trataremos de propriedades do CSS que configuram o layout da página HTML.

As propriedades width, max-width e margin: auto.

Já sabemos que um elemento de bloco ocupa toda a largura disponível da página.

Definir a propriedade width de um elemento de bloco impedirá que ele se estique até as margens de seu contêiner. Definir as margens como automáticas centraliza o elemento horizontalmente nesse contêiner.

Porém, quando a largura da tela é menor que a largura definida, o navegador adiciona barras de rolagem à página e o contêiner pode ficar maior que a tela, vazando nas laterais. Para solucionar esse problema, defina a propriedade max-width.

A propriedade position

Especifica o tipo de posicionamento de um elemento (static, relative, fixed, absolute ou sticky). Depois, os elementos são posicionados usando as propridades top, bottom, left e right. Essas propridades, entretanto, funcionam de forma diferente dependendo do valor da propriedade position.

Lembre-se: essa propriedade define o posicionamento de acordo com o contêiner pai do objeto definido. Isto é, se o elemento estiver dentro de um contêiner, o posicionamento do elemento será relativo ao contêiner.

position: static

Todos os elementos têm essa posição definida por padrão e não são afetados pelas propriedades top, bottom, left e right. Isso define o elemento de acordo com o fluxo normal da página.

Exemplo

Este elemento div tem position: static;.

position: relative

Um elemento com esta propriedade será posicionado de forma relativa ao seu contêiner, e as propriedades top, bottom, left e right alteram a posição do elemento.

Exemplo

Este elemento div tem position: relative; e left: 70px;.

position: fixed

Um elemento com esta propriedade é posicionado relativamente ao viewport, isto é, sempre fica no mesmo lugar ao rolar a página. Use top, bottom, left e right para controlar o posicionamento do elemento.

O local na página em que o elemento ficaria não tem espaço em branco.

Note o elemento fixo no canto direito inferior da página! Veja que ele não ocupa espaço aqui.

Exemplo

Este elemento div tem position: fixed; e bottom: 0; e right: 0;.

position: absolute

Um elemento com esta propriedade é posicionado relativamente ao ancestral mais próximo, em vez de relativamente ao viewport, como o elemento fixed. Entretanto, se o elemento absoluto não tiver ancestrais, ele usará o corpo do documento e se movimentará na página com a rolagem.

Observação: elementos com posição absoluta são removidos do fluxo normal da página e pode ficar sobrepostos a outros elementos.

Exemplo

Este elemento div tem position: relative;
Este elemento div tem position: absolute;

position: sticky

Esta propriedade posiciona o elemento com base na rolagem da página. Esta propriedade alterna o estado entre "relative" e "fixed": o elemento fica relativo até atingir a posição definida, depois fica fixo.

Observação: elementos com posição fixa não são removidos do fluxo normal da página e podem ficar sobrepostos a outros elementos.

Observação: elementos com posição fixa não tem ancestrais.

A propriedade z-index

Define a ordem de empilhamento de um elemento e quais elementos sobreporão outros. A ordem pode ser positiva ou negativa, isto é, quais ficarão na frente e quais, atrás.

A propriedade overflow

Define se um conteúdo deve ser cortado e se serão exibidas barras de rolagem no caso de o conteúdo ser maior que a área definida para o elemento.

Valores da propriedade overflow

  • visible: padrão. o conteúdo que sobra não é cortado e é processado fora da caixa do elemento.
  • hidden: o conteúdo que sobra é cortado e o restante fica invisível.
  • scroll: o conteúdo que sobra é cortado e são exibidas barras de rolagem para o restante.
  • auto: similar a scroll, mas as barras de rolagem aparecem conforme necessário.

Observação: essa propriedade só funciona para elementos com uma altura definida.

Exemplos

overflow-x e overflow-y

Definem o que acontece com os eixos horizontal e vertical, respectivamente, do elemento em questão.

overflow-x: hidden specifies what to do with the left/right edges of the content. overflow-y: scroll specifies what to do with the top/bottom edges of the content.

overflow: wrap

overflow-wrap: normal|anywhere|break-word|initial|inherit;

Define se o navegador pode ou não quebrar linhas se o conteúdo for muito grande para o contêiner.

As propriedades float e clear

float define como o elemento deve flutuar na página e clear define quais elementos podem flutuar ao lado do elemento com esta propridade e em qual lado.

O uso mais simples de float é fazer o texto se adequar em volta de uma imagem.

Valores de float: left, right, none e inherit.

clear deve corresponder ao float usado, isto é, se o elemento tiver um float: left, o clear deve ser o mesmo.

Valores de clear: left, right, none, both e inherit.

Consulte também: Cleafix Hack, Exemplos de float e The end of the clearfix hack?.

display: inline-block

Em comparação com o elemento display: inline, a principal diferença é que display: inline-block possibilita definir a largura e a altura do elemento. Além disso, com display: inline-block, as margens e paddings superior e inferior são respeitadas, o que não acontece com display: inline.

Em comparação com display: block, a principal diferença é que display: inline-block não adiciona uma quebra de linha após o elemento, então um elemento fica grudado aos que estão ao lado dele.

Layout de páginas da Web

O cabeçalho geralmente fica no topo da página (ou logo abaixo do menu de navegação) e costuma apresentar um logotipo e o nome do site.

A barra de navegação contém uma lista de links para ajudar os visitantes a navegar pelo site.

O layout da seção de conteúdo geralmente depende dos usuários que se deseja atrair com o site. Os layouts mais comuns são de 1 (para navegadores móveis), 2 (para tablets e laptops) ou 3 (para desktops apenas) colunas. Uma dessas colunas pode ocupar 50% da largura disponível, exibindo o conteúdo principal, deixando os outros 50% para serem divididos entre outras duas colunas (cada uma com 25%).

O rodapé fica no final da página e geralmente apresenta informações como copyright e de contato.
