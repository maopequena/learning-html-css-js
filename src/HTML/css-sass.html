SASS

O SASS é um pré-processador de CSS, ele reduz a repetição ao criar folhas de estilo, o que economiza tempo.

Introdução

O SASS (pronuncia-se [sɛs], extensão de arquivo .scss) funciona como uma extensão do CSS, com todas as suas versões, e é gratuito para baixar e usar.

Por que usar SASS?

Uma folha de estilo pode ficar muito grande, complexa e difícil de manter, e é nesses casos que o SASS pode ajudar. Ele apresenta recursos que não existem no CSS, como variáveis, regras aninhadas, mixins, importações, herança, funções incorporadas e muito mais.

Digamos que nosso site usa estas três cores:

#a2b9bc
#b2ad7f
#878f99

Quantas vezes precisaríamos digitar esses valores de cores? VÁRIAS! E as variações dessas cores? Pois é. Em vez de digitar essas cores, podemos usar variáveis. Assim, se a cor mudar, só precisamos alterar o valor em um lugar:

      
        /* define variables for the primary colors */
        $primary_1: #a2b9bc;
        $primary_2: #b2ad7f;
        $primary_3: #878f99;

        /* use the variables */
        .main-header {
          background-color: $primary_1;
        }

        .menu-left {
          background-color: $primary_2;
        }

        .menu-right {
          background-color: $primary_3;
        }

Observação: o tutorial do W3 sobre SASS está um pouco desatualizado, já que no momento da criação deste site, já é possível usar variáveis com o CSS normal. Inclusive este site já usa as variáveis "--lightest-grey" e "--table-border", por exemplo, para cores.

Como o SASS funciona?

Um navegador não entende o código do SASS, portanto é preciso pré-processá-lo para transformar o código SASS em CSS padrão. Esse processo se chama "transpilação" (uma mistura de tradução e compilação). Então precisamos dar a um transpilador (um tipo de programa) o código SASS para obtermos o código CSS de volta.

Instalação

Requisitos:

  • Sistema operacional: independe de plataforma.
  • Navegador: o SASS funciona no Edge/IE (a partir do IE 8), Firefox, Chrome, Safari e Opera.
  • Linguagem de programação: o SASS é baseado em Ruby.

Saiba mais sobre SASS no site oficial e na página sobre instalação.

Variáveis

As variáveis armazenam informações que podem ser reutilizadas posteriormente. As informações que podem ser armazenadas incluem:

  • sequências de caracteres
  • números
  • cores
  • booleanos
  • listas
  • valores nulos

Para declarar uma variável, use o cifrão ($) seguido do nome da variável e do valor: $nomevariavel: valor;. Por exemplo:

      
        $myFont: Helvetica, sans-serif;
        $myColor: red;
        $myFontSize: 18px;
        $myWidth: 680px;

        body {
          font-family: $myFont;
          font-size: $myFontSize;
          color: $myColor;
        }

        #container {
          width: $myWidth;
        }

Após o processamento, o CSS será o seguinte:

      
        body {
          font-family: Helvetica, sans-serif;
          font-size: 18px;
          color: red;
        }
        
        #container {
          width: 680px;
        }

O escopo de uma variável SASS depende do aninhamento. No exemplo a seguir, a cor do <h1> será verde, mas a cor de <p> será vermelha.

      
        $myColor: red;

        h1 {
          $myColor: green;
          color: $myColor;
        }

        p {
          color: $myColor;
        }

Entretanto, podemos usar o comutador !global para definir variáveis globais, mesmo que elas estejam aninhadas em um elemento específico.

      
        $myColor: red;

        h1 {
          $myColor: green !global;
          color: $myColor;
        }

        p {
          color: $myColor;
        }

Dê preferência para definir as variáveis globais fora dos seletores ou, até, em um arquivo próprio, chamado "_globals.scss", que pode ser incluído no arquivo de regras com a palavra-chave @include.

Aninhamento

Com SASS, é possível aninhar seletores! Isso deixa o código mais limpo e mais fácil de ler. Por exemplo:

      
        nav {
          ul {
            margin: 0;
            padding: 0;
            list-style: none;
          }
          li {
            display: inline-block;
          }
          a {
            display: block;
            padding: 6px 12px;
            text-decoration: none;
          }
        }

Propriedades aninhadas

Muitas propriedades do CSS têm o mesmo prefixo, como font-family, font-size e font-weight. Com o SASS, podemos agrupá-las:

      
        font: {
          family: Helvetica, sans-serif;
          size: 18px;
          weight: bold;
        }
        
        text: {
          align: center;
          transform: lowercase;
          overflow: hidden;
        }
