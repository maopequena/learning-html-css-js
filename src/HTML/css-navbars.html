Barras de navegação

Ter uma navegação fácil de usar é importante para qualquer site. Com o CSS é possível transformar menus HTML enfadonhos em belas barras de navegação.

Basicamente, uma barra de navegação é uma lista de links, portanto é preciso usar os elementos <ul> e <li> para, depois, estilizá-los conforme desejado.
